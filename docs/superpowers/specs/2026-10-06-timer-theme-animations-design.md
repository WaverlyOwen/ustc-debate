# 计时器：主题动画打磨 设计文档

日期：2026-10-06　分支：`feature/theme-animations`　基于：`docs/superpowers/specs/2026-09-30-debate-timer-design.md`（下文称「主规格」）与 `docs/superpowers/specs/2026-10-01-timer-themes-and-match-export-design.md`（下文称「主题规格」）

## 0. 用户的要求

> 优化主题动画，现在的动画比较粗糙。

先做了一次审计：共享舞台（`stage.css`、`render.js`）与八个主题，逐个时刻录帧、逐条交叉核实，保留 68 条（高 2、中 35、低 31），驳回 9 条。原有的核心动效是对的（入场横扫没有 `to` 帧、落在实时裁切上；逐帧排水平滑；静帧、减少动态、缩略图都有专门处理），粗糙来自它们周围。几乎所有条目落在八种模式里：

| # | 模式 | 典型 |
|---|---|---|
| P1 | 缓动的时刻里夹着一帧突变 | 换边时五个主题把共享的滤镜变暗换成了没有过渡的换色；锁定时数字一帧消失；超时的装饰一帧变色；换环节时旧状态一帧消失 |
| P2 | 一个通用的铃声波纹套在所有主题上 | 金色圆环画在数字之上；自由辩一方用完时第二圈落在舞台中央；昼里金上加金，绿幕里半透明地压着键色 |
| P3 | 入场只有色场在动，竖直的裁切边与有机纹理冲突 | 星云、粉笔排线、水墨、网点被一道直边切开；其余部件在第 0 帧就位 |
| P4 | 内容变化引起版式跳动 | 超时的「+」让整串数字左移约 100px，两圈终止波纹因此不同心；锁定时数字 `display: none`，状态字换了位置和大小 |
| P5 | 同一时刻里时序不一 | 换边时数字跟着分界线的弹簧过冲；墨的浓淡一帧跳而字色走 300ms，对比度掉到约 1:1；暂停时冒号一帧跳而「暂停」淡入 200ms |
| P6 | 每帧重画、重栅格化 | `--used` 几乎每帧写入并驱动数字的裁切；黑板的板与排线每帧重画（软件光栅约 17fps）；半区色场随列宽每帧改尺寸 |
| P7 | 该连续的运动在跳步 | 构成的扇形按 .5° 跳、与数字的 1Hz 不同步；张力在两次秒跳之间变化；冒号在暂停与继续时跳变 |
| P8 | 绿幕的键控被半透明或键色帧破坏 | 底板以透明度淡入；波纹半透明跨过绿；提示条是略亮的键绿 |

P1–P3 的根子是钩子不够：主题只能按 `data-phase`、`data-side`、`.is-entering` 写规则，不知道哪声铃响了、数字在哪，入场也只有约 600ms。所以先改共享层（§1，提交 `44f2056`），再逐个主题设计（每个时刻比较「立意优先」与「克制优先」两种做法，按立意、可读、弱机性能、对测试与静帧的风险、克制五项裁定：表现更强的做法只要在中间三项上不吃亏就取它），最后经一轮审查与一次八个主题的一致性检查修正（`b822b2f`、`a132ee1`、`6efaa8a`、`75bef1e`、`f28648b`、`2abe4a9`）。

**不变的约束**（主规格与主题规格的，全部保留）：冻结截图（`?frozen=1`）是每个状态的终态；缩略图静止；`prefers-reduced-motion` 下只留颜色与数值的变化；不逐帧重跑滤镜，不逐帧排版（2026-10-03 规格 P5）；画面确定；绿幕上每个像素要么是键色、要么是实色；主题规格 §1.5 的可读性硬约束。

## 1. 共享层的动效

### 1.1 每个时刻一套时序

`--ease-out` 即 `cubic-bezier(.2,.8,.2,1)`，`--ease-spring` 即 `cubic-bezier(.34,1.36,.64,1)`；时间从触发那一帧算起。

| 时刻 | 动什么 | 时长 / 曲线 |
|---|---|---|
| 换环节（入场） | 色场从本方席位一侧横扫，关键帧只有 `from`，落在实时裁切上；标题、发言人、数字依次浮起；卡片的辩题、队名、记录各自浮起（间隔卡：标题 0、数字 140、辩题 210ms）；提示铃线随色场淡入；进度条的段换不透明度，当前段的金色标记淡入 | 色场 560ms `--ease-out`；文字 `dt-rise` 420ms `--ease-out`，上浮 1.1cqh，错开 0 / 70 / 140ms；铃线 300ms 从 260ms 起；进度条 300ms。全部 `backwards` 填充。`.is-entering` 留 1100ms（`ENTER_MS`），主题自己的入场动画不超过 1000ms |
| 开始 / 继续 | 冒号从静止值接上 1Hz 呼吸（1 ↔ .55），峰值落在数字跳变上 | 接上 200ms（`dt-colon-wake`）；呼吸 1000ms，相位由 `--beat-delay` 定 |
| 暂停 | 冒号从呼吸的当前值落到静止值（默认 .55），此后冒号上不再有动画；「暂停」淡入；继续时「暂停」带着字淡出 | 200ms |
| 状态变化 | 数字与冒号的颜色、「+」的出现；提示铃响后铃线淡出 | 300ms `ease`；铃线 400ms |
| 提示铃 | 一道贴合字形的金色椭圆，在响铃的那个时钟里、数字之下扩开淡出；冒号变金 | 1100ms `ease-out`，缩放 1.15 → 1.65，不透明度 .8 → 0；冒号 300ms |
| 逐秒倒数 | 数字轻弹 1.07 → 1 | 240ms |
| 终止铃（单方） | 两圈，第二圈沿用第一圈的测量，两圈同心；色场最后一截收尽 | 1100ms × 2，间隔 320ms（`RING_GAP_MS`，与双响铃同步） |
| 超时起点 | 数字不动；数字与冒号一起变为 `--over-ink`（默认金）；「+」悬在数字左侧，不占排版，淡入后以 0.5Hz 呼吸；主题的超时记号落在第二声铃上，在金色数字读完之后 | 300ms `ease`；呼吸 2000ms 从 300ms 起；记号 `dt-stamp 300ms var(--ease-out) 320ms backwards` |
| 自由辩换边 | 分界线带回弹滑动；数字字号、等待方变暗（滤镜与 `--dim`）、地线展开或收拢，都不过冲，与弹簧同时结束 | 分界线 520ms `--ease-spring`；其余 520ms `--ease-out` |
| 一方用完 | 该方一圈波纹，与换边同时开始；数字原地退去（留着位置）；「时间到」用标题字体居中盖在原处 | 波纹 1100ms；数字 240ms（不透明度 `ease`，缩到 .92 `--ease-out`）；状态字 200ms 后 300ms 淡入 |
| 放弃（G G） | 同上，没有铃；所有读 `--remain` 的东西（水位、笔触、表盘、网点、星云）一起排空 | `--remain` 520ms `--ease-out` |
| 提示条 | 从顶部下滑，1.5s 后收回 | 200ms：出 `--ease-out`，收 `ease-in` |
| 计时中 | 色场逐帧收回；数字张力按整秒变化 | 无过渡 |

细则：

- **半区里的波纹不出本列**：`render.js` 写 `--ring-to = min(1.65, .96 × 列宽 / 椭圆宽)`，列宽取铃响之后弹簧落定的宽度（提示铃 58%；用完一方 42%，对方已锁定时仍是 58%）。实测用完一方的波纹在 16:9 下只长到约 1.41–1.56，真 4:3 下约 1.13，接近只剩淡出，这是几何限制。间隔的波纹停在 1.2：居中的环节名在数字上方 3cqh，时钟画在标题之上。
- **锁定**：终态立即生效，只有过渡等入场结束（`.dt-stage:not(.is-entering)`）。打开时已有一方用完的环节直接是终态；入场 1.1s 内发生的锁定是一帧切换；解锁（撤销、重置）也是一帧切换。
- **冒号停下后不留动画**：运行中的动画或结束了的 `forwards` 填充会让元素常驻合成层，自由辩里带滤镜的等待半区因此每帧重画。所以停下时只放一次 200ms 的 `dt-colon-settle`（无填充），从 `--colon-from` 落到 `--colon-rest`；`--colon-from` 是 `render.js` 在 `update()` 写任何东西之前读到的每个冒号当时的不透明度（读样式会刷新样式，夹在中间会把一次更新拆成两半，等待半区的冒号就丢了颜色过渡）。
- **呼吸的相位**：时钟开始时 `render.js` 在时钟上写 `--beat-delay = −(1000 − 距下一次秒跳的毫秒)`，新环节是 0ms；它写在 `data-running` 之前，呼吸与 wake 在同一次样式计算里生成，恢复时冒号不会先闪到呼吸的值。
- **张力与量化**：`t = 1 − 显示整秒 / 总整秒`（超时、结束为 1，间隔为 0），与数字跳变同帧，值不变不重写；每一步会重排一次，所以一秒最多一次。`--used`、`--remain` 量化到 1/2000（1920 宽约 1px），值变了才写。
- **超时的「+」**：分钟到两位（时钟的 `data-long`）且舞台比 3:2 更方（4:3、5:4）时，「+」回到排版里，否则 +MM:SS 会出屏；这一刻（+9:59 → +10:00）数字本来就要重新居中。+10:00 以下仍悬在左侧。
- **「暂停」淡出时字还在**：`render.js` 把「暂停」记在 `.dt-state[data-was]`，清空后 `:empty::before` 显示它直到淡完；锁定一方的状态字不留；换环节直接切掉。
- **铃属于响它的环节**：换环节时清掉 `data-bell` / `data-bell-clock`。
- **缩略图是静帧**：`mount(host, {thumbnail: true})` 也给舞台加 `data-still`。冻结与减少动态的规则也覆盖舞台自己的 `::before` / `::after`（主题用它们画霾或入场遮片）。

### 1.2 主题可用的钩子

| 钩子 | 在哪、何时 | 用途与限制 |
|---|---|---|
| `.dt-ring`，带 `data-type="warn\|end"`、`data-nth="1\|2"`、`data-side="pro\|con\|none"` | 在响铃的 `.dt-clock` 里，`z-index: -1`（数字之下）；`--bell-w` / `--bell-h` 是字形的宽、高（舞台的百分比），`--bell-dy` 是字形中心比时钟中心低多少（cqh 数）；半区里有 `--ring-to`，间隔里是 1.2。第一次 `animationend` 时移除，兜底 1500ms | 主题换形（流星、辉光、色带两线、金边、墨洇、两鼓、黄线）。用 margin 居中，`translate` 留给主题。时钟是独立合成组：不能用 `mix-blend-mode`；在半区里继承那一半的变暗滤镜，还会被半区裁切 |
| 舞台 `data-bell="warn\|count\|end"`、`data-bell-clock="main\|pro\|con"` | 铃响后 1500ms（`RING_MS`）；换环节时清除；减少动态下不设；冻结演示与缩略图里没有 | 铃响期间的一次性动画（底板闪边、刻度点亮）。`RING_MS` 不得低于 1420（绿幕的 `cr-flash-twice`）。投影窗口可能先收到状态、后收到铃，按铃键控的终态会先闪一帧 |

| `.dt-stage.is-entering` | 换环节时 1100ms | 主题入场动画 ≤ 1000ms。只能门控过渡，不能门控动画（§1.3 事实 3） |
| `@keyframes dt-fade-in`、`dt-stamp`、`dt-rise`、`dt-sweep-l` / `-r` | — | 都只有 `from`。超时记号用 `dt-stamp 300ms var(--ease-out) 320ms backwards` |
| `--dim`（`@property <number>`，继承） | 每个 `.dt-half`：发言或未开始 0，等待 1；520ms `--ease-out` | 按颜色或不透明度变暗的主题读它，与弹簧同步 |
| `--remain`（`@property <number>`，继承） | 每个 `.dt-half` 的余量，1/2000 一步；锁定时 520ms 过渡（入场后） | 放弃时排空；锁定后一步归零的主题（墨、孔版）在自己的锁定规则里改成 `0s` 加延迟 |
| `--over-ink` | 时钟上；默认 `--accent` | 超时数字与冒号的颜色，一处设置 |
| `--beat-delay`、`--colon-from`、`--colon-rest` | `--beat-delay` 在时钟开始时写在时钟上；`--colon-from` 在时钟停下时写在每个冒号上；`--colon-rest` 由主题设，默认 .55 | 呼吸与秒跳同相；停下时的静止值（孔版设 1） |
| `--secs`、`--secs-total` | 舞台与每个半区；显示的整秒与总整秒，每秒变一次；舞台上没有活动时钟时（开场卡、结束卡、未开始的双方环节）两者都是 0，超时 `--secs` 为 0 | 每秒一跳的表盘（构成） |
| `--used`、`--tension` | 舞台；`--used` 1/2000 一步，`--tension` 按整秒 | 主题不必自己再量化；不许给它们加过渡 |
| `.dt-sign` 绝对定位；时钟的 `data-long` | 「+」悬在数字左侧，空时不透明度 0（不再 `display: none`）；`data-long` = 分钟两位 | 主题不必处理「+」的跳动；要把「+」放进底板的主题自己覆盖（绿幕） |
| `.dt-state[data-was]` | 「暂停」清空后的字 | 另设了 `.dt-state` 不透明度的主题要把 `:empty` 设回 0（墨） |
| `[data-locked]` 的几何 | 数字不透明度 0、缩到 .92，留着盒子；`.dt-state` 居中，标题字体 6cqh | 锁定与放弃有稳定的位置 |
| `data-still` | 冻结演示与缩略图的舞台 | 新增的一次性层挂在 `:not([data-still])` 下或只用 `from` 帧 |

**主题写动效的义务：**

1. 重写某个元素的 `transition` 时，列全它原有的过渡：`.dt-half` 上保留 `filter`、`--dim`，锁定规则里再加 `--remain`；`.dt-half .dt-digits` 上保留 `font-size`、`color`；`.dt-sign` 上保留 `opacity 300ms`。
2. 一次性动画只写 `from` 帧、用 `backwards` 填充，终态就是实时值，冻结截图（`animation-delay: -10s` 暂停）里自然落定。
3. 不把 `animation` 门控在 `:not(.is-entering)` 下。
4. 计时器驱动的状态（`data-bell`、`data-locking`、只在入场时存在的层）不进静帧；新的循环动画周期要整除 10s（这次没有新增循环）。
5. 不给 `font-variation-settings`、`--tension`、`--used` 加过渡；带 feTurbulence 或笔刷滤镜的层上，不放随 `--used`、`--remain`、`--dim` 连续变化的渐变或颜色（改为叠一层只变不透明度的层）。
6. 主题占用的共享位置要互相知会：堂、昼占用 `.dt-deco` 的 `transition` 与 `::before` / `::after`；星轨占用舞台的 `::after`，墨的入场遮片也在舞台的 `::after`（z 6）。

### 1.3 写动效前先读：浏览器事实（Chromium 141 / Edge，探针实测）

1. 移除一个动画，不会让过渡从动画当前值起算：属性一帧跳回基础值。
2. 一个属性只要被某个 CSS 动画持有（正在播放，或 `forwards` / `both` 填充已结束），无论在变化前还是变化后的样式里，这个属性上的过渡都不会启动。所以入场关键帧用 `backwards`；要在动画之上接管一个属性，叠一个动画，而不是过渡。
3. 一条规则开始匹配时，它声明的 `animation` 就开始播放，包括因为某个类被移除而开始匹配。所以绝不能把动画门控在 `:not(.is-entering)` 下（类移除时会重放）；过渡需要值变化才触发，可以这样门控。
4. 更具体的规则里的 `transition` 简写会替换整张过渡表。
5. 同一次样式变化里，一边取消另一个动画的暂停、一边新加一个叠加动画，叠加动画的第一帧不生效。所以不用 `animation-play-state` 做暂停与恢复。
6. （堂的探针）移除声明过渡的类，不会停止正在跑的过渡；值随后再变，它也照原时长跑完。要让它在类移除时停下，基础规则须写 `transition: none`（写 `<属性> 0s` 不行）。用「入场期间才有的过渡」来保持旧值的主题（堂、昼）都靠这一条。
7. （星轨的探针）新建的 CSS 过渡在创建时是 pending，`startTime` 要到下一帧才定；`effect.getComputedTiming().progress` 是缓动后的进度（弹簧过冲时大于 1），反向时新过渡的时长已按缩短系数算好。想与过渡同步的画师要读过渡本身，不能按时钟推算。

### 1.4 计时中每一步都整盒重画的四种写法（实测）

渲染器每一步都写 `--used`，它在舞台上继承，整棵子树重算样式。下面四条由黑板的设计实测得出，一致性审查用 `drive.js`（1920×1080，`--disable-gpu --disable-gpu-compositing`，按瓦片计数）复核并改正了第 2 条：

1. 经 `var()` 进入声明的 `url()` 图片，每次样式重算都被当作新图，整盒连同滤镜重画；含 `url()` 图片的声明里另有任何 `var()` 也一样。`--backdrop` 正是经 `stage.css` 的 `var(--backdrop)` 画出的。图片要字面写在用到它的盒子上（例如主题自己的 `.dt-backdrop::before`）。
2. 同一个 `background` 或 `mask` 列表里既有 `url()` 图片又有渐变，每次重算整盒重画，**普通元素与伪元素都一样**（黑板原先只在伪元素上测到）。实测墨的 `.dt-backdrop`：图片字面写出、渐变仍同列，4 秒 1959 块瓦片；只留字面图片，80 块（只画一次）。把渐变画成 SVG 图（`linearGradient`、`rect`），或把图片单独放到另一个盒子上。
3. 自带滤镜的元素自成一层时标 `will-change: transform`，合成器每帧重跑滤镜；标 `will-change: opacity`，滤镜只画进图层一次。滤镜写在子元素（`::before`）上，动的只是父元素的裁切、遮罩，或这一层的不透明度与变换。
4. 自成一层的滤镜元素必须落在整像素上：`translate: -50%` 居中会落到半像素，颗粒被重采样、洗掉。用 left / top 定位。

## 2. 各主题的动效

墨、构成、孔版按定稿描述，以合并时的实现为准。堂、昼、绿幕、星轨、黑板已在本分支实现，括号里是提交。

### 2.1 堂 `hall`（`2b34611`、`a132ee1`）

**立意**：屋子里的光。新一方的光从它的席位推进来，盖过旧一方的光，屋子不先熄灯。堂是共享层默认样式的参照主题，不添新物件。

- **换环节**：旧色场（同色、同裁切、同顶光）留在新色场之下。会被新色场盖过的那部分（`.dt-deco::before`，两者裁切的交集）先保持实色，以 `cubic-bezier(.55,0,1,.45)` 560ms 淡去，读作被推回席位；新色场不会盖到的部分（`::after`：进卡片、间隔、双方环节时是全部，回到用过时间的单方环节时是新色场边缘以外）以 `--ease-out` 560ms 随屋子暗下。注册的 `--hall-was-field/-l/-r` 以 1000ms `step-end` 保住旧值；舞台底色 `--hall-deep` 560ms 过渡到新一方的沉色或黛，底栏渐变同步。这要求 `render.js` 先 `enter()`（`replay()` 刷新一次样式）、再写新环节，`theme-hall.test.js` 钉住顺序。
- **字随光至**：色场从右侧席位扫来的单方环节，标题 260ms、发言人 330ms 才浮起；数字仍 140ms。
- 其余时刻全用共享默认：滤镜变暗，两层数字保留（1px 重叠的几何测试在堂上跑）。

**静态画面**：不变，十张 1366×768 冻结截图与共享层基线逐像素相同。

### 2.2 昼 `daylight`（`8805104`、`a132ee1`）

**立意**：亮场里的一道光。动作都落在数字背后 34cqh 的色带上；整个主题不用任何滤镜，是弱机的后备。

- **换环节**：浅轨在每个画面上都留着位置，只有颜色随单方环节 300ms 亮起、在两方之间交叉、离开时熄灭；双方的两条轨道出现时以 `@starting-style` 300ms 淡入。旧色带像堂一样留在新色带之下再淡去（`--daylight-was-band/-l/-r` 1000ms `step-end`，560ms 淡出；进单方环节只留新色带将盖过的部分；进卡片、间隔、双方环节时以 `--ease-out` 随轨道熄灭）。
- **铃**：单方与半区里，色带上下两条边各发出一道赭线（带 1px 米色晕）向墙面推开并淡出，提示铃 6cqh、终止铃 8cqh，1100ms `ease-out`；线从字形外侧出发、只往外走。间隔没有色带，仍是椭圆，赭色带晕，停在 1.25。
- **提示冒号**：色带外赭 `#744B0D`，色带上淡金 `#F4D79A`。
- **超时**：轨道当帧变金，上面一层浅色盖子从席位向远端收拢（560ms `--ease-out`），金色像从色带收尽的席位铺回；数字保持墨色（`--over-ink`）；离开超时 300ms 退回。
- **换边**：等待方按颜色变暗：色带随 `--dim` 逐帧混向旧滤镜算出的颜色（`#5C2A27` / `#283A51`），数字与冒号以同一条 520ms `--ease-out` 过渡到 `#BFBEBC` / `#111213`；`--field-ground` 如实写出这个混色。
- 「暂停」「时间到」「已放弃」改为墨色（原先米色字落在光地上 1.1:1）；自由辩里「暂停」挂在轨道下方。

**静态画面**：`cross` 的提示冒号改赭；`dual`、`seat-right` 只有「正方 / 反方」两个小标签的抗锯齿差（去掉滤镜层的代价）；`dual-locked` ≤1 级；其余六张逐像素相同。

### 2.3 绿幕 `chroma`（`bc3ae25`、`6efaa8a`、`75bef1e`）

**立意**：直播包装的底板。抠像台只认键色与实色：底板由键色遮罩上场，从不改透明度；金色只在底板里面，离外沿至少 `--plate-rim`（.4cqh）。

- **入场**：键色遮罩（伪元素的 `scaleX`，合成器画）从底板挂靠的边收走：环节名从左（420ms），数字底板从发言方席位（140ms 起 420ms），自由辩每一半从外侧（560ms），卡片与间隔从中间；时钟与队名条只平移上浮（`cr-rise`）；标题 100ms、发言人 170ms 起浮入，先底板后字。
- **顶栏**：进自由辩时留在原位、向中间合拢（多边形裁切 320ms），出来时张开（360ms）。
- **换边**：等待方底板颜色随 `--dim` 520ms 向底板色退 45%；发言方的金色地线画在两层底板的下沿内，从中间展开。
- **铃**：通用波纹不画，铃是底板内圈的金边（`--rim-w` .6cqh）。提示铃从时间边缘（底板上本方色的尽头）横向打开成整圈再冷却（`cr-ignite` 1100ms）；单方终止铃是闭合的整圈闪两下（`cr-flash-twice` 1420ms，第二下在 320ms，第二圈不画）；一方用完闪一下（1100ms）。
- **超时**：数字不动、变金；第二声铃时「+」带一块底板从主底板左沿抽出（`cr-tab-out` 300ms，从 320ms 起），那块的金边与主环同一动画；620ms 起「+」按颜色呼吸。一开就在超时里的环节没有铃，「+」块随遮罩一起露出。4:3 / 5:4 上分钟到两位时，「+」回到排版内，它自己的底板块与金边隐藏，主底板随整行变宽。
- **锁定**：底板保持数字大小，颜色随 `--remain` 流干成暗底板，字落在底板上。**暂停**：「暂停」是实色暗标签，从底板下沿放下、带着字收回（200ms 裁切）。提示条也是底板，金线收进底板。只用一层数字，不裁切。

**静态画面**：`over`（数字居中，「+」在左侧自己的底板块里）、`dual` / `seat-right`（地线移进底板下沿）、`dual-locked`（数字大小的暗底板，字居中）有变化，其余相同。

### 2.4 星轨 `startrail`（`18b13e8`）

**立意**：一张长曝光照片。换环节是快门合上、新的一次曝光打开；换边是两扇窗在同一片固定的天空上移动；终止铃是亮星在底片上过曝的一下。

- **换环节**：画布第 0 帧归零（快门），40ms 后 560ms 淡入到实时值（画师已画好新天空）；星云不再被直边横扫，而是从席位处的光心绽开（opacity 0、scale .8 → 实时值，560ms `--ease-out`）；时间线整条从席位外滑入，头点在前、不拉伸。只动合成器已有图层的 opacity、scale、translate：入场的光栅 CPU 从约 1500 降到约 450ms（1920×1080，软件光栅）。
- **霾**：正方、反方、城镇三层常驻（`.dt-backdrop::before` / `::after` 与舞台自己的 `::after`），按 `data-side` 交叉淡化 520ms，换边与换环节是同一条规则。
- **换边**：两片天空的接缝逐帧跟着分界线走（包括过冲与反向缩短）：画师读 `.dt-halves` 上 `grid-template-columns` 过渡本身的缓动进度与起点，每个画师帧只复制接缝扫过的一条；实测每个画师帧与分界线相差 ≤1px。每一半的星云固定为发言列宽（58cqw）、锚在本方席位，列只是看它的窗口，不再拉伸、滑动、逐帧重新栅格化。
- **提示铃**：流星不变（900ms），从数字之下穿过，轨迹高于字形顶线，半区里被分界线裁切。
- **终止铃**：数字之下一团金色辉光涨起又熄灭（1100ms，scale .9 → `min(1.45, --ring-to)`），单方两次；一方用完一次，600ms，与弹簧、星云熄灭一同结束。金色数字对它最低 4.31:1。
- **一方用完 / 放弃**：那一侧的星云从当前值 520ms 淡到 0。
- **卡片**：开场卡、结束卡的两片半边天空在中线 10% 宽的带里交叉溶入，只画一次，带外逐像素不变；结束卡的画布从 0 淡到 .5。
- 与定稿的一处偏离：自由辩半区的星云从本方席位的边缘绽开（`transform-origin: 0 56%` / `100% 56%`），不从光心——以光心为原点时，盒子外沿在屏幕边缘内 3–12px 处画出一道直线。

**静态画面**：`dual`、`dual-idle`、`seat-right`（等待方星云固定在天上）；`title`、`end` 只在中线带内；其余五张逐字节相同。

### 2.5 黑板 `chalk`（`587122f`）

**立意**：板前那只手。每个时刻是手在黑板上做的一件事；没有东西会长大，没有笔画被直尺切开；粉笔滤镜画出的东西只画一次。

- **计时中**：按 §1.4 改写：图片都字面写在用到它的盒子上（板灰在 `.dt-backdrop` 自己的 `::before` / `::after`，`--backdrop` 只剩光），与图片同列的平涂带和渐隐改成 SVG 图；滤镜画出的东西各自成层（`will-change: opacity`，left / top 定位），只裁切或遮罩它们的父元素。1920×1080 软件光栅、4 秒：单方 56 → 209 帧（席位在左）、51 → 214（在右），自由辩 76 → 200；排线的 36 块瓦片、板的 80 块只画一次。
- **换环节**：一道与笔画平行、上端领先、带参差的前沿从席位排进来（父元素上的多边形裁切，由注册的 `--chalk-in` 驱动，560ms，与共享横扫同一曲线）；灰雾、粉尘、勾下的擦净圆斑在同一前沿下出现，勾随后淡入；自由辩两半各从外侧排进。
- **换边**：每一半画两套同样的线（第二套错开半个线距），线盒固定（最宽的列加出头，锚在席位）。发言方两套都显示，等待方只留第一套 .63 / .62（旧的淡色，用不透明度），开局第二套 .4；只有这些不透明度随弹簧 520ms 变化，没有一笔移动或重画。
- **提示铃**：板擦从远端向席位把勾抹掉（420ms 裁切，`--chalk-wipe`）；勾下的圆斑改为无滤镜的颗粒遮罩，随板擦边裁切，没有排线重新冒出来；数字下方一道黄粉笔线划出（264ms 内），1100ms 散成灰。间隔的两声终止铃各划一道线。
- **终止铃**：第一声是板擦的最后一遍，30% 的重灰从远端扫到席位（600ms），前方仍是平时的灰；第二声绕数字逆时针画圈（父元素上的 conic 遮罩，320ms 起 780ms），从顶部偏右起笔。圈左移半个「+」宽，圈住「+0:07」，4:3 下只移到贴边。单方终止与一方用完时不画共享波纹。
- **一方用完**：「时间到」「已放弃」用粉笔滤镜写，不放波纹。

**静态画面**：`single`、`cross`（勾下圆斑，擦除边那一列像素）、`over`（圈左移）、`dual` / `seat-right` / `dual-idle`（两套线）、`dual-locked`（粉笔字）、开赛页缩略图（47px 的圆斑）。

### 2.6 墨 `ink`（按定稿）

**立意**：发言权是一笔水墨。每个时刻是毛笔的一个动作：落笔、提笔与按笔、洇开、钤印、一笔画圆。笔刷滤镜很贵，所以墨只画一次，动的都是合成层。

- **结构**：笔刷滤镜挪到色场的 `::before`，色场自己只管位置、裁切和动作。
- **换环节**：笔触第一帧就整道画好，上面盖一张同样的纸（舞台的 `::after`，z 6，在文字之上、提示条之下），纸的遮罩边缘是笔锋，从席位揭开（`--ink-lay: cubic-bezier(.45,.25,.4,1)`），数字也在纸下、随墨露出；自由辩每一半一张（`.dt-half::after`），两道笔同时从各自席位落笔，发言方的地线随后写出（320ms，从 240ms 起）。
- **换边**：先提笔：让出方 260ms（`--ink-lift`）变淡（场的不透明度 1 → .42，淡墨是同一墨色的透明度）、变细（高度 ×.7）；再按笔：拿到方 220ms 起 300ms 压实。半区笔触按发言列宽固定尺寸、锚在席位，随注册的 `--ink-col` 在分界线同一条弹簧上 `scaleX`，不重画。数字、晕边、冒号在下面那道墨「两种字色同样清楚」的一刻一步换色（让出方 130ms、拿到方 260ms），全程对比度 ≥ 3.67:1（原先最低 1.06:1）。
- **地线**：发言方墨色的一道干笔（锥形、飞白），从本方席位写出（300ms，从 220ms 起），随提笔收回（260ms）。
- **铃**：墨在湿纸上洇开的一圈不规整水线（滤镜在 `::before` 上画一次，环只做 scale 与 opacity），扩到 `min(1.35, --ring-to)`；终止铃第二圈转 7°、扩到 1.5、更淡。
- **超时**：`--over-ink` 设为赭金；「超时」朱文印在第二声铃上按下（`dt-stamp`，只在非静帧挂动画）。
- **锁定 / 放弃**：笔触在原处 300ms 淡出，`--remain` 等淡完再一步归零（共享的 520ms 排空会让笔刷逐帧重画）。
- **间隔**：圆相随入场一笔画成（conic 遮罩，注册 `--ink-enso`，700ms，从 140ms 起）；逐帧重画有界，明知而接受。
- **数字的晕边**从层上移到每个字形上，冒号呼吸时只重做它自己：1366×768 软件光栅计时中 32 → 58fps。
- 一致性审查把定稿的入场 600ms、铃 1300ms、印的 `both` 统一为 560ms、1100ms、`backwards`，与其余主题同一家族。

**静态画面**：`cross`、`break` 2px，`over` 305px（晕边，≤2 级）；`dual`、`seat-right` 约 8 万像素（半区笔触按列宽缩放、淡墨改透明度、干笔地线）；`dual-idle` 约 22 万；`dual-locked` 约 8 千（地线）。

### 2.7 构成 `construct`（按定稿）

**立意**：一台几何机器。零件只绕毂转、沿自己的直线滑；新的标记都在数字之下，落在毂与刻度上。

- **换环节**：扇形从轴线张开（保留）；毂从席位边缘外推入（半径 6.5 → 15cqh，双方 10cqh，注册 `--construct-hub`），560ms；刻度与外沿 160ms 起 300ms 淡入；色带沿自己的对角线从舞台下沿外滑上来（720ms `cubic-bezier(.45,0,.2,1)`），从张开的扇形下面穿出；大号序号随标题浮起。开场卡的两个大圆盘从各自席位外长出（560ms，注册 `--construct-disc`）。
- **计时中**：扇形角度改由 `--secs / --secs-total` 算，每秒一格、与数字同帧跳变、不缓动；两条边柔化 `min(.1°, 角度 / 2)`，角度为 0 时没有软边。
- **提示铃**：不再有绕数字的椭圆。毂亮黄后褪回本方色（900ms `ease-out`），约 130ms 后外沿刻度亮黄、1100ms 内褪去；只是两块小标记的不透明度，表盘不重画。键在 `data-bell` 与 `data-bell-clock` 上。
- **终止铃**：t=0 毂亮黄；色带当帧是黄色，上面一块混凝土色的盖子沿色带退到场外（560ms `linear`），黄色像从地面一端爬上去，约 320ms 爬出舞台；t=320ms 刻度的黄标记 300ms 淡入，620ms 时刻度本身翻黄。键在 `[data-phase="over"][data-bell="end"][data-bell-clock="main"]`，静帧直接是黄色。
- **换边**：两个表盘画在舞台宽的固定底板上（`width: 100cqw`，锚在本方外侧边缘），只被半区裁切；发言方半径仍随弹簧 74 → 98cqh。
- **一方用完**：该半区里同样的毂与刻度标记，随半区缩小变暗；**放弃**：扇形 520ms 转回轴线（锁定半区上 `--construct-sweep` 的过渡）。

**静态画面**：只有扇形两条边的软边（`single` 291px、`cross` 1667px）与自由辩 ≤8 级的取整差；`title`、`over`、`break`、`end` 不变。

### 2.8 孔版 `riso`（按定稿）

**立意**：一张社团海报从两只滚筒的孔版机里印出来：走纸、两次过版、褪色、滑版、盖印、揭墨。`contrast(14)` 之下的网点只印一次；油墨不半透明。

- **换环节**：网点以滚筒的匀速从席位印入（共享横扫的关键帧，曲线换成 560ms `linear`，边不在最后一截网点上爬）；字分两次过版：先印本方油墨的一道边，130ms 后套印的字身与另一种油墨的边落下（标题 130ms、数字 270ms 起，各 160ms，注册 `--riso-pass`）。开场卡与间隔的两个圆盘先正方、130ms 后反方浮起（各 360ms）。
- **换边**：让出的海报随 `--dim` 褪色（油墨 100% → 46%，套印距离 .4 → .22cqh），520ms；右侧海报的网点与颗粒锚在右缘（席位），分界线弹动时不滑；自由辩舞台名的红蓝两边钉在席位，不随换边对调。
- **铃**：两鼓印出的圈：本方油墨与套印两道实色线错开一个套印距离，1.15 → 1.65 扩开，线条分五步揭薄（1100ms `step-end`），全程不透明；油墨按 ring 的 `data-side` 取。冒号的两道套印边随颜色 300ms（提示铃）、随不透明度 200ms（暂停）收放；停下的冒号是实心（`--colon-rest: 1`）。
- **超时**（按 `data-phase` 键控，不按 `data-bell`，避开投影窗口先到状态、后到铃的竞态）：第二只滚筒 450ms 滑开（套印距离 .4 → 1.5cqh）；「超时」块在第二声铃上盖下（`dt-stamp … backwards`）；席位的残留网点保持到 320ms 再一步印满。
- **放弃**：海报在原处 300ms 揭起，`--remain` 揭完再一步归零。

**静态画面**：`dual`、`dual-idle`、`seat-right` 右侧海报的网点相位（改从右缘铺）；`seat-right` 舞台名两色边对调（标题区 2298px）；其余逐像素不变。

## 4. 工具

**`timer/tests/frames.py`**（`1f64b78` 新增；`6dd472e`、`f28648b` 修正）：把一个主题的一个时刻录成逐帧 PNG。

```
python timer/tests/frames.py --theme hall                                    # 入场：单方环节扫入，16 帧、每 50ms 一帧
python timer/tests/frames.py --theme ink --demo dual --skip 1200 --key KeyL  # 入场结束后，自由辩换边
python timer/tests/frames.py --theme hall --skip 76500 --count 24 --step 60  # 提示铃（single 还剩 30 秒时）
```

- 打开不冻结的 `?demo=<名字>&theme=<id>`，用 DevTools 的虚拟时间把页面时钟停住；`--skip` 把时钟拨快若干毫秒，`--key` 再按一个键，然后每隔 `--step` 毫秒（页面时间）截一帧，共 `--count` 帧，存到 `timer/tests/out/frames/<W>x<H>/<id>/<名字>[-<键>][-skip<毫秒>]/NNN.png`。装了 ffmpeg 时旁边还有 `sheet.png`：每行四帧、按时间顺序、最宽 2400px 的拼图，一眼看出一个时刻里各部件的先后。终端每帧一行：时间、`data-phase`、`data-side`、`data-kind`、是否还在入场、活动的动画数。
- 无头 Chromium 的 Web Animations 时间线不受虚拟时间管，所以脚本把时间线放慢到几乎停止，每帧之前把每个动画与过渡拨到它的虚拟年龄；有画师的主题先在真实时间里呈现一次画布，否则第一次虚拟时间下的截图约三次里卡一次。
- **`--size` 是页面（投影）的大小**（`f28648b`）：录制时用 `Emulation.setDeviceMetricsOverride` 把页面设成 W×H。原先它设的是窗口，无头窗口自带的边框（`--no-sandbox` 时还有一条信息栏）占去 87px 以上，1024×768 实际录到约 1024×629–681 的页面，4:3 的判断偏乐观，出了真 4:3 舞台的「+」也照样在画面里。
- **`--skip` 之后先落座**（`6dd472e`）：拨快之后、按键之前，把每个动画拨到它的年龄并让已结束的离场。原先页面加载时开始的过渡在 `--skip` 之后仍停在起点，紧接着录的换环节从一个永远不会出现的画面开始（底色已是新色，色场还没有）。
- 引擎丢掉 1.5s 前越过的铃，所以 `--skip` 要停在铃点之前，让某一帧跨过它。录换边或锁定时用 `--skip 1200`：`.is-entering` 留 1100ms，期间锁定的过渡被门控。

**`timer/tests/screenshots.py` 不变**，这样新旧静帧可以互相比较。它的 `--size` 仍是窗口大小：1366×768 的静帧里是 1366×680 的舞台加上约 88px 的页面底色。所有基线都是这样拍的，彼此比较有效；判断真实比例（4:3、5:4 出屏与否）要用 `frames.py`。

## 5. 验收

1. **测试**：`python timer/tests/run_js_tests.py` 共 467 条浏览器测试，除「theme construct: the top bar is set in upright columns against the edges」一条外全过；那一条在 Linux 容器里因缺 Windows 字体、字形度量不对而失败，与动效无关。`ui: one frame that throws does not stop the frame loop` 在负载重的全量运行里仍会偶发失败（`674be51` 已把等待放宽到 3s；单独重跑通过）。墨、构成、孔版按定稿各自的主题测试由 17、17、19 条变为 28、25、26 条。`python -m unittest discover -s timer/tests -p "test_*.py"` 共 38 条（`test_build` 28、`test_export` 1、`test_keyboard` 9），`build.py --check` 通过。新写或改写的主题测试大多核对过能失败（换回旧样式，或做它守着的那个变异，见各提交说明）；共享层的每个钩子都有测试。
2. **静帧**：每个主题改动前后各用 `screenshots.py --theme <id> --size 1366x768` 拍十个场景（`title single cross over dual dual-locked dual-idle break end seat-right`），与共享层改动之后的基线逐像素比较（部分主题另比 1920×1080）。差异只出现在 §2 各节「静态画面」声明的地方，每一处都对应审计条目或共享层带来的碰撞。共享层自己声明的变化：`over` 里数字整体居中、「+」悬在左侧；`dual-locked` 里状态字居中盖在原数字处；`single`、`cross` 的色边可能移动不到 1px（1/2000 量化）。墨、构成、孔版合并后重拍一套基线。
3. **冻结静帧的保证**：一次性动画只有 `from` 帧，冻结规则（`transition: none`、`animation-delay: -10s`、暂停）让它停在实时值上；入场期才有的层（堂、昼的旧色场，墨的纸，绿幕的遮罩，墨的圆相遮罩）挂在 `:not([data-still])` 下或只在 `.is-entering` 里；`data-bell`、`data-locking` 由计时器设置，冻结演示与缩略图里不会出现；这次没有新增循环。规则覆盖舞台自己的 `::before` / `::after`。
4. **减少动态的保证**：舞台及其所有后代、舞台自己的伪元素上，动画与过渡全部关掉；`pulse()` 直接返回，没有波纹，也不设 `data-bell`；画师只画静态帧。画面一步到终态，颜色与数值的变化照常（冒号变金、超时变色、等待方变暗、余量）。墨另把两处入场遮片 `display: none !important`。孔版运行中的冒号显示为 1（它的 `--colon-rest`）。
5. **缩略图**：带 `data-still`，没有入场、波纹、提示条，画师只画一帧。
6. **每个时刻都录帧看过**：入场、提示铃、终止铃、换边、一方用完、放弃、暂停、卡片，各主题前后对照（`frames.py`）。
7. **弱机**：没有新增的常驻逐帧工作；性能在 `--disable-gpu --disable-gpu-compositing` 下实测，数字见 §2 各节。

**未了的事**

- **经 `var()` 的图片、与渐变同列的图片**违反 §1.4 的第 1、2 条，计时中每一步整盒重画。星轨的星云遮罩（`--nebula`）已在 `5892232` 改为两张字面写出的 url() 图、渐变换成 SVG 图（1080p 计时 4 秒里 1751 块瓦片 → 115 块，每帧光栅 129ms → 17ms，静帧逐像素不变）。墨、孔版定稿的 `--backdrop`（纸的图片、套准标与颗粒加渐变）同样违反；以合并时的实现为准，未改的随后补，改后静帧应逐像素不变。孔版网点 `.dt-field::before`（经 `var()` 的图片加坡度渐变，在 `contrast(14)` 下）要核对重画是否只来自 .0025 的量化台阶。
- **`screenshots.py` 拍的是窗口**，不是页面（§4）；改成页面大小以后要重拍全部基线。
- **绿幕在 5:4**（1280×1024）上，即使 +0:07，「+」的底板块也伸出舞台左缘约 14px。绿幕按 16:9 抠像，暂作非目标。
- **构成的投影窗口竞态**：色带盖子与刻度标记按 `data-bell` 键控；投影窗口先收到超时状态、后收到铃时，色带第一帧是黄色，随后被盖子盖回再爬一次。孔版因此选了按阶段键控；构成接受。

**各主题的推迟**（理由都是在可读、弱机或克制上要付代价；触发条件在各主题定稿里）

- 堂：提示铃线「一闪而熄」；只留一层数字；等待方按颜色变暗（软件光栅 1080p 换边约 25 → 60fps，但改动所有双方静帧的抗锯齿）；首次挂载时底色由黛淡入沉色。
- 昼：单方 → 双方时旧色带被半区挡住；提示后呼吸变浅（需要共享的 `--breathe-low`）；首次挂载时轨道淡入。
- 绿幕：真正的 take out（等离场节拍）；挂载时的「上线」；更粗的金边（要与「+」块出自同一个盒子）；本方色「倒入」；撤销跨过零时「+」块一帧消失；操作台的状态药丸（`console.css` 的 `.dt-pill`）以透明度淡入、叠在被抠像的舞台上；`cr-flash-twice` 的 22.5% × 1420ms = 320ms 与 `RING_GAP_MS`、1420 < `RING_MS` 是硬编码的耦合。
- 星轨：入场时星轨从点「回放」到当前弧长；提示铃时金星闪亮；四角星芒（横芒紧贴「+0:00」读作「−」）；换边期间解除 30fps 上限；霾缩成小盒子。
- 黑板：换边时数字用 `scale` 缩放、结束时一次落定字号（等换边节拍）；分界线与竖线画出、「暂停」写出；地线 `scaleX` 拉伸颗粒；换环节时新排线整层重画一次（1080p 软件光栅约 300–400ms）；m 档（舞台宽 520–1100px）颗粒频率正好 2.0 周 / 像素；4:3 上画圈的头半秒遮住残段粉尘；超过约 5.4 分钟的单方环节勾的圆斑伸进残段。
- 墨：1080p 软件光栅下计时中 2–4fps（笔触每 .2cqw 一步整道重画，与动效无关；目标机多有 GPU 光栅）；换环节的首帧约 600ms；落笔时的湿墨笔头；开场卡的竖笔写出；印泥洇开；入场期间锁定时数字 240ms 退出（未门控，无害）。
- 构成：每秒一格加 120ms 缓出（软件光栅下整段发言掉约五分之一的帧）；开场卡圆盘收拢成第一个环节的毂、结束卡另一侧的毂长出（等离场节拍）；同侧换环节时色带不动；表盘绕毂 `scale`（完整 K10）。
- 孔版：换边时网点层固定栅格加合成层（软件合成下反而更慢，1080p 35–40 → 20fps）；旧海报留住被新海报盖过；圈加纸纹针孔；运行中的冒号在呼吸低点沉进网点（需要 `--breathe-low`）。
