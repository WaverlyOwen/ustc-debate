# 计时器：主题动画完善 设计文档

日期：2026-10-05　分支：`feature/debate-timer`　基于此前三份计时器规格（主规格 §5.5 的动画表仍是基线）

## 0. 要做什么

用户：「完善一下水墨那个主题的动画，以及其他主题的动画做一次完善。」

现状：墨、黑板、孔版没有一个专属动画，全部沿用「堂」的横扫 / 上浮 / 波纹；星轨只有流星，构成只有扇形展开。结果是每个主题静止时各有面貌，一动起来就都一样。

目标：**每个主题有自己的动作语言，从它的立意里长出来**，墨做得最深。动画仍然只在有意义的时刻出现（主规格 §5.5 的原则：一个编排好的入场，其余是对操作和铃点的回应），不加无意义的循环。

## 1. 动作时刻（所有主题共用的词表）

| 时刻 | 触发 | 说明 |
|---|---|---|
| `enter` | 换环节、开场卡进入第一个环节 | 唯一编排好的大动作 |
| `start` / `pause` | 开始、暂停、继续 | 小回应 |
| `warn` | 越过提示铃点 | 一次 |
| `count` | 逐秒倒数每一秒 | 很小 |
| `end` | 单方到 0、间隔到 0、双方一方耗尽 | 一次 |
| `over` | 单方进入超时后的持续状态 | 缓慢，可循环（≤ 0.5Hz） |
| `switch` | 双方环节发言权换手 | 中等 |
| `lock` | 双方一方用完或放弃 | 一次 |
| `title` | 开场卡 / 结束卡 / 间隔环节的静场 | 可有极缓的环境动作 |

### 1.1 渲染器接口（新增）

- `render.js` 从 `tick` 事件与视图前后差异推出上表的时刻（`start`/`pause` 由 `running` 变化，`lock` 由 `locked` 变化，`over` 由 `phase` 进入 `over`，其余来自 `pulse`），统一走 `moment(name, detail)`
- 每个时刻在 `.dt-stage` 上**重放**一个类 `is-m-<name>`（先移除、强制回流、再加），在 `--moment-ms`（主题可设，默认 1200ms）后移除；`detail` 里的方位（`side`、`clock`）写到 `data-m-side`。主题 CSS 用 `[data-theme="x"].is-m-warn …` 这样的选择器编排
- 主题 JS 可选新钩子 `decorate(stageEl, {thumbnail, reducedMotion, frozen}) → { update?(view), moment?(name, detail), destroy?() }`：挂载时调用一次，用来插入主题自己的 DOM（印章、圆相 SVG、粉笔灰粒子……），并在时刻发生时用 JS 驱动（例如 SVG 的 `beginElement()`、`stroke-dashoffset`）。画师也可选 `moment(name, detail)`
- 缩略图、`frozen`、reduced-motion 下：不重放时刻类，`decorate` 的 `moment` 不调用，元素直接处于终态
- 现有的 `pulse` 波纹仍保留为默认；主题可以用 CSS 把 `.dt-ring` 隐藏，换成自己的表达

### 1.2 动作的硬约束

- 时长 150–1200ms（`over` 与 `title` 的环境动作除外）；曲线写明（不准用浏览器默认 `ease`）
- 只动 `transform`、`opacity`、`clip-path`、`mask-position`、`stroke-dashoffset` 与 CSS 变量；**不准持续动画 SVG 滤镜或 `filter: blur()`**（一次性的、≤ 600ms 的滤镜过渡可以）
- 动画期间数字始终清楚可读：任何遮罩、粒子都在数字之下，或不覆盖数字区域
- reduced-motion：全部直接到终态，`over` 不呼吸，环境动作停止
- 1920×1080 无头 Edge 下，每个时刻动画期间的帧耗时 p95 ≤ 20ms（动作取样工具测量）

## 2. 每个主题的动作语言

下面是必须实现的编排；具体数值在动作取样图里调到好看为止。

### 2.1 墨 `ink`（做得最深）

运笔的「起—行—收」，墨的「落—洇—干」。

- **enter**：笔从本方席位一侧落下。① 起笔：席位一侧边缘先出现一团浓墨（≈120ms，缩放 0.7→1，不透明度 0→1）；② 行笔：笔触沿水平方向推出去，速度先快后慢（≈520ms，`cubic-bezier(.16,.84,.24,1)`），推进的前沿是**飞白**（前沿 6–10% 宽度用遮罩渐变做出拉丝的半透明）；③ 收笔：到位后墨「洇开」：边缘晕染从无到有（一次性，≈400ms）。标题随后由淡墨渗成浓墨（不透明度 + 极轻的模糊到清晰，≈360ms），左上角印章**按下**：从 1.12 倍、略微旋转落到原位，印泥色在落下瞬间加深一次
- **start / pause**：继续时笔触前沿轻轻一顿（前沿飞白闪现一次）；暂停时数字下的「暂停」以淡墨渗出
- **warn**：墨点处**一滴墨落下**：从上方 ≈8vh 处落下（≈260ms，加速），触纸后扩散成一圈淡墨晕（≈700ms，缩放 0.2→1.6，不透明度 0.7→0）。不画金色波纹
- **count**：每秒数字下方一圈极淡的墨晕（≈300ms），数字本身不跳
- **end**：最后一截笔触变成**枯笔**收尽（飞白拉丝散开消失，≈500ms），随后一枚朱文印章「时」**盖**在数字右下（按下动画同上）
- **over**：数字转金（现有），印章外缘的印泥极缓慢地洇（2.4s 周期，幅度很小）
- **switch**：**提笔—落笔**：当前一方的笔触淡成半透明并略微收缩（提笔，≈240ms），对方从自己的席位一侧重新落笔（enter 的笔触部分，压缩到 ≈420ms）
- **lock**：用完或放弃的一方笔触褪成淡灰墨（去饱和 + 不透明度，≈600ms），盖一枚小印「止」
- **title**：开场卡与间隔环节的中央，**圆相**（一笔画成的圆，SVG path）用 `stroke-dashoffset` 画出（≈1.4s，起笔重、收笔轻，收笔处留一个缺口）；间隔环节里圆相随倒计时被一点点淡去
- 印章、圆相、墨滴都由 `ink.js` 的 `decorate` 生成（SVG / DOM），不用图片

### 2.2 星轨 `startrail`

快门与曝光。

- **enter**：**快门打开**：天空从近黑亮起（≈600ms），星轨从点快速生长到当前弧长（快进 ≈700ms，ease-out），像一次缩时
- **start / pause**：暂停时星轨停止生长，画面亮度降一档（快门半闭）；继续时恢复
- **warn**：流星（现有）——改进为带渐隐尾迹、从发言方一侧的天空划向数字上方，一次
- **count**：离数字最近的一颗亮星每秒闪烁一次
- **end**：**快门关闭**：星轨定格、整体亮度降一档，地平线上天文台的狭缝灯熄灭
- **over**：天空极缓地泛起一点该方色温的辉光（2s 周期）
- **switch**：发言方的天极开始转动、另一方停止；两种色温在 ≈500ms 内交叉渐变
- **lock**：用完一方的星轨褪成冷灰
- **title**：整片天空以极慢的速度旋转（肉眼刚能察觉）；间隔环节银河缓慢漂移

### 2.3 黑板 `chalk`

书写与擦除。

- **enter**：粉笔排线**一组一组画出来**（分 8–12 组，按顺序错开 ≈40ms，每组用遮罩从上到下「写」出，总长 ≤ 700ms），几粒粉笔灰从笔触处落下淡出；标题（楷体）**逐字写出**（每字错开 ≈50ms，不透明度 + 极小位移）
- **start / pause**：暂停时板擦停在收回边缘（显示一个淡淡的板擦痕）
- **warn**：粉笔勾 ✓ **画出**（`stroke-dashoffset`，≈350ms），随后一小团粉笔灰扬起淡出
- **count**：每秒数字像被粉笔「点」了一下（下方出现一个粉笔点并淡出）
- **end**：老师用黄粉笔在数字外**画一个圈**（`stroke-dashoffset`，≈600ms，略不规则，首尾不完全闭合）
- **over**：黄圈旁的粉笔灰极缓地飘
- **switch**：中间那条粉笔竖线被**重描**一遍（≈300ms），发言方的排线加密
- **lock**：用完一方的排线被擦淡
- **title**：辩题像板书一样逐字写出（只在进入开场卡时一次）

### 2.4 孔版 `riso`

印刷过版。

- **enter**：**两色依次过版**：第一色（本方油墨）的网点层像纸过滚筒一样从席位一侧滑入（≈380ms），第二色随后叠上；数字的套印偏移从大（≈14px）收敛到最终的 3–5px（带一点回弹，≈500ms）
- **start / pause**：暂停时套印偏移略微变大（像机器停下来没对准）
- **warn**：套准十字标闪一下，所有套印偏移晃一下再归位
- **count**：每秒网点「跳」一档（尺寸一次性缩一级）
- **end**：一行「时间到」用另一色油墨**斜着印**上去（盖印动画，multiply 混合，不遮挡数字主体）
- **over**：纸张颗粒极缓地闪动
- **switch**：**换纸**：当前一张向下滑出（≈220ms），另一张向上滑入（≈320ms）
- **lock**：用完一方的油墨褪色，像印淡了
- **title**：辩题两色依次叠印

### 2.5 构成 `construct`

几何的展开与咬合。

- **enter**：网格线依次出现（错开 ≈20ms）→ 扇形从 0 展开到当前角度（现有，保留并统一曲线）→ 对角色带从屏外滑入 → 环节序号的描边**画出**
- **start / pause**：暂停时扇形边缘的刻度停住并变暗
- **warn**：黄色刻度闪一次，色带一闪而过
- **count**：扇形最外圈的刻度每秒「咔」一格（旋转一个刻度距离）
- **end**：扇形收尽时圆心圆环脉冲一次（几何闭合），色带变黄（现有）
- **over**：黄色色带缓慢呼吸
- **switch**：两个扇形一收一展、对向旋转
- **lock**：用完一方的扇形变为描边空心
- **title**：大圆与网格以极慢的速度相对旋转

### 2.6 堂、昼、绿幕

基线动画（主规格 §5.5）保留并打磨：
- 堂：横扫的前沿加一条极细的亮边（≈1px，随横扫移动后消失），让「收回」与「铺开」更像一块布被拉动
- 昼：色带入场改成从席位一侧伸出（而不是全屏横扫），提示波纹用深金色以保证亮底上的对比
- 绿幕：不做背景动画（直播抠像需要稳定背景），只有底板自身的伸缩与数字的回应；波纹换成底板边缘的一次闪亮

## 3. 动作取样工具

`timer/tests/motion.py`：

```
python timer/tests/motion.py --theme ink --moments enter,warn,count,end,switch,lock,title [--size 1920x1080] [--frames 10] [--slow 4]
```

- 用 DevTools 协议（把 `test_keyboard.py` 里的最小 CDP 客户端提取成共用模块 `timer/tests/cdp.py`，两个文件都用它）打开构建产物的演示态（`?demo=…&theme=…&test=1`），通过 `?test=1` 的测试钩子触发时刻（推进 `DT.clock`、调用控制器动作）
- `Animation.setPlaybackRate(1/slow)` 放慢全部 CSS 动画；Canvas 画师按同样的倍率推进（测试钩子提供）
- 每个时刻按等间隔截 `--frames` 帧（覆盖该时刻的完整时长），并用 `Performance` / rAF 时间戳记录帧耗时
- 输出 `timer/tests/out/motion/<主题>/<时刻>.png`：把各帧按时间排成一张**连拍图**（用一个本地 HTML 页面把帧平铺，再用无头 Edge 截图；不依赖 Pillow），每帧下标注时间；另输出 `summary.json`（每个时刻的帧耗时 p50 / p95）
- `--reduced` 用 `Emulation.setEmulatedMedia` 打开 `prefers-reduced-motion: reduce`，确认动画直接到终态
- 只结束自己启动的浏览器进程

## 4. 验收

1. 全部测试与 `build.py --check` 通过
2. 8 个主题的动作取样图逐张看过：每个主题的动作明显属于它自己，不能互换；墨的 enter、warn、end、switch、title 符合 §2.1
3. 动画期间数字始终可读；reduced-motion 下全部直接到终态
4. `summary.json` 中每个时刻帧耗时 p95 ≤ 20ms
