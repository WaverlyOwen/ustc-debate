## 2. 重置与退出

### 2.1 重置

- **当前环节**：已有的 R 连按两次保留。底部控制条加一个「重置」按钮（单屏模式下原来没有），操作台的「重置」按钮保留
- **任意环节**：环节列表（S 抽屉与操作台左栏）每一行，在这个环节有过计时（Run 存在且用时 > 0 或有锁定）时，行尾出现一个小的「重置」按钮（图标 ↺ + 文字提示「重置」，`aria-label="重置第 N 个环节"`）。点击后不跳转光标，只重置那一个环节
- **两步确认**：所有按钮式的危险操作（重置、退出）用同一个模式：第一次点击，按钮文字变成「再点一次重置」或「再点一次退出」（写出动作；环节列表行尾的 ↺ 还带上这一环节已记的用时，如「再点一次重置　✓ 2:57」）并高亮 1.5 秒；1.5 秒内再点才执行；移开或超时恢复。键盘上的 R R / Q Q 与之等价
  - 修订（2026-10-03 终审）：原文是「再点一次确认」，按钮换字后只能从位置看出是哪个动作，改为写出动作。高亮是实心的强调色底，文字对比度不低于 4.5:1；按钮在两种样子之间宽度不变；按住回车的自动重复不算第二次点击
- **引擎**：`reset(session, now, index?)` 增加可选的 `index`：省略时重置当前环节（现行为）；给出时重置那个环节。被重置的若是当前环节且在走，先停。可以 Z 撤销

### 2.2 退出

- **按键**：Q 连按两次（第一次提示「再按一次 Q 退出到开赛页，这一场会保留」）
- **按钮**：底部控制条与操作台控制栏各加一个「退出」按钮，两步确认
- **行为**：先暂停当前环节（结算用时，时钟不能在后台继续走），保存场次，然后：
  - 普通计时器 → 开赛页，顶部出现已有的「上一场还没打完」横幅，「继续」回到退出时的那个环节
  - 导出的专用文件 → 它的「继续上次 / 重新开始这一场」询问页
- **投影窗口**：操作台退出后，投影窗口显示这一场的**开场卡**（辩题与队名），不显示计时，不断开；操作台回到这一场时恢复同步
- 开场卡和结束卡上也能退出

## 3. 键盘修复（根因已用真实输入复现并证明）

调查用 Edge 的 DevTools 协议注入真实鼠标与键盘事件（脚本派发的事件不会触发浏览器默认行为，复现不了这些问题）。证明了的根因与修法：

| # | 根因 | 修法（在源头） |
|---|---|---|
| P1 | 音量滑块包在 `<label>` 里，点「音量」字样或滑块周围的空白会让滑块获得焦点；`isEditable` 把所有 `<input>` 都当成文本输入，于是全部快捷键失效，方向键改去调音量，直到点别处 | `isEditable` 只认文本类输入（`TEXTAREA`、`SELECT`、contenteditable，以及 type 不是 range/checkbox/radio/button/submit/reset/color/file 的 `INPUT`）；把包裹的 `<label>` 换成普通元素，输入框加 `aria-label="音量"`；删掉 `pointerup → blur` 的补丁 |
| P2 | `keepFocus`（鼠标点击不让按钮拿焦点）只用在控制条与操作台控制栏，没用在环节列表和覆盖层里；焦点留在行按钮上，回车会再点一次（跳回旧环节、执行被拒绝过的插入、再复制一次） | 把 `keepFocus` 用到操作台环节列表与每一个覆盖层容器 |
| P3 | 编辑器关闭动画的 260ms 内 `blocked()` 仍为真，按键被丢弃，背后的页面也仍是 `inert` | 编辑器在开始关闭时就通知（新回调 `onLeave`），ui 立即解除阻挡与 `inert`；`editor` 引用仍保留到 `onClose`，防止重入 |
| P4 | 操作台关闭后，投影窗口仍把按键发给已关闭的 `opener`，并吞掉按键 | 投影窗口发键前检查 `opener && !opener.closed`；断开时不发、不吞，并在投影窗口上显示提示「控制台已关闭。在主窗口按 O 重新连接」 |
| P5 | `--tension` 每帧写入并驱动 `font-variation-settings`，每帧整页重新排版；慢电脑上按键排队 30–180ms | `render.js` 把 tension 量化到 0.02，值不变就不写；主题里各自的量化删掉 |

两处体验调整（不是 bug，但会让人觉得「要按两次」）：

- **开场卡上按空格直接开始第一个环节**（之前只进入第一个环节，要再按一次才开始；开场卡上写的是「空格开始」，与行为不符）。第一个环节是自由辩一类的双方环节时，发言权给它的 `first` 一方。只想进入第一个环节而不开始，用 →。这修改了主规格 §3.2「光标在开场卡上：等同 next」
- **`e.code` 为空时用 `e.key` 兜底**：有的翻页笔或屏幕键盘不带扫描码，`code` 为空，现在会被忽略
