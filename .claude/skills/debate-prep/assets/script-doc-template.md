二级标题按赛制文件「各持方文稿标题」一节原样使用。成段讲稿分两类（`references/stage-playbooks.md` 第 0 节）：

- **定稿**只有正方一辩立论：完整成文，标题写 `（正文 NNN 字 / 180 秒）`
- **其余都是套件**：固定段 + 条件模块 + 临场位，标题写 `（套件 · 组装后 NNN–NNN 字 / T 秒）`，两个数字是最短与最长组装，照 `check_speeches.py` 的输出填

套件里任何一句断言台上发生了什么的话，都只能出现在条件保证它为真的模块里。每个选择组都有一个不断言场上事实的兜底模块。
