# 文档结构约定：写法决定排版

三类文档都是 Markdown，`scripts/md2pdf.py` 按下面的约定把它们排成有层次的 PDF。写文档时遵守这些约定，排版就会自动分层；不遵守，内容会被压成平铺的项目符号。

## 1. 标签项：一条项目 = 一个字段

以 `- **标签**：内容` 开头的项目符号列表，整列都这样写时，会被排成"左侧小标签、右侧内容"的字段行，而不是圆点列表。标签名决定排版角色：

| 标签 | 排版 |
|---|---|
| 主张、判准是什么、结论、辩题性质 | 引导句：字号放大、加重 |
| 机制 | 步骤：内容里的（1）（2）（3）或子级有序列表，排成带圆圈编号的步骤 |
| 学理、数据、案例、补充学理 | 证据卡：黑底类型标签 + 边框卡片，卡内按子标签分行 |
| 回扣判准 | 收束句：左侧色条 |
| 对方最强攻击 → 我方回应 | 攻防对：子项写成 `攻击：… → 回应：…`，排成左攻右回的双栏 |
| 正方有利定义 / 判准、反方有利定义 / 判准 | 持方卡：红或蓝的左色条，标题同色 |
| 中立定义 / 中立判准 | 中立卡：底色面板，定义正文加重 |
| 正方的定义杀陷阱 / 反方的定义杀陷阱、劣势方打法、优势方要防 | 持方卡 |
| 正方一句话立论 / 反方一句话立论 | 论纲：红蓝底色引语，结论速览里并排成两栏 |
| 论据核实 | 数字砖：`已核实 N 条 / 有把握 N 条 / 【待核实】N 条` 排成三块 |
| 时间表 | 时间轴：子项写成 `第 10–8 天：…`，左列时间、右列内容 |
| 含"背下来""清单"的标签 | 勾选框列表 |
| 其他标签 | 普通字段行 |

标签名要**原样**用上表里的写法，括号补充可以加在后面，如 `**机制**（三步）`。

## 2. 句内子标签：一个字段里的第二层

字段内容里出现下面这些词加冒号时，会从该处折行成"子标签 + 内容"，形成字段内部的第二层。可以加粗也可以不加粗：

有利之处、反方如何反驳它、正方如何反驳它、合理性、核心主张、支撑、边界、口头版、出处、来源、方法、主要发现、局限、代表性、贴合度、状态、正方需要证明、反方需要证明、自律口径、词典义、学术义、法规义、查证方向

另外任何 `**十四字以内的短语**：` 都会被当作子标签，所以不要把加粗强调词直接跟冒号。

`状态：` 后面的"已核实 / 有把握 / 【待核实】"会渲染成色块标记。

## 3. 表格里的固定词

单元格里只写下面这些词时，会渲染成色块：已核实、有把握、【待核实】；偏正、略偏正、偏反、略偏反、均衡；最终、淘汰、常见。

口径表（表头以"类别"开头且含"标准表述"）会按"类别"列自动分组，"禁止的说法"列用警示色。

## 4. 文稿

- 二级标题按赛制文件的写死格式，`（正文 NNN 字 / 180 秒）` 会拆成编号、名称、徽章三段
- 讲稿正文里的 `**加粗**` 渲染成着重号，不是粗体，所以每篇最多两处
- 稿末的 `**如果……就……**` 加项目符号会收进虚线备注框

## 5. 不要这样写

- 不要把整段分析塞进一个字段而不用子标签，那样仍然是一坨
- 不要用 `1. 2. 3.` 编号列表代替字段（除机制步骤外）
- 不要在字段之间混入无标签项目，混了整个列表会退回普通圆点
- 不要用四级标题分层，用字段和子标签
