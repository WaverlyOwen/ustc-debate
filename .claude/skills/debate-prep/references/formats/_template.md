# 新增赛制的模板

要为一个新的赛事新增赛制，复制本文件为 `references/formats/<赛制英文简称>.md`，按下面结构填写。填好后在 `SKILL.md` 输入表格「赛制」一行补一句说明，让模型知道用户提到这个赛事名称时该读哪个文件；`check_speeches.py --list-formats` 会自动列出它，`--format <简称>` 就能用。不需要改任何脚本。

用户贴出流程但没有给全信息（例如缺计时方式）时，先按常见规则推断并在文件中标注"待确认"，同时提醒用户向组委会核实。

---

# 赛制：<赛事名称>

适用：<哪个比赛、几对几、谁先立论、谁先结辩>。

## 流程总表

| 序 | 环节 | 时长 | 计时 | 发言人 | 打分块 |
|---|---|---|---|---|---|
| 1 | | | | | |

计时列填写：单方 / 双边计时 / 单边计时 / 各自计时。

## 计时方式说明

解释本赛制中每种计时方式的具体含义，以及对策略的影响（谁掌握节奏、能否打断、拖延是否有利）。

## 打分块与每块的胜负点

如果评委分段打分，列出每一块包含的环节以及我方在该块的目标。如果评委只打一次总分，说明这一点并给出"哪些环节权重最大"的判断。

## 各持方稿件清单（双方都要准备）

分正方、反方两份清单（双方都要准备），按环节顺序列出需要准备的稿件、提纲与防守预案。注意标出发言顺序带来的不对称（谁先谁后、谁有最后一发）。

## 时长与字数换算

按本赛制的各类时长给出字数区间。默认语速与两个中科大赛制相同：**每分钟 250–280 口播字**（只数汉字、数字、英文单词，不数标点），写稿瞄准中值。质询、盘问、对辩、自由辩给出问题数或发言点数而非字数。

`scripts/check_speeches.py` 直接读这一节的表，所以表要按下面的格式写，写错脚本会退回内置区间并提示：

| 时长 | 口播字数 | 备注 |
|---|---|---|
| 180 秒 | 750–840 字 | 立论稿 |
| 120 秒 | 500–560 字 | 驳论稿；若预留临场位，正文按 400–460 字写 |
| 90 秒 | 375–420 字 | 盘问小结；留临场位则正文按 300–340 字写 |
| 210 秒 | 875–980 字 | 反四结辩（不留临场位） |
| 210 秒（留 35 秒临场） | 730–815 字 | 正四结辩 |
| 120 秒 质询（双边） | 3 条问题链，共 6–10 个问题 | 每问不超过 25 字 |
| 90 秒 盘问（单边） | 2 条问题链，共 5–8 个问题 | |

规则：第一列写秒数；第二列写「低–高 字」；第三列的关键词决定这行是哪篇稿（立论 / 驳论 / 小结 / 反四结辩 / 正四结辩 / 奇袭申论），「临场位」后面的第二个区间是留临场位时的正文区间；问题链行在第二列写「N 条问题链，共 A–B 个问题」。也要同步复制「计数规则（唯一口径）」和「各持方文稿标题」两节，标题表里的每一行就是文稿 `\begin{speech}` / `\begin{stage}` 的两个参数。

## 本赛制的特别提醒

列出这个赛制特有的顺序陷阱、规则细节（例如是否允许打断、是否有观众提问、是否有结辩前的暂停）。
