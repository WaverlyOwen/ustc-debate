# 新增赛制的模板

要为一个新的赛事新增赛制，复制本文件为 `references/formats/<赛制英文简称>.md`，按下面结构填写。填好后在 `SKILL.md` 第二步的"默认赛制"附近补一行说明，让模型知道用户提到这个赛事名称时该读哪个文件。

用户贴出流程但没有给全信息（例如缺计时方式）时，先按常见规则推断并在文件中标注"待确认"，同时提醒用户向组委会核实。

---

# 赛制：<赛事名称>

适用：<哪个比赛、几对几、谁先立论、谁先结辩>。

## 流程总表

| 序 | 环节 | 时长 | 计时 | 发言人 | 打分块 |
|---|---|---|---|---|---|
| 1 | | | | | |

计时列填写：单方 / 双边计时 / 单边计时 / 各自计时。

## 计时方式说明

解释本赛制中每种计时方式的具体含义，以及对策略的影响（谁掌握节奏、能否打断、拖延是否有利）。

## 打分块与每块的胜负点

如果评委分段打分，列出每一块包含的环节以及我方在该块的目标。如果评委只打一次总分，说明这一点并给出"哪些环节权重最大"的判断。

## 我方持方对应的稿件清单

分正方、反方两份清单（双方都要准备），按环节顺序列出需要准备的稿件、提纲与防守预案。注意标出发言顺序带来的不对称（谁先谁后、谁有最后一发）。

## 时长与字数换算

按本赛制的各类时长给出字数区间。默认语速 220–250 字/分钟，留 10% 缓冲。质询、盘问、对辩、自由辩给出问题数或发言点数而非字数。

## 本赛制的特别提醒

列出这个赛制特有的顺序陷阱、规则细节（例如是否允许打断、是否有观众提问、是否有结辩前的暂停）。
