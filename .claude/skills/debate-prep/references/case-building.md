## 1. 辩题类型与对应框架

先判断类型，因为不同类型的"赢法"不一样。

| 类型 | 典型句式 | 双方在争什么 | 标准框架 |
|---|---|---|---|
| 事实判断 | "X 是 / 不是 Y""X 会 / 不会导致 Y" | 一个事实性或趋势性命题是否成立 | 定义 X 与 Y，给出判断"是不是"的标准，用机制推演与证据说明 |
| 价值比较 | "X 利大于弊 / 弊大于利""X 是好事 / 坏事" | 在某个衡量标准下的净效果 | 定义 → 判准（谁的利、比什么、时间尺度）→ 分层比较 |
| 政策题 | "应该 / 不应该实施某政策""X 该不该 Y" | 一项具体行动是否值得做 | 需根解损：需求性（有没有问题）、根属性（问题是否源于现状）、解决力（政策能否解决）、损益比（代价是否可接受）。正方要四项都立住，反方打掉任意一项即可 |
| 比较题 | "A 比 B 更 X""X 更需要 A 还是 B" | 两个对象在同一标准下的高下 | 定义 A、B、X，给出比较标准，逐层比较；注意"更"意味着承认对方也有 X，只是程度不同 |
| 应然/实然混合 | "当代青年更应该 X" | 既有事实前提又有价值主张 | 先确认事实前提（当代青年的处境），再在价值层比较 |

有些题目会被出题方刻意写得模糊，这时"辩题类型"本身就是第一个战场：把题目往对我方有利的类型上引，并在立论开头明确说出来。

## 2. 关键词拆解

把辩题中的每一个实词拿出来，逐个回答三个问题：

1. **常识含义**：普通人、评委听到这个词想到什么。远离常识的定义会被评委本能地排斥。
2. **争议空间**：这个词有哪些合理的不同理解，每种理解对哪一方有利。
3. **我方选择**：我方采用哪一种，为什么它既对我方有利又是合理的。

还要拆隐含要素：
- **主体**：谁在做这件事、谁受影响（"我们""青年""社会"分别指谁）
- **范围**：讨论的是当下中国、全球、还是抽象普遍情况
- **时间尺度**：短期还是长期，这一点经常决定利弊题的胜负
- **比较对象**：利大于弊是跟"没有 X"比，还是跟"X 的替代方案"比

写出来的成果是一张关键词表：词 / 常识含义 / 争议 / 我方解释 / 对方可能解释。

## 3. 定义策略

- **题解优先**：赛事方给了题解，题解里的定义与讨论范围是硬边界。违背题解的定义会被评委直接扣分，所以只在题解允许的空间里找有利解释。
- **合理优先于有利**：一个稍微没那么有利但评委一听就点头的定义，胜过一个极有利但需要花一分钟辩护的定义。立论只有 180 秒。
- **不做"定义杀"**：把对方的持方定义成不可能成立（比如把"成功"定义成"我方论点"），评委会认为这是逃避辩论。新生赛评委尤其反感。
- **定义要能承载论点**：定义写完，检查每个论点是否都能在这个定义下展开。
- **准备定义之争的口径**：如果对方定义与我方不同，准备一段 30 秒的话，说明为什么我方定义更贴近常识、更贴近题解、更能让讨论有意义。

## 4. 判准设计

判准（判断标准）是回答"评委凭什么判我方赢"的那句话。它是整个立论的枢纽。

好的判准满足：
- **与持方绑定**：在这个判准下，我方论点自然成立、对方论点自然不足。
- **可比较、可检验**：能落到具体的机制或现象上，而不是"看是否更有价值"这种空话。
- **能被一句话说清**：例如"我方判准是：X 是否让大多数普通人在长期来看拥有更多选择"。
- **不会反噬**：把对方最强论点放进来试一试，判准不能反而帮对方。

判准之争是高水平比赛的核心，也是新生赛最容易被忽视的部分。要准备：为什么我方判准比对方判准合理（更符合题目的语境、更照顾题目的主体、更能区分双方）；对方判准的问题在哪。

## 5. 论点设计

数量：两到三个。新生赛两个讲透优于三个讲浅。

结构：论点之间要**互相独立、层次分明**。常用的分层方式：
- 个人层 → 社会层
- 短期 → 长期
- 现象层 → 机制层 → 价值层
- 需根解损（政策题）

每个论点用四段写：
1. **主张**：一句话，就是这个论点要说的结论
2. **机制**：为什么会这样，中间的因果链是什么。机制讲清楚了，即便数据被质疑论点也还能站
3. **论据**：数据、案例、学理、常识中的一到两种，服务机制而不是替代机制
4. **回扣**：所以在我方判准下，这意味着什么

再给每个论点起一个**短标签**（四到八个字），用于场上互相呼应，如"选择变多""风险前置"。

## 6. 论据的类型与可信度

| 类型 | 优点 | 风险 | 使用建议 |
|---|---|---|---|
| 统计数据 | 直观、有说服力 | 最容易被质疑出处；编造会被当场打死 | 只用有把握的；不确定标注【待核实】并写明查证方向 |
| 研究结论 | 权威 | 常被过度概括 | 说清是相关还是因果、样本是谁 |
| 案例 | 生动、易记 | 个例不能代表整体 | 用于说明机制，不用于证明普遍性；准备"个例反驳"的回应 |
| 学理/理论 | 结构性强 | 评委未必熟悉 | 用一句话解释理论，不要堆术语 |
| 常识与类比 | 评委易接受 | 类比可被反类比 | 类比要在关键属性上对应 |
| 机制推演 | 不依赖外部证据 | 每一步都可能被打 | 链条不要超过三步 |

每一条论据都标注可信度：**已核实 / 有把握 / 【待核实】**。手册末尾汇总【待核实】清单。

## 7. 价值层

价值层回答"这道题为什么值得讨论、我方立场背后关心的是什么"。它放在立论结尾和结辩，用来让评委在情感上站到我方这边。要求：

- 从论点中自然长出来，不是另起炉灶的抒情
- 具体的价值优于抽象的口号："让一个普通人犯错之后还有第二次机会"胜过"人文关怀"
- 不与我方的定义、判准冲突

## 8. 替对方立论

替对方立论至少两个版本：

- **最常见版本**：对方最可能拿出来的框架，用于准备常规攻防
- **最强版本**：如果对方是高手，会怎么立。用它来压力测试我方立论。如果我方在最强版本面前会整体塌掉，回到第 4 步改判准

对每个版本写出：定义、判准、论点、最可能的论据、它跟我方在哪些战场相遇、它最薄弱的一环。

## 9. 立论自检清单

写完立论逐条检查：
- [ ] 一句话立论说得出来
- [ ] 定义符合常识与题解
- [ ] 判准与持方绑定，且放入对方最强论点后不反噬
- [ ] 每个论点都有机制，不只是论据堆砌
- [ ] 论点之间不重叠、不矛盾
- [ ] 每个论点都能回扣判准
- [ ] 没有隐含的让步（比如为了强调 A 而承认了对方的 B）
- [ ] 论据都标了可信度
- [ ] 价值层从论点里长出来
- [ ] 换成对方来看，最想打哪一点，我方有没有准备口径

## 10. 新生赛的适配

- 用队员自己能复述的语言写框架。写完让队员用自己的话讲一遍，讲不出来就是太复杂。
- 立论开头 30 秒之内让评委听到定义与判准。
- 所有队员对以下问题背出同一个答案：我方定义是什么、判准是什么、两个论点叫什么、对方最可能打哪里、我方怎么回。口径不一致是新生队最常见的失分点，三辩盘问就是专门抓这个的。
- 不要在场上临时创造新论点。新论点没有论据支撑，而且会让评委觉得前面的立论不够用。
