## 1. 辩题性质与关键词拆解

先判断辩题性质，因为它决定了判准的形态与双方的论证义务。

| 性质 | 典型句式 | 双方在争什么 | 判准形态 |
|---|---|---|---|
| 利弊比较 | "X 利大于弊 / 弊大于利" | 某个衡量标准下的净效果 | 谁的利、比什么、时间尺度、与什么比较 |
| 价值倡导 | "更应该 X""X 是好事 / 坏事""X 值得 / 不值得" | 一种态度或取向是否值得提倡 | 提倡的对象是谁、提倡会带来什么、代价是什么 |
| 事实判断 | "X 是 / 不是 Y""X 会 / 不会导致 Y" | 一个事实或趋势命题是否成立 | 成立的标准是什么、证据强度、因果还是相关 |
| 政策选择 | "应该 / 不应该实施某政策" | 一项具体行动是否值得做 | 需根解损：需求性、根属性、解决力、损益比 |
| 比较题 | "A 比 B 更 X" | 两个对象在同一标准下的高下 | 比较标准；"更"意味着承认对方也有 X |

有些题目被刻意写得模糊，"这道题到底属于哪种性质"本身就是第一个战场。备赛文档里要写明双方各自倾向于把题目解释成哪种性质、为什么。

关键词拆解：把辩题中的每一个实词拿出来，还要拆隐含要素：

- **主体**：谁在做、谁受影响（"我们""青年""社会"分别指谁）
- **范围**：当下中国、全球、还是抽象普遍情况
- **时间尺度**：短期还是长期，利弊题常常在这里决出胜负
- **比较对象**：与"没有 X"比，还是与"X 的替代方案"比

## 2. 定义三分法

对每个关键词做四件事，缺一不可：

**（1）调研**。查词典义（《现代汉语词典》《辞海》）、学术义（该领域教科书、综述、百科条目）、法规或行业义（法律条文、行业标准、官方文件）。有联网工具就搜，注明来源；没有则写出你确知的定义并标明"凭知识，建议查证"。调研的意义是：赛场上定义之争的胜负取决于谁的定义"看起来更像公认的"，而不是谁的更聪明。

**（2）正方有利定义**。写出定义本身、它为什么对正方有利（把哪些情形划进来、划出去），以及**反方如何反驳它**：指出它偏离常识或题解、指出它把结论藏进了定义（循环论证）、指出它让辩论失去意义（对方持方在此定义下不可能成立）。

**（3）反方有利定义**。同样写出定义、有利之处、**正方如何反驳它**。

**（4）中立定义**。写出定义与合理性说明：贴近常识（评委一听就点头）、贴近题解（若有）、让双方都有得打。中立定义是一辩稿要说的定义，也是双方在定义之争中的退守线。

有题解时，题解定义优先。三版定义都必须在题解范围内；题解没说的部分才有空间。

不要做"定义杀"：把对方持方定义成不可能成立。评委会认为这是逃避辩论，新生赛评委尤其反感。

## 3. 判准与论证义务

判准回答"评委凭什么判一方论证成功"。它由三部分组成：

- **判断标准**：在什么尺度上衡量（例如"多数普通人长期的可选择空间是否更大"）
- **正方的论证义务**：正方要证明什么才算赢
- **反方的论证义务**：反方要证明什么才算赢

论证义务经常不对称。利弊题里正方要证明"利大"，反方要证明"弊大"，谁都不能只证明"有利"或"有弊"；事实题里主张"会导致"的一方通常要证明因果，另一方证明"没有因果"或"因果不成立"即可；政策题里正方要四项都立住，反方打掉任意一项即可。备赛文档里要把双方义务写清楚，因为很多比赛输在一方自以为证明了什么。

然后写三版：

- **正方有利判准**：让正方论点自然成立的标准，以及反方的反驳（这个标准回避了什么、把谁排除在外、为什么与题目语境不符）
- **反方有利判准**：同上，反过来
- **中立判准**：双方都能接受的标准，以及在这个标准下双方各自的论证义务。说明它为什么合理：符合题目性质、照顾题目主体、能真正区分双方

**一辩稿使用中立判准**。原因：偏向性判准在质询里会被立刻攻击，一辩稿没有时间辩护它；而一个中立判准配上强论点，评委会觉得这一方是"在公平的标准下赢的"。有利判准留在攻防中使用：当对方提出他们的有利判准时，用我方有利判准的理由指出对方的偏向，然后把评委拉回中立判准。

## 4. 候选论点与筛选

每方先列 5–8 个候选论点，来源包括：从判准的每个维度出发、从主体的不同层次出发（个人 / 群体 / 社会）、从时间尺度出发、从这道题的公开讨论中常见的说法出发。

筛选标准，按顺序：

1. **合并相关的**：两个论点如果依赖同一个机制，就是一个论点
2. **删掉论据找不到的**：三件套（第 5 节）配不齐的论点上场就是靶子
3. **删掉在中立判准下不起作用的**：论点成立但不回扣判准，评委不会记分
4. **删掉被对方一句话就能打掉的**：对方最常见的反驳能覆盖的，不如换一个
5. 剩下的排优先级，留 2–3 个

留下的论点要**互不重叠**：换一种检验方式，如果对方打掉其中一个，另一个应当不受影响。

被淘汰的候选论点记录下来，交给反驳库：对方可能就用它们。

## 5. 论点三件套

每个入选论点必须配齐：

**学理**：
- 理论或概念的名称、提出者、年代
- 一句话说清它的核心主张（用队员能复述的话）
- 它如何支撑本论点（对应哪一步机制）
- 它的边界（在什么条件下不适用），这是对方会打的地方，先自己写出来

**数据**：
- 数值、来源机构或作者、年份、出处链接或文献信息
- 研究方法：样本是谁、多少、怎么收集的（调查 / 实验 / 追踪 / 元分析）、主要发现
- 局限：相关还是因果、样本能否推广、时间是否过时
- 赛场口头引用格式（见 `evidence.md` 第 8 节）

**案例**：
- 事件或人物的简述、出处
- 代表性：它代表的是普遍情况还是极端个例，如果是个例，用来说明机制而不是证明普遍
- 贴合度：它证明的正是本论点的机制，而不是一个相近的东西

论点本身的写法：主张（一句话结论）→ 机制（因果链，不超过三步）→ 三件套 → 回扣判准。给每个论点一个四到八字的标签，供全场引用。

## 6. 对抗迭代

对称迭代的结构：

```
第 1 轮  正方建构 → 反方建构
第 2 轮  反方用最强版本攻击正方每个论点 → 正方用最强版本攻击反方每个论点
        双方修补：改写机制、换论据、或替换论点
第 3 轮  重复第 2 轮
停止    每个论点同时满足：三件套齐全有出处；在对方最强攻击下仍成立或已改写到成立；与同方其他论点不重叠
```

攻击时不要客气，用对方最好的辩手会说的话。常用攻击角度：定义是否偏离、判准是否回扣、机制哪一步断了、数据是否支持结论（相关当因果、样本不对、过时）、案例是否个例、论点之间是否矛盾。

修补的原则：优先改机制与措辞，其次换论据，最后才换论点。换论点意味着回到第 4 节重新筛选。

每轮都做完两边再进入下一轮。如果使用子代理，给两方的建构代理与攻击代理完全相同的提示词，只替换持方，并要求它们输出相同的结构。

迭代过程不进入交付文档。交付的是最后一轮的结果。

## 7. 反驳库

对每一方，反驳对方**全部**可能的论点，来源三类：

- 对方入选的最终论点
- 对方被淘汰的候选论点（对手未必淘汰它们）
- 这道题在公开讨论中常见的其他说法

每条反驳的结构：

| 字段 | 内容 |
|---|---|
| 对方论点 | 用对方会用的话准确复述，不加戏 |
| 一句话反驳 | 15 秒内能说完，对辩与自由辩用 |
| 展开反驳 | 从定义、判准、机制、论据中选最狠的一到两个角度，60 秒 |
| 对方追问 → 再回应 | 对方最可能的追问以及我方的回答 |
| 来源标记 | 最终 / 淘汰 / 常见 |

反驳同样迭代一轮：站到对方那边，对每条反驳回击一次，站不住的改写。

反驳库里的数据也要有出处，也要进口径表。

## 8. 持方优劣评估

从五个维度评估，每个维度写一段并给出"偏正 / 偏反 / 均衡"：

| 维度 | 看什么 |
|---|---|
| 定义空间 | 常识定义与题解定义天然更接近哪一方的有利定义 |
| 论证义务 | 中立判准下哪一方要证明的东西更多、更难 |
| 论据可得性 | 数据与研究更多支持哪一方；哪一方的数据更容易被质疑 |
| 评委直觉 | 未经论证时，普通人更倾向哪一方；哪一方要先克服直觉 |
| 赛制顺序 | 正方先立论、最后结辩，反方先结辩等结构性因素 |

然后给结论：哪一方较劣势、劣势主要来自哪个维度，以及劣势方的打法建议：

- **收窄战场**：把比赛拉到劣势方论据最强的一两个点上，不接与胜负无关的战场
- **抢先定义**：劣势方常常输在定义，一辩稿就把中立定义说透，让对方的有利定义显得偏
- **判准之争**：如果直觉偏向对方，就把评委的注意力拉到论证义务上，指出对方"只证明了有，没证明大"
- **价值层**：直觉劣势可以用价值层扭转，结辩的价值升华在劣势方更重要
- **顺序利用**：反方先结辩就写封路式结辩；正方最后一发就留临场位

评估是给用户看的判断，不改变备赛投入。

## 9. 口径表

口径表是全队的唯一真源，每方一张。字段：

| 类别 | 标签 | 标准表述 | 允许的换说法 | 禁止的说法 | 出处 |
|---|---|---|---|---|---|
| 定义 | | | | | |
| 判准 | | | | | |
| 论点 | | | | | |
| 数据 | | | | | |
| 案例 | | | | | |

- 标准表述：一辩稿里说的原话
- 允许的换说法：意思不变的其他表述，供不同环节避免重复
- 禁止的说法：容易被对方抓住的表述，例如把"补位"说成"替代"、把"相关"说成"导致"、把整数说成约数

所有稿件从口径表取词。写完稿件用 `scripts/check_consistency.py` 检查数字是否都在口径表内。

## 10. 新生赛适配

- 框架用队员自己能复述的语言写。写完让队员用自己的话讲一遍，讲不出来就是太复杂
- 一辩稿开头 30 秒内让评委听到定义与判准
- 全队对以下问题背出同一个答案：我方定义、判准、论点标签、对方最可能打哪里、我方怎么回。三辩盘问就是专门抓口径不一致的
- 不在场上临时创造新论点，新论点没有论据支撑
- 劣势方队员容易在场上滑向绝对立场（把"不会更孤独"说成"让人更不孤独"），口径表的禁止栏要写明这类滑坡
