# 正赛文稿：更应该用现实向孩子解释死亡（正方）

- **赛制**：中国科学技术大学新生辩论赛（四对四，正方先立论，反方先结辩）
- **口径来源**：01-备赛文档 第十节 10.1 正方口径表。本文稿所有定义、判准、论点、数据均取自该表
- **上场纪律**：01-备赛文档 第十一节中状态为【待核实】的条目，一律不得出现在本文稿与临场发言中

## 1. 正一开篇立论稿（正文 832 字 / 180 秒）

谢谢主席，问候各位。

我先说清楚我方今天不主张什么。我方不主张对着一个四岁的孩子念解剖学，也不主张不许他听绘本。温柔不归对方所有。我方要的，恰恰是温柔地把话说清楚。

今天有三个词要定义。

用现实解释死亡，指以死亡的事实属性作为解释的主要内容，核心是三句话：人死了不会再回来，身体停止运作，每个人最后都会死。语气可以很轻。

用故事解释死亡，指以叙事、比喻、拟人作为解释的主要载体，它的字面内容不要求和事实一一对应。变成了星星，去了另一个地方。这些说法都算在里面。

孩子指三到十二岁，重心在三到八岁。为什么是这一段时间？因为孩子最早三岁半就开始问了，而死亡概念要到五岁到七岁之间才成形。

我方判准是：哪一种方式更能让孩子既正确地知道发生了什么，又承受得住它，并且愿意继续跟大人谈。两个指标，一个是懂，一个是受得住。在这个判准下，我方要证明以现实为主导整体更好，对方要证明以故事为主导整体更好。谁都不能只证明自己这边有好处。

我方第一点，孩子问的是事实。

你想想，一个孩子跑过来问的是什么。是爷爷为什么会死，是爷爷还会不会回来。二〇二〇年《儿童发展》上发表的一项研究访谈了六十一个三岁半到七岁的孩子，他们关于死亡的提问里，六成一问的是死因，没有一个孩子问到宗教；而家长的回答里有两成二讲的是来世。孩子问的和大人答的，根本不是同一件事。

更麻烦的是他会按字面把答案收下。美国儿科学会在给家长的指南里点了两句话的名：爷爷睡着了，爷爷去了一趟远门。为什么点名？因为真有孩子从此不敢关灯，也真有孩子听说奶奶出了远门，就死死抱住要出差的爸爸。

我方第二点，现实是地基。

二〇〇三年《认知心理学》上有一个实验。六十个三岁多到快六岁的孩子，其中四十个上了一节课，内容是身体靠什么运转才活着，另外二十个什么都没教。教完再测，学过的那一组不但更懂身体，对死亡的理解也显著提高了。请评委记住这个结果：讲最枯燥的现实，没有吓到孩子，反而让他更懂死亡。

还有一份研究访谈了九十个四到八岁的孩子。控制年龄和焦虑之后，越懂死亡，越不怕死。

所以我方全场都会追着对方一个问题：当孩子问出"爷爷还会回来吗"，你们的故事准备怎么回答这一句？

诚实从来就不等于不温柔。把真话说出口，孩子才知道，以后他撞上再坏的事，也可以来问你。

- 如果……就……：如果反四一上来就问"你是不是要跟四岁小孩讲器官衰竭"，答"不是，我方的现实是三句话，第一句就是人死了不会再回来"，然后立刻把问题还回去。如果对方抢先把"故事"定义成"不违背事实的叙事"，答"那我方欢迎，因为你已经在用现实了"。

## 2. 正一被质询防守预案（反四质询，120 秒双边计时）

双边计时下，答得越长，对方能问的越少，但评委会看出你在拖。原则是每答一句先给立场，再给一个短理由，然后闭嘴。

| 对方会问 | 我方回答（简短，守住前提） |
|---|---|
| 你方的"现实"是不是就是讲医学事实？ | 不是。是三句话：不会再回来，身体停止运作，每个人都会死。这三句里没有一个医学名词。 |
| 四岁孩子听得懂"身体停止运作"吗？ | 听得懂"不会再回来"。而且二〇〇三年那个实验里，三岁多的孩子被教身体怎么运转之后，对死亡的理解提高了。 |
| 你反对孩子读绘本吗？ | 不反对。我方反对的是用绘本代替那三句话，不是反对绘本。 |
| 《獾的礼物》算不算故事？ | 算，而且是好故事。它从头到尾没有否认獾死了。请对方解释，为什么它是好故事。 |
| 亲人今天刚去世，你也要先讲事实？ | 是。先说"他不会再回来了"，然后抱住孩子。英国那份对三十三位童年丧亲者的研究发现，当年没人把话说清楚，影响会跟到成年。 |
| 孩子哭了怎么办？ | 哭不是失败。孩子发现大人说的话不算数，那才是失败。 |
| 你方是不是认为讲故事的家长在骗孩子？ | 不是。我方认为大多数家长是好意，但好意不等于有效。 |
| "变成星星"这种说法，孩子长大自然会懂，有什么害处？ | 长大会懂，不等于中间这几年不用付代价。 |

守住的两个前提：第一，我方从不反对故事作为辅助；第二，我方的现实包含语气，温柔属于我方定义之内。这两条只要不松口，对方的质询就拿不到东西。

## 3. 正四质询反一问题链（120 秒，双边计时）

**链一：年龄边界**（目标：逼反方把默认年龄说死，要么说到三岁以下显得荒谬，要么说到六岁以上就进了我方战场）

1. 你方说的孩子，默认是几岁？ → 答"三到五岁"：那五岁以上的孩子呢，你方还坚持用故事吗？ → 答"各年龄都是"：那对九岁孩子讲变成星星，你方也认为更好吗？
2. 三岁半的孩子会主动问"人为什么会死"，这一点你方承认吗？ → 答"承认"：他问的是原因，你方的故事回答的是原因吗？
3. 你方是否承认，五到七岁之间多数孩子就能理解死亡不可逆？ → 答"承认"：那这一段年龄，你方为什么还要绕开事实？

打断用语：好的，我理解为您没有否认。下一个问题。

收束语：感谢，对方已经把年龄定在了学龄前，那么六岁以上的孩子，今天就归我方了。

**链二：故事的字面义**（目标：让反方在"故事可不可以偏离事实"上二选一）

1. 你方的故事，允许不允许字面上不符合事实？ → 答"允许"：那你方怎么保证孩子知道那是比喻？ → 答"不允许"：那你方的故事和我方的现实，区别只剩下修辞了吗？
2. "爷爷变成了星星"这句话，字面上是真的吗？
3. 一个还不知道死亡不可逆的孩子，他凭什么判断这是比喻？

收束语：对方要么承认故事会被当真，要么承认故事必须以事实为底。两条路都通向我方。

**链三：谁在被安慰**（目标：拿到"讲故事是为了大人好受"这个承认）

1. 家长说"奶奶在天上看着你"的时候，是孩子先提出来的，还是大人先说的？
2. 二〇一八年一项英国研究里，有成年受访者承认自己并不相信来世，却仍然这样告诉孩子，因为这样"威胁更小、更安慰人"。你方怎么解释？
3. 所以这句话安慰的到底是谁？

收束语：谢谢。对方一直没有回答，那句话安慰的是孩子还是大人。

## 4. 正二驳论稿（正文 416 字 + 临场位 100 字 / 120 秒）

谢谢主席。反方的立论听起来很温暖，但它有一个洞：反方全场都在论证故事这个形式更好接收，却始终没有论证故事讲的内容更该被接收。

〔此处留临场位，约一百字，回应反二刚才的驳论，先复述对方最强的一句，再用我方判准打回去〕

先看对方的第一个论点。对方说孩子接不住生物学解释，所以要用故事。可是你想想，接不住完整的生物学，不等于接不住"不会再回来"这五个字。对方自己引的河南那份研究里，五到六岁孩子成熟率最高的一项，恰恰就是不可逆性。最能接住的那一项，被对方当成了接不住的理由。请评委记一下这个顺序，对方的前提是从自己的数据里反着读出来的。

再看对方的第二个论点。对方说故事不占用准确性，证据是墨西哥那份研究。可是那份研究的孩子上限只到六岁十一个月。二〇一八年那份英国研究把年龄拉到了十一岁，结果就变了：八到十一岁里，宗教家庭的孩子只有两成三给出生物学模型，非宗教家庭是七成七。差距不是不存在，是在对方的样本里还没到显现的时候。

我方承认叙事在传递上确实更有效。可正因为有效，讲错的东西也会被记得更牢。对方到现在还欠我方一个答案：孩子问爷爷还会不会回来，你们那个故事，第一句准备说什么。这个问题一辩问过，我现在再问一次。

- 如果……就……：如果反二把战场拉到"正方冷酷"，不要辩解，直接举我方的三句话，然后问对方这三句里哪一句冷酷。如果反二搬出《獾的礼物》，就接住它，说那本书一句假话都没有，正是我方要的。

## 5. 正二对辩要点（90 秒，单边计时）

单边计时，对方拖不了我的表，我也拖不了对方的。比的是每次发言的密度。一次一个点，说完就停。

**进攻点（每个十五到二十秒）**

1. 孩子的提问里六成一是问死因，没有一个问宗教；家长的回答里两成二是来世。请对方解释这个错配。
2. 你方举的所有故事都不违背事实，那你方和我方的分歧到底在哪里？
3. 三岁多的孩子被教了身体怎么运转，对死亡的理解就提高了。这个实验对方怎么解释？
4. 请正面回答：孩子问"爷爷还会回来吗"，你方的故事怎么答这一句？
5. 你方说长大就懂了。那从四岁到十四岁这十年，孩子按你方的故事活着，代价谁承担？

**备用点（用于回应对方进攻）**

1. 我方从不反对绘本，我方反对的是用绘本代替那三句话。
2. 温柔不归你方所有，我方的定义里语气可以很轻。
3. 你方那份元分析测的是读课文的理解和记忆，不是死亡观。
4. 拟人化绘本让孩子学到的事实更少，这也是绘本研究的结论。
5. 亡灵节那份研究里，三成一的孩子说自己害怕，四岁组超过一半。故事也会吓人。
6. 讲现实不等于不抱孩子。安慰不需要谎言当前提。
7. 你方把"故事"和"回避"混在一起了，真正的回避是"你还小，长大就懂了"。
8. 你方举证责任在"故事更好"，不在"故事无害"。

**对方最可能问的三个问题**

- 你方是不是要给四岁孩子讲器官衰竭？ → 不是。三句话，第一句是"不会再回来"。
- 《獾的礼物》你方反不反对？ → 不反对，那本书正是我方要的：讲了死亡，一句假话都没有。
- 孩子当场崩溃怎么办？ → 抱住他。我方从没说过安慰要靠谎言。

## 6. 正三盘问问题链（90 秒，单边计时）

单边计时，一般只计我方的时间，所以可以让对方多说几句，但对方一开始展开立论就打断。

**链一：同一个问题先问二辩再问四辩**（目标：检验反方在"年龄"上的口径是否一致，为小结取证）

1. 请问反方二辩，你方主张的默认年龄是几岁？
2. 同一个问题请反方四辩回答，你方主张的默认年龄是几岁？
3. 那么八岁的孩子，你方还主张用故事吗？请二辩回答。
4. 四辩同意二辩刚才这个回答吗？

**链二：故事的底线**（目标：让反方承认故事必须以事实为底，否则就是骗）

1. 请问反方四辩，你方的故事允许字面上与事实不符吗？
2. "爷爷变成了星星"这句话，字面上是真的吗？
3. 如果孩子当真了，你方打算什么时候纠正他？
4. 纠正他的时候，你方用的是故事还是现实？

打断用语：好的，这个我方听明白了，请回到问题。

盘问目标（小结里要证明什么）：第一，反方在年龄上给不出一致的答案，说明"孩子接不住"这个前提是随场调整的；第二，反方一旦承认故事需要被纠正，纠正的工具就是现实，那么现实就是底，故事是选配。

## 8. 正三盘问小结稿（正文 382 字 / 90 秒）

谢谢主席。刚才的盘问里，反方交出了两样东西。

第一样是年龄。我问反方二辩和四辩同一个问题，他们给的答案不一样。二辩说的是学龄前，四辩说的是各个年龄。这说明什么？说明"孩子接不住事实"这个前提不是一个结论，是一个可以随场调整的说法。哪里需要就放在哪里。一个会随场调整的前提，撑不起一整个论点。

第二样更要紧。反方承认了，如果孩子把故事当了真，是要纠正的。那我请评委想一想：纠正的时候用什么？只能用现实。也就是说，在反方自己的方案里，现实是那个兜底的东西，故事是可以不选的那个。谁主谁次，反方刚才替我方回答了。

到这里，全场的分歧已经很清楚。反方一直在论证故事这个形式更好接收，这一点我方承认，叙事确实更容易进去。但今天的题目问的不是哪种形式更顺耳，是哪种解释更应该占主导。形式再顺，装错了东西也还是错的。碗好看不好看，跟里面盛的是什么，是两回事。

反方到现在还没有回答我方一辩抛出的那个问题：当孩子问"爷爷还会回来吗"，你们的故事怎么答这一句。这个问题已经问了三次了。

## 9. 自由辩战场设计（240 秒）

### 战场一：孩子到底问了什么（前 90 秒）

- 目标：让评委记住"孩子问事实、大人答来世"这个错配，把举证责任压到反方身上
- 开场问题：孩子问"爷爷还会回来吗"，你方怎么答这一句？
- 对方答"我会说爷爷变成了星星" → 追问：那孩子明天再问一次呢？你是继续讲星星，还是改口？
- 对方答"我会先说不会回来，再讲故事" → 追问：那你已经承认现实在前，故事在后，这正是我方的主张
- 对方可能反攻："你方的错配数据是墨西哥的，中国不一样" → 我方防守：中国的数据我方也有，河南那份研究里五到六岁孩子不可逆性成熟率最高，说明这一项最接得住
- 收束语：一整场下来，对方始终没有正面答过这一句话。

### 战场二：故事有没有底（中 90 秒）

- 目标：把反方逼进二选一，要么承认故事会被当真，要么承认故事必须以事实为底
- 开场问题：你方的故事，允许字面上与事实不符吗？
- 对方答"允许" → 追问：那一个还不知道死亡不可逆的孩子，凭什么判断这是比喻？
- 对方答"不允许" → 追问：那你方和我方只剩下修辞之争，今天这道题就没得辩了
- 对方可能反攻：搬出《獾的礼物》 → 我方防守：接住它，指出那本书一句假话都没有，所以它是我方的例子
- 收束语：对方的故事要么需要现实兜底，要么会被孩子当真。

### 战场三：谁在被安慰（后 60 秒，不开新战场，只收束）

- 目标：把讲故事的动机问题摆出来，为结辩的价值层铺路
- 开场问题：二〇一八年那份英国研究里，有成年人承认自己不信来世却仍然这样告诉孩子，因为这样威胁更小、更安慰人。这句话安慰的是谁？
- 收束语：我们今天争的不是要不要温柔，是温柔要不要建在真话上面。

## 10. 正四结辩稿（正文 740 字 / 210 秒，留 30–40 秒临场回应）

谢谢主席。

〔开场留三十到四十秒，真回应反四刚才说了什么，不要念稿。先复述对方最有力的一句话，再用判准打回去〕

全场打到现在，分歧只剩一个。反方一直在说，故事这个形式孩子更容易接住。这一点我方承认，从第一分钟就承认了。叙事确实更好懂，也更好记。可是请评委注意，我方从来没有在这一点上跟反方争过。

我方争的是另一件事：接住了什么。

反方全场举了三个例子，《獾的礼物》，亡灵节，还有清明的那三只碗。这三个例子有一个共同点，它们都没有否认死亡。獾死了就是死了，书里没让它回来。清明摆碗的那一家人，没有一个以为爷爷真的会吃。反方举的每一个好例子，都建在一个已经知道真相的人身上。

那反方真正要辩护的是什么呢？是"变成了星星"，是"睡着了"，是"去了一趟远门"。这几句话，反方一整场一次都没有替它们辩护过。各位可以回想一下，有吗？

所以我方要处理反方全场最强的那一点。反方说，讲故事的家庭，孩子的生物学理解并没有被拖累，墨西哥那份研究里父母的宗教倾向对四个子成分都没有显著影响。这一条我方正面回答：那份研究的孩子最大只有六岁十一个月。二〇一八年的英国研究把年龄拉到十一岁，差距就出来了，八到十一岁里宗教家庭的孩子只有两成三给出生物学模型，另一边是七成七。代价不是没有，是还没到结账的时候。

我方那个问题问了一整场：孩子问"爷爷还会回来吗"，你们的故事怎么答这一句。反方到现在也没有答。

〔停顿〕

我想说一件小事。

我认识一个孩子，他外婆走的那年他六岁。家里人告诉他，外婆去了很远的地方。他信了。他每天放学都跑到小区门口那条路上站一会儿，因为从很远的地方回来，总要走那条路。他站了大半年。后来大人告诉他真相，他没有哭，他说了一句话：那你们为什么让我等。

我方今天争的不是要不要温柔。我方争的是，一个六岁的孩子，值不值得被当成一个能听真话的人。

真话会让他难受，但难受是他自己的，他扛得动。一句让他等下去的好话，扛的是别人替他做的决定。

孩子第一次问起死亡的时候，他其实是在问另外两件事：我还会不会被爱，你会不会有一天也不见了。这两个问题，故事答不了，只有一个肯对他说真话的大人答得了。

请把真话给他。然后抱住他。
