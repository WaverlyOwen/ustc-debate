# 正赛文稿：更应该用故事向孩子解释死亡（反方）

- **赛制**：中国科学技术大学新生辩论赛（四对四，正方先立论，反方先结辩）
- **口径来源**：备赛文档 第十节 10.2 反方口径表。本文稿所有定义、判准、论点、数据均取自该表
- **上场纪律**：备赛文档 第十一节中状态为【待核实】的条目，一律不得出现在本文稿与临场发言中

## 1. 反一开篇立论稿（正文 835 字 / 180 秒）

谢谢主席，问候各位。

刚才的质询里，正方一辩已经承认了一件事：他们不反对绘本。那就请评委记住这句话，因为对方接下来举的每一个反例，都会是"睡着了""弄丢了"这种敷衍，不是故事。

我先把故事这个词从"骗人"里摘出来。

用故事解释死亡，指以叙事、比喻、拟人作为解释的主要载体，它的字面内容不要求和事实一一对应，但也从来不要求和事实冲突。

有一本绘本叫《獾的礼物》。獾老了，然后它死了。书里没让它复活，也没说它去了别的地方。朋友们靠着回忆它教过的每一件事，一天天过下来。鼹鼠记得的是獾教他剪一串手拉手的纸小人。这就是我方说的故事：讲完了死亡，一句假话都没有。

用现实解释死亡，指以死亡的事实属性为主要内容，语气可以温柔。这一点我方不跟对方争。

孩子指三到十二岁，重心在三到八岁，关键在于这个年纪的死亡概念还在成形。

我方的判准是：哪一种方式更能让孩子既正确地知道发生了什么，又承受得住它，并且愿意继续跟大人谈。请各位注意这里的重点：解释算不算成功，看的不是大人说出了什么，而是孩子接住了什么。

我方第一点，在那个年纪，故事是进得去的那条路。

去年发表在《心理学前沿》上的一项研究，测了河南一百一十四个五到六岁孩子的死亡概念。五个成分里最高的一项是不可逆性，六成八；最低的一项只有五成四。也就是说，在孩子追问死亡最频繁的年纪，连最容易的那一项，都还有三分之一的孩子没有掌握。

那剩下的这三分之一怎么办？二〇二一年一篇元分析汇总了七十五个以上的样本、三万三千多名参与者，结论是故事比说明文更容易被理解，也记得更牢。我先说清楚它的局限：它测的是读文本的理解和记忆，不是死亡观。我方用它，只用来说明叙事是更有效的传递形式。

我方第二点，故事不占用准确性，却多给了一样东西。

墨西哥有一项对六十一个孩子的研究。八成二的孩子相信亡故的亲人在亡灵节回来探望，可这些孩子同时全都表现出了生物学意义上的死亡理解，而且父母的宗教与灵性倾向，对四个死亡子成分都没有显著影响。

一套用来知道，一套用来相处。我们自己每年清明不也是这样吗？墓前摆三只碗，说一句爷爷你吃。没有哪个大人真以为爷爷会回来吃。

所以我方全场只问对方一件事：一个四岁的孩子听完你们的生物学解释，只记住了"心脏会停"，那你们解释的到底是死亡，还是心脏？

- 如果……就……：如果正四质询逼你把年龄说死，答"三到八岁是重心，因为死亡概念正在这一段成形"，不要缩到三到五岁。如果对方说"那你已经在用现实了"，答"我方从不反对事实，我方反对的是只给事实"。

## 2. 反一被质询防守预案（正四质询，120 秒双边计时）

双边计时，答长了就是在吃自己的表，而且评委看得出在躲。每答一句先给立场，再给一个短理由。

| 对方会问 | 我方回答（简短，守住前提） |
|---|---|
| 你方说的孩子几岁？ | 三到十二岁，重心三到八岁。因为死亡概念正好在这一段成形。 |
| 八岁的孩子你方还用故事吗？ | 还用。八岁孩子读《獾的礼物》一样有用，理解力和需要安放的情感是两件事。 |
| 你方的故事允许字面上与事实不符吗？ | 不要求一一对应，也不要求冲突。《獾的礼物》一句假话都没有。 |
| "爷爷变成了星星"字面上是真的吗？ | 不是。所以我方不拿它当范例，对方全场只有这一个靶子。 |
| 你方承不承认孩子会把故事当真？ | 承认有这种可能。墨西哥那份研究里孩子当真了，生物学理解照样没受影响。 |
| 那孩子当真了要不要纠正？ | 要。但纠正不等于一开始就不该讲，任何教育都有后续。 |
| 你方是不是反对告诉孩子真相？ | 不反对。我方反对的是只给一堆事实就算解释完了。 |
| 你方那份元分析测的不是死亡观吧？ | 对，我方立论里自己说了。我方只用它说明叙事传递更有效。 |

守住的两个前提：第一，故事不等于谎言，我方的故事可以完全不违背事实；第二，解释成功与否看孩子接住了什么。这两条不松口，对方就拿不到取证。

## 3. 反四质询正一问题链（120 秒，双边计时）

**链一：把"现实"逼到具体的话**（目标：让正方要么说出一句冷冰冰的话，要么承认自己也在讲故事）

1. 四岁孩子问爷爷去哪了，请用你方的现实，现场说一句话给我听。
2. 就这一句吗？孩子接着问"那我还能见到他吗"，你说什么？
3. 你刚才那句话里有"他在你心里"这样的说法吗？ → 答"有"：那就是我方说的故事。 → 答"没有"：那孩子拿到的就只有"见不到了"这五个字。

打断用语：好的，我理解为您没有否认。下一个问题。

收束语：谢谢，对方的现实要么变成了我方的故事，要么只剩下一句见不到了。

**链二：接受与接住**（目标：拿到"解释成功看孩子接住了什么"这个承认）

1. 你方承不承认，大人说了不等于孩子懂了？
2. 五到六岁孩子里，还有三分之一没掌握不可逆性，这一点你方承认吗？
3. 那这三分之一的孩子，你方的现实解释对他们起作用了吗？

收束语：对方已经承认，说了不等于懂了。那么今天比的就是谁更进得去。

**链三：《獾的礼物》**（目标：把正方逼进二选一，要么反对好故事，要么承认分歧不成立）

1. 《獾的礼物》算不算故事？
2. 它有没有任何一句违背事实？
3. 那你方今天反对的到底是叙事这个形式，还是"睡着了"这种敷衍？

收束语：对方反对的是敷衍，可今天的辩题写的是故事。

## 4. 反二驳论稿（正文 509 字 / 120 秒）

谢谢主席。正方的立论有一个换靶子的动作，我要把它指出来。

正方全场举的例子只有两个：爷爷睡着了，爷爷去了一趟远门。请评委想一想，这两句话是故事吗？一个故事要有人物，有情节，有结局。"睡着了"三个字什么都没有，它是敷衍，是大人不想谈了。正方真正反对的是敷衍，可今天的辩题写的是故事。

先看正方第一个论点。正方说孩子问的是事实，用故事回答是答非所问，证据是那份墨西哥研究里孩子问死因、家长答来世。可是同一份研究的原文写得很清楚，父母是在回答了孩子的问题之后，再扩展到来世的。孩子问死因，家长里有五成五答的正是死因。那不是答非所问，那是答完了还多说了一句。请评委把这两件事分开看。而多说的那一句，按同一份研究的结论，没有让任何一个孩子的生物学理解变差。

再看正方第二个论点。正方最重的那个训练实验，六十个孩子，教的是身体靠什么运转才活着。我方承认这个结果，可请对方注意，那节课教的是身体，场景是课堂。把它当成"应该用现实向孩子解释死亡"的直接证据，中间跨了一大步。至于那份说越懂生物学越不怕死的研究，是横断面的相关，不是因果。也完全可能是本来就不那么焦虑的孩子，更愿意正面谈论死亡。方向是反过来的，对方那份数据分不出来。

最后我要问正方一句。你方举的那个训练实验里，孩子听完课懂了死亡，这我承认。可孩子的外婆刚刚去世的那天晚上，你打算给他上哪一节课？

- 如果……就……：如果正二把"温柔"抢过去了，不要争温柔，改成"我方争的不是谁更温柔，是孩子接住了什么"。如果正二用了《獾的礼物》反打我方，就顺着说"那我方欢迎对方承认好故事有效"，然后立刻问他为什么全场只举敷衍的例子。

## 5. 反二对辩要点（90 秒，单边计时）

单边计时，谁也拖不了谁的表，比的是密度。一次一个点，说完就停。

**进攻点（每个十五到二十秒）**

1. 你方全场只举了"睡着了""弄丢了"。请举一个《獾的礼物》这个级别的故事，然后告诉我它错在哪。
2. 五到六岁孩子里还有三分之一没掌握不可逆性。这三分之一，你方的现实解释怎么办？
3. 墨西哥那份研究里，父母的宗教与灵性倾向对四个子成分都没有显著影响。准确性没有被占用，你方怎么解释？
4. 一个四岁孩子听完只记住"心脏会停"，你方解释的是死亡还是心脏？
5. 孩子的外婆今晚刚走，你方的第一句话是什么？

**备用点（用于回应对方进攻）**

1. 我方从不反对说"死了"这两个字，我方反对的是说完就没了。
2. 你方那个训练实验教的是身体，不是丧亲场景。
3. 越懂生物学越不怕死是相关，不是因果。
4. 英国那份研究测的是父母信不信来世，不是父母讲不讲故事。
5. 同一份英国研究里，成人组没有出现共存式思维。这笔账后来是还清的。
6. 清明我们自己也在做同一件事，为什么轮到孩子就成了欺骗。
7. 《爷爷变成了幽灵》的结尾是爷爷说完再见就走了，那本书讲的正是告别。
8. 你方的举证责任是"现实更好"，不是"故事有风险"。

**对方最可能问的三个问题**

- "变成星星"字面上是真的吗？ → 不是，所以我方不拿它当范例，我方的范例是《獾的礼物》。
- 孩子当真了怎么办？ → 会纠正。任何教育都有后续，一次说不到位不等于方法错。
- 孩子问"爷爷还会回来吗"你怎么答？ → 答"不会了"，然后讲獾的故事。两件事从来不冲突。

## 6. 反三盘问问题链（90 秒，单边计时）

单边计时一般只计我方的时间，可以让对方多说两句，但对方开始展开立论就打断。

**链一：同一个问题先问二辩再问四辩**（目标：检验正方在"故事到底指什么"上的口径是否一致）

1. 请问正方二辩，《獾的礼物》算不算你方反对的那种故事？
2. 同一个问题请正方四辩回答，《獾的礼物》算不算？
3. 如果不算，那你方今天反对的是什么？请二辩回答。
4. 四辩同意二辩这个回答吗？

**链二：解释的目的**（目标：让正方承认解释死亡不只是传递知识）

1. 请问正方四辩，孩子问死亡的时候，他只是在要一个知识吗？
2. 他是不是也在问"你会不会有一天也不见了"？
3. 这个问题，你方的三句话回答得了吗？
4. 那剩下的那一半，你方打算用什么回答？

打断用语：好的，这个我方听明白了，请回到问题。

盘问目标（小结里要证明什么）：第一，正方两位辩手对"故事"的边界给不出同一个答案，说明他们反对的其实是敷衍；第二，正方一旦承认孩子问的不只是知识，那么他们的三句话就只覆盖了一半，剩下那一半只有叙事能装。

## 7. 反二、反四被盘问防守预案（两人口径必须一致）

赛前两人对着这张表各背一遍，意思必须一样，用词可以不同。回答短，不确定就说"我方立论的立场是"。

| 对方会问 | 二辩答 | 四辩答（必须一致） |
|---|---|---|
| 你方的故事允许字面与事实不符吗？ | 不要求一一对应，也不要求冲突。 | 不要求对应，也不要求冲突。《獾的礼物》就是证明。 |
| "变成星星"你方支持吗？ | 那不是我方的范例，我方的范例是《獾的礼物》。 | 不拿它当范例。它是敷衍和故事之间的东西。 |
| 你方默认的孩子几岁？ | 三到十二岁，重心三到八岁。 | 三到八岁是重心，因为死亡概念在这一段成形。 |

| 纠正的时候用的是现实吗？ | 用的是把故事讲完整，比如那本书的结尾就是告别。 | 用的是继续讲。现实是材料，叙事是形式，两者不对立。 |
| 你方反对说"死了"这两个字吗？ | 不反对。我方反对的是说完就没了。 | 不反对。我方争的是说完之后怎么办。 |
| 你方承认现实有价值吗？ | 承认，作为材料有价值。 | 承认。我方争的是谁主导，不是谁存在。 |
| 亡灵节那份研究里三成一的孩子说害怕，你方怎么解释？ | 同一份数据里这个比例随年龄下降，四岁五成五，六岁一成五。 | 随年龄下降，四岁五成五，六岁一成五。而且怕本来就是死亡的一部分。 |

## 8. 反三盘问小结稿（正文 310 字 + 临场位 80 字 / 90 秒）

谢谢主席。

〔此处留临场位，约八十字，直接回应正三小结刚才的两点成果，先说他哪一点我方接受，再说他哪一点问错了〕

刚才的盘问里，正方交出了两样东西，我一件一件说给评委听。

第一样，我问正方二辩和四辩同一个问题，《獾的礼物》算不算他们反对的故事。两个人给的答案不一样。这说明正方今天反对的东西一直没有边界。哪一句话听起来像谎，哪一句就是故事。可辩题写的不是谎，写的是故事，这两个词各位不能混着用。

第二样更要紧。正方四辩承认了，孩子问死亡的时候不只是在要一个知识，他也在问"你会不会有一天也不见了"。请评委记住这个承认。正方的三句话只回答了前半个问题。后半个问题，一个还不会写字的孩子要怎么带走？他带不走一个定义，他只带得走一个故事。我方承认，定义也要给，可给完之后，孩子手里得有个东西。

所以到现在为止，正方的现实覆盖的是一半，我方的故事装得下两半。请评委在这一点上认真看一看，今天到底谁的方案是完整的。

## 9. 自由辩战场设计（240 秒）

### 战场一：正方在反对什么（前 90 秒）

- 目标：让评委看清正方全场的例子都是敷衍，不是故事，把举证责任推回去
- 开场问题：请举一个《獾的礼物》这个级别的故事，告诉我它错在哪。
- 对方答"那本书不算故事，它在讲事实" → 追问：那你方承认叙事形式没问题，今天这道题就没得辩了
- 对方答"它算，但它好在没违背事实" → 追问：那你方反对的是违背事实，不是故事，辩题写的可是故事
- 对方可能反攻："大多数家长讲的就是变成星星" → 我方防守：大多数家长讲的也不是你方那三句话，方法之争比的是上限
- 收束语：一整场下来，对方举的例子没有一个是故事。

### 战场二：解释的那一半（中 90 秒）

- 目标：把"孩子问的不只是知识"钉进评委脑子里，这是反方最能赢的地方
- 开场问题：孩子问死亡的时候，他是不是也在问"你会不会有一天也不见了"？
- 对方答"是" → 追问：那你方那三句话回答的是哪一半？
- 对方答"不是，他只是在问事实" → 追问：那请你方解释，为什么孩子问完之后要抱住大人不放
- 对方可能反攻：搬出"孩子按字面理解比喻" → 我方防守：《獾的礼物》没有比喻，只有一只死掉的獾和一群记得他的朋友
- 收束语：对方解释的是死亡这件事，我方解释的是孩子的那个夜晚。

### 战场三：准确性有没有被占用（后 60 秒，不开新战场，只收束）

- 目标：用零效应把正方最重的攻击挡回去，然后收
- 开场问题：墨西哥那份研究里，父母的宗教与灵性倾向对四个子成分都没有显著影响。准确性到底被占用在哪？
- 对方搬出英国研究 → 防守：那测的是父母信不信来世，不是讲不讲故事；而且同一篇的成人组没有共存式思维
- 收束语：我们今天争的不是要不要说真话，是真话要用什么形状交到孩子手上。

**必问**（前两分钟内问完）

1. 请举一个《獾的礼物》级别的故事，告诉我它错在哪。
2. 五到六岁孩子里还有三分之一没掌握不可逆性，这三分之一怎么办？

## 10. 反四结辩稿（正文 952 字 / 210 秒，封路式）

谢谢主席。

我先替正方四辩把待会儿的结辩说了。

正方等一下大概会这样收：我方不反对温柔，我方只反对不真实；孩子值得被当成一个能听真话的人。这句话很好听，我也承认它有力量。但请各位评委在听到它的时候，问正方一个问题：这一整场，正方举过一个真正的故事吗？

没有。从第一分钟到现在，正方举的是"爷爷睡着了"，是"爷爷去了一趟远门"，是"我们把妈妈弄丢了"。这些不是故事，这些是大人不想谈了。一个故事要有人物，有情节，有结局。"睡着了"三个字，一样都没有。

正方还可能说，他们的现实只有三句话，第一句就是"不会再回来"。我方承认这三句话都对，从头到尾没有反对过。今天的分歧从来不在要不要说真话，而在真话说完之后，还剩下什么。

那我们就来看剩下的那一半。

一个孩子跑来问你人为什么会死。他要的真的只是一个死因吗？正方四辩在盘问里已经承认了，孩子同时是在问另一件事：你会不会有一天也不见了。这后半个问题，正方的三句话一个字都没有碰到。

我方两个论点，到现在还立着。

第一，在孩子最需要解释的年纪，故事是进得去的那条路。河南那一百一十四个五到六岁孩子里，最容易的不可逆性也只有六成八的人掌握，最低的一项只有五成四。剩下的那三分之一，正方从来没有说过要拿他们怎么办。

第二，故事没有占用准确性。墨西哥那六十一个孩子，八成二相信亲人在亡灵节回来探望，可他们全都有生物学意义上的死亡理解，而且父母的宗教与灵性倾向，对四个子成分统统没有显著影响。

正方全场最有力的一击，是那份英国研究：八到十一岁里，宗教家庭的孩子只有两成三给出生物学模型。我正面回答两句。第一，那测的是父母信不信来世，不是父母讲不讲故事，一个无神论的家长照样会说姥姥变成星星了。第二，也是更要紧的一句，同一篇论文里的成年人，没有一个出现共存式思维，只剩下清清楚楚的两套解释。这笔账，后来是还清了的。

〔停顿〕

最后我想请各位想一个具体的画面。

清明那天，一家人站在墓前，摆三只碗，说一句爷爷你吃。旁边站着一个七岁的孩子。他知道爷爷不会回来，这一点家里早就告诉过他了。可他还是把自己那块糖掰了一半，放在碗边上。

那一刻他在干什么？他不是在犯糊涂。他是在用一个我们所有人都在用的办法，跟一个已经不在的人，继续待一会儿。

我们成年人一辈子都在做这件事。我们给逝者写墓志铭，我们在他生日那天照样买一块蛋糕，我们清明去扫墓。我们从来没有因此忘记他已经死了。

我们自己都要靠故事才过得去的一件事，凭什么要求一个四岁的孩子，只靠三句话就扛下来。

真话我们当然要给他。但真话是一块很硬的石头，得有个东西托着，他才拿得动。

那个东西就是故事。
