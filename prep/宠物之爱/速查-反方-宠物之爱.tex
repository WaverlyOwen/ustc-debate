\begin{thesisbox}[一句话立论]问卷上愿意负债的是九成，账单真来时让它等过的近半；病老之时它一句话说不了，多疼一段还是早走一步，跟着我的不舍和我的负担走。冲突时让路的是它，决定的是我，所以爱的更是我。\end{thesisbox}
\section{定义与判准（标准表述）}
\begin{fields}
\field{爱}{对一个对象的深挚感情，以及这份感情带来的持续关切和行动。（与正方相同，不争）}
\field{更}{这是一道比较题，两边都在。我方不否认你爱它，我方比的是分量。}
\field{我}{饲主自己的需要：陪伴、被需要、情感出口、可控感、自我形象。}
\field{判准}{冲突时优先谁（正方那一条），我方只加一句：以行为为准，以多数为准。\sub{我方要证明}{让不让路跟着我的钱、我的负担、我的不舍，不跟着它的指标。}\sub{对方要证明}{多数人让的是自己。}}
\field{什么算为它（可证伪，必背）}{有得选时让自己扛；按它的指标而不是我的状况定终点；被告知后按它的需要改。都存在；有比例的地方跟着我走的是多数：依恋主导 69.3\%、凭自己观察 53.5\%、用指标只有 7.3\%。}
\end{fields}

\section{必问与必答}
\begin{points}{必问（对方不答就点名、重复、不换题）}
\item 用它的指标判断终点的人在哪里？（一辩稿抛出的那个问题）
\item 九成愿意负债，是意愿题还是行为题？
\item 同样的疼，负担不同，决定是不是不同？
\end{points}
\begin{points}{必答（15 秒正面回答）}
\item “有没有任何一种爱更指向对方？” → \textbf{有}。母亲为孩子放弃职业规划。请你方给条件，我们逐条比。
\item “饲主做什么才算为它？” → 三样（上）。用指标的只有百分之七。
\item “它病了你的状况变不变？” → 变。我方不否认代价，我方说决定跟着谁走。
\item “Zarit 量表是为照护失智父母的子女设计的，他们也更爱自己吗？” → 我方不用负担分判母爱，用它判决定跟着谁走；我方说的是分量，不是不爱。
\end{points}

\section{如果……就……，以及三条铁律}
\begin{contingency}
\ifthen{对方定义杀或拿出没预料到的数据}{问“被告知狗超重仍每周喂三次零食的主人算不算爱狗”；对数据先问机构、年份、样本，再问是意愿题还是行为题。}

\end{contingency}
\textbf{三条铁律}：先说“我方不否认你爱它”；不说“46 大于 37”“早走一步也是它让路”；价值层收在“再看它一眼”。
