\debatetitle
\begin{thesisbox}[一句话立论]钱和它的病相撞时多数人削的是自己；它病了老了不再回应时投入不降反升；明知结局仍然开始。冲突时让路的是我，所以爱的更是它。\end{thesisbox}
\section{定义与判准（标准表述）}
\begin{fields}
\field{爱}{对一个对象的深挚感情，以及这份感情带来的持续关切和行动。}
\field{更}{这是一道比较题，两边都在。我方承认养宠让人快乐、让人被需要，我方争的是分量。}
\field{它}{你家那一只，它有自己的需要，不随你的想法改变。}
\field{判准}{冲突时优先谁：当它的需要和我的需要撞上，让路的是谁，这份爱就更是谁的。说全两问：让谁受益、让谁让路。\sub{我方要证明}{多数人让的是自己；回报最低时投入不降。}\sub{对方要证明}{多数人让的是它，或让路跟着我的状况走。}}
\field{全队三句}{一、它的疼通过我的负担到达我的决定，渠道是我，起点和理由是它。二、被需要是我的需要；它需要我起床、我需要睡觉，起床的是我。三、什么算为我：有得选时让它扛、拖着让它多疼、被告知后不改；都存在，典型饲主做的是相反的事。}
\end{fields}

\section{必问与必答}
\begin{points}{必问（对方不答就点名、重复、不换题）}
\item 按你方标准，饲主做什么才算爱的更是它？（一辩稿抛出的那个问题）
\item 行为题两边都不过半，“多数让它等”在哪里？
\item 负担中介的起点是不是它的疼？
\end{points}
\begin{points}{必答（15 秒正面回答）}
\item “九成是意愿题吧？” → 是。行为题是三成七、三成七、四成四，两边都不过半。
\item “负担越高越考虑安乐死。” → 渠道是我，起点和理由是它。
\item “被需要是你的需要吧？” → 是。起床的是我。
\item “它的疼是你感知的吧？” → 是，它不会说话。观察的对象是它。
\end{points}

\section{如果……就……，以及三条铁律}
\begin{contingency}
\ifthen{对方换判准（受益结构、决定变量在我）或拿出没预料到的数据}{一句“母爱也更是我，不可证伪”，回到冲突检验两问；对数据先问机构、年份、样本，再问是意愿题还是行为题。}
\ifthen{论点一被打穿或对方回避必问}{回到全队第一句，收缩到终点理由 87\% 与卢卡的画面；回避就点名、重复、不换题。}
\end{contingency}
\textbf{三条铁律}：不说“我什么都没得到”“被需要不是我的需要”“我的负担不决定它哪天走”；不用 84\%、91\%、65\% 证多数；不说“所以它也爱我”。
