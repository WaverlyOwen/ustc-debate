\begin{speech}{1. 正一开篇立论稿}{正文 827 字 / 180 秒}
谢谢主席，问候在场各位。

今天这道题，问的是一份感情朝哪边走。我方的立场是：对宠物的爱，爱的更是它。

先把三个词说清楚。

爱，词典上的第一个意思是，对人或事有深挚的感情。我方再补一句：这份感情会带出持续的关切和行动。所以爱有两层，一层是我心里的感受，一层是我为它做的事。

「更」这个字，请评委记住。这是一道比较题，它本身就预设了两边都在。我方承认：养宠让人快乐，让人被需要，也让人有一件每天都要回家去做的事。这些我方全都承认。我方要争的是分量，不是有无。

「它」指的是你家那一只。它有自己的脾气和需要，不随你的想法改变。

判准我方给两条通道。第一条，这份爱的内容是被谁塑造的；第二条，当它的需要和我的需要真的撞上，这份爱跟着谁走。两条合起来偏向哪一边，哪一边就是「更」。在这个标准下，我方要证明的是，这份感情主要由它塑造，而且冲突真的发生时，多数人让的是自己。对方要证明的是反过来。

我方第一点，让路的是我。

人和动物住在一起，作息、钱、自由、睡眠，一定会撞。撞的时候往哪边让，就能读出这份感情朝哪边。心理学里有一套照料行为系统，它和依恋系统不是一回事：依恋系统的目标是我自己安不安全，照料系统的目标是对方过得好不好。真正能说明问题的，是那些我一点好处都拿不到的场合。二零二零年武汉封城，主人困在外地，只能从监控里看着猫粮一点点见底。他们拿着身份证录一段视频，请素不相识的人开锁进自己家喂猫。武汉市小动物保护协会八个核心工作人员，带着六十来位志愿者，从一月二十六号晚上到二月十一号，救了大约五千只留守的猫狗。这件事里主人得到什么了？什么都没有。他只是不想让它饿死。

我方第二点，认的是这一只。

这份感情是围着它的具体脾气长出来的。你以为它想被抱，它挠你，你就学会了不抱。你改了作息，换了猫砂，把沙发让出来。这些改动换一只同品种、同花色的就不成立了。二零一九年一项陌生情境实验里，二十九对狗和主人参加，狗在分离和重聚时找的是主人，不是陌生人，而且狗的皮质醇水平和主人的皮质醇水平正相关。它认得的是这个人。我们面对的不是一面镜子，是一个会区分人的真实他者。

最后，我方全场都会请对方回答一个问题：按对方的标准，有没有任何一种爱，是更指向对方的？如果一种都没有，那今天这道题就不成立了。

谢谢。

\begin{contingency}
\ifthen{反方把「爱」定义成“满足自我需要的情感投入”}{30 秒定义之争口径：这个定义让母爱、爱情、友情全都“更是我”，命题不可证伪，请对方先回答上面那个问题。}
\ifthen{反方抢先把判准定成“只看冲突时刻”}{承认冲突时刻是必要检验，但不是唯一检验，把第一条通道拉回来。}
\ifthen{反方拿出我方没预料到的数据}{先问机构、年份、样本，再问它测的因变量在谁身上。}
\end{contingency}
\end{speech}
\begin{stage}{2. 正一被质询防守预案}{反四质询，120 秒双边计时}
\begin{qa}[对方会问][我方回答（简短，守住前提）]
\qarow{你养宠物，是不是因为你想要陪伴？}{是，我方承认。但需要它和爱它是两件事，交朋友也是因为需要朋友。}
\qarow{你承不承认，人会按自己的审美挑宠物？}{承认。挑是养之前的事，今天问的是“对宠物的爱”，爱的是已经进家门的这一只。}
\qarow{你承不承认，有人把狗喂到走不动路？}{承认。那是不懂，不是不爱。对方要证的是指向，不是效果。}
\qarow{你承不承认，有人会弃养？}{承认。但用不爱它的人来定义爱，这个方法有问题。}
\qarow{宠物死了你会难过，难过的是不是你自己？}{难过的是它不在了。我为它难过，跟我难过，不矛盾。}
\qarow{你说照料系统，那系统长在谁身上？}{长在我身上，目标写的是对方的福祉。所有感情都发生在人身上，这不是问题。}
\qarow{你花那么多钱给它看病，是不是想让它多陪你几年？}{有这一层。请对方解释临终那一段：皮下补液换不来陪伴，只换来它少疼一点。}
\qarow{那你能不能说，你从养宠里什么都没得到？}{不能，我方从没这么说。得到是副产品，指向还在它身上。}
\qarow{你方判准里“真实需要”由谁判定？}{由它的生理与行为需要判定，不由我的想象判定。这正是我方第一条通道。}
\end{qa}
防守原则：不否认常识，不抢话筒，被逼二选一时先指出预设，再给第三种表述。全场只有一句话绝对不能说：\textbf{我从养宠里什么都没得到}。

\end{stage}
\begin{stage}{3. 正四质询反一问题链}{120 秒，双边计时}
\begin{chain}{链一：定义杀边界}{逼反方承认存在“更指向对方”的爱，否则命题不可证伪}
\q{对方说爱的更是我。请问，母亲对孩子的爱，更是谁？}{答“孩子”：那说明存在更指向对方的爱，下一问；答“母亲”：那对方的标准下有没有任何一种爱更指向对方？}
\q{请问按您的标准，什么样的行为才算“爱的更是它”？}{答不出：请评委记住，对方无法给出反例；答得出：那这个行为存不存在于养宠里？}
\q{那么对方证明的到底是“更是我”，还是“爱本来就有自我成分”？}{收束。}
\end{chain}
\begin{chain}{链二：时间尺度}{把品种选择挤到关系之前}
\q{挑品种发生在你认识它之前，还是之后？}{答“之前”：下一问。}
\q{那时候你爱的是“这一只”，还是“一只法斗”？}{答“一只法斗”：所以那还不是对宠物的爱。}
\q{今天的辩题问的是对宠物的爱，请问这份爱从什么时候开始？}{收束。}
\end{chain}
\begin{chain}{链三：因变量在谁身上}{防对方把我方的依恋研究转用}
\q{对方承不承认，动物对主人有真实的依恋？}{答“承认”：下一问。}
\q{那这份依恋是不是说明，它是一个会区分人的真实他者？}{答“是”：所以我方面对的不是投射。}
\cut{“好的，我理解为您没有否认。下一个问题。” 收束语：“感谢。对方已经承认存在更指向对方的爱，也承认它是真实的他者，那么剩下的只是分量之争。”}
\end{chain}
\end{stage}
\begin{speech}{4. 正二驳论稿}{正文 420 字 + 临场位 100 字 / 120 秒}
谢谢主席。

\reserve{此处留临场位，约 100 字：接反二刚才驳论中最用力的一点，先用一句话复述对方原话，再指出它落在我方判准的哪一条通道上，然后进入下面两个驳点。}
反方今天的立论有一个很深的问题：把“不懂”讲成了“不爱”。

反方第一个驳点，说我们爱的是自己投射上去的那个它。可是投射有个特点，它不会被现实纠正。反方拿出的每一个例子恰恰相反。你以为它爱吃罐头，它吐了，你就换。你以为它喜欢你抱，它挠你，你就不抱了。这个过程不是投射，这是被它一次次修正。反方引用的拟人化研究回答的是“人什么时候更容易拟人化”，它从来没说被拟人化的那个对象因此变成了假的。

反方第二个驳点更值得说。反方说，狗被喂到走不动路，夏天那件小裙子能把它闷出中暑，扁脸犬连喘气都费劲。我方承认这些现象都在，一条都不否认。但从“效果不好”到“动机不对”，中间少了一整步。你想想，爸妈逼你多穿一件衣服，劝你在食堂多打一碗饭，效果常常是错的，也没人因此说父母爱的是他们自己。做错事和不为你，是两件完全不同的事。反方真正需要证明的是另一句话：知道之后还不改。可这几年减肥粮、体况评分表、宠物营养师，在中国卖得越来越好。知道之后去改的那批人，就在那里。反方全场没有告诉评委他们有多少。

请评委回到判准。反方全场举的是“人会做错事”，我方问的是“这份感情朝哪边”。

\begin{contingency}
\ifthen{反二打的是“依恋研究证明它爱我”}{立刻用“真实他者”口径回应，不要说“所以它也爱我”。}
\ifthen{反二拿 84\% 这个数字}{承认数字，指出它是美国样本，然后把它归到认知偏差，再拉回判准。}
\ifthen{反二没打我方论点二}{把临场位的字数补到驳点二，加武汉案例的一句复述。}
\end{contingency}
\end{speech}
\begin{stage}{5. 正二对辩要点}{90 秒，单边计时}
\begin{bullets}
\item 进攻点（每个 15–20 秒，说完就停）：
\begin{enumerate}[leftmargin=1.8em,itemsep=2pt,topsep=2pt]
\item 对方所有的数据，因变量都在人的认知上：主人以为它不胖、主人以为它不喘。这证明的是人看不准，不是人不爱。
\item 对方的自我延伸理论，本来是解释爱情的。照这个用法，所有爱情都是自恋。
\item 对方说挑品种按我们的审美。请问，进家门之后呢？这道题问的是对宠物的爱。
\item 对方说弃养。请给一个数字：家庭弃养占城镇犬猫的多少？
\item 临终的皮下补液，换不来一分钟陪伴。对方怎么解释这笔钱？
\end{enumerate}
\item 备用点（回应对方进攻用）：
\begin{enumerate}[leftmargin=1.8em,itemsep=2pt,topsep=2pt]
\item 得到是副产品，我方从第一句就承认了。
\item Badhwar 说的是客观上可替换、现象上不可替换。爱本来就是现象层面的事。
\item 照料系统长在我身上，目标写的是对方。所有感情都发生在人身上。
\item 起点是需要，不等于指向是自己。
\item 极端情境的价值在于它切断了回报，这正是判准要看的。
\item 拍写真一年一次，喂饭一天两次。哪个更能说明日常形态？
\item 对方承认过它是真实的他者，那就不是投射。
\item 对方一直在证“有”，没有证“更”。
\end{enumerate}
\item 对方最可能问的三个问题 → 回应：
\begin{enumerate}[leftmargin=1.8em,itemsep=2pt,topsep=2pt]
\item “你承认养宠是为了陪伴吗？” → 承认，需要和爱是两件事。
\item “84\% 的主人说狗不胖，这是不知道还是不想知道？” → 人对自己的体重也估不准，用估不准推自私跳得太远。
\item “安乐死为什么大家都拖？” → 拖的是我的不舍，签字的是它的痛苦。没有人从拖延里得到好处。
\end{enumerate}
\end{bullets}
\end{stage}
\begin{stage}{6. 正三盘问问题链}{90 秒，单边计时}
\begin{chain}{链一：口径一致性检验}{让反二与反四在“有没有更指向对方的爱”上出现分歧}
\q{问反二：您方承认不承认，母亲对孩子的爱更指向孩子？}{}
\q{同一个问题问反四：您同意二辩刚才的回答吗？}{}
\q{追问不一致的那一位：那么按您方的标准，一份爱要满足什么条件才算更指向对方？}{}
\q{收：这个条件，养宠里有没有？}{}
\end{chain}
\begin{chain}{链二：把“更”逼出来}{证明反方只证了“有”，没证“更”}
\q{问反四：您方举的肥胖、扁脸、弃养，加起来能说明多少比例的饲主？}{}
\q{答“没统计”：那您方凭什么说“更”？答“很多”：请给数字。}{}
\q{问反二：您方承不承认，绝大多数饲主一辈子没弃养过？}{}
\q{收：那对方的“更”建立在少数人身上。}{}
\end{chain}
盘问目标（小结里要证明什么）：第一，反方内部对“什么算更指向对方”没有统一答案；第二，反方举的全是“有”，拿不出“更”的比例。

\end{stage}

\qaarow{你承不承认养宠能缓解孤独？}{承认，这是副产品。}{承认。得到不等于指向。}
\qaarow{你承不承认人按自己审美挑品种？}{承认，那是进门之前。}{承认，爱是进门之后长出来的。}

\end{stage}
\begin{speech}{8. 正三盘问小结稿}{正文 412 字 / 90 秒}
谢谢主席。

刚才的盘问里，我问了反方二辩和四辩同一个问题：母亲对孩子的爱，更指向谁。请评委注意他们的回答。这个问题不是绕弯子，它是反方立场的地基。如果反方承认世上有更指向对方的爱，那就请他们说出条件，我们一条条拿到养宠里去比。如果反方一种都不承认，那今天这道题在反方的口径下根本不可能成立。

我还问了第二件事：反方举的肥胖、扁脸、弃养，加起来覆盖多少饲主。反方给不出比例。请评委记住这一点。反方全场在做的事情，是举出一个又一个“有”，可这道题问的是“更”。有和更之间，隔着一个反方一直没有跨过去的数字。

回到我方的两条通道。第一条，这份感情的内容由谁塑造。反方说是我们投射的，可你以为它想被抱、它挠了你之后，你改了。改的那个人是我，让步的是我。第二条，冲突时跟着谁走。武汉封城那五千只猫狗背后，主人一点陪伴都拿不到，还是托人进了自己家的门。

老实说，到现在为止，双方的分歧只剩一个：人做错事，算不算爱错了人。我方认为不算。做错事说明的是我们不够懂它，不是我们心里装的是自己。一个把狗喂胖的人和一个把狗丢在路边的人，评委一眼就分得出来。

谢谢。

\begin{contingency}
\ifthen{反二反四答案一致且都说“更指向孩子”}{直接要条件，然后逐条搬进养宠。}
\ifthen{反三在我之后翻盘说“我方从没说过没有更指向对方的爱”}{那正好，请他给条件，自由辩第一问就问这个。}
\end{contingency}
\end{speech}
\begin{stage}{9. 自由辩战场设计}{240 秒}
\begin{battleground}{战场一：有和更之间的那个数字（前 90 秒）}
\begin{bullets}
\item 目标：让评委看到反方拿不出“更”的比例。
\item 开场问题：家庭弃养占城镇犬猫的比例是多少？
\item 对方答“没有统计” → 追问：那您方凭什么用它证明“更”？
\item 对方答“流浪动物很多” → 追问：流浪动物的主要来源是不受控繁殖和散养，请给家庭弃养的占比。
\item 对方可能反攻：你方的武汉案例也只有五千户。 → 我方防守：我方从没用它证明比例，我方用它证明机制——回报被切断之后投入还在。
\item 收束语：反方全场举的是“有人做过”，我方问的是“多数人往哪边”。
\end{bullets}
\end{battleground}
\begin{battleground}{战场二：投射会不会被纠正（中间 90 秒）}
\begin{bullets}
\item 目标：把“拟人化”从“爱的对象是假的”拉回“理解的方式”。
\item 开场问题：你以为猫想被抱，它挠了你，你会不会改？
\item 对方答“会” → 追问：那这就不是投射，是被它修正。
\item 对方答“改的还是按我的想法” → 追问：我改的依据是它的反应，还是我的想象？
\item 对方可能反攻：Packer 那 58\% 的主人就没改。 → 我方防守：承认有人不改，那是认知偏差；而对方要证的是动机，不是视力。
\item 收束语：真正的自我投射不会被对方修正，而这份感情天天在被它修正。
\end{bullets}
\end{battleground}
\begin{battleground}{战场三：临终那一段（最后 60 秒）}
\begin{bullets}
\item 目标：给评委一个画面，收束全场。
\item 开场问题：一只肾衰竭的老猫做皮下补液，这笔钱买到了什么？
\item 对方答“心安” → 追问：止痛的是它，心安的是我，请问止痛这件事的受益人是谁？
\item 对方答“想让它多活几天陪自己” → 追问：医生已经说了不会多活，主人还在做。
\item 收束语：我方承认得到，我方只说，得到是副产品。
\end{bullets}
\begin{points}{必问 （不问就亏）：}
\item 按您方的标准，有没有任何一种爱是更指向对方的？（一辩稿抛出的那个问题）
\item 家庭弃养占多少？
\item 挑品种发生在认识它之前还是之后？
\item 依恋研究的因变量在谁身上？

\begin{speech}{10. 正四结辩稿}{正文 759 字 / 210 秒，留 30–40 秒临场回应}
谢谢主席。

\reserve{此处留临场位，约 35 秒：真回应反四结辩。先复述反四最用力的一句原话，再说它落在哪条通道上，最后一句拉回我方判准。不要背稿，评委对最后一发只是念稿非常敏感。}
全场打到现在，分歧其实只剩一句话：人在爱里做错的事，算不算爱错了人。

反方今天最有力的一击，是安乐死。我方正面回答。反方说主人普遍拖延，怕自己难过。这是真的，我方不否认。但请评委把两件事分开。拖延，说明的是人不愿意面对失去，它甚至恰恰说明了这段关系在一个人生命里有多重。而最后签下那张单子的，是同一个人。他在自己完全不愿意的情况下，为了让它少疼一点，亲手结束了自己还能被它陪着的每一天。你很难在人类的生活里，找到一个比这更纯粹的决定。反方在这件事上证明的是我们有多舍不得，不是我们有多为自己。说到底，一个人从拖延里能得到什么呢？得到的不是享受，是每天早上醒来先去看它还在不在的那种折磨。

反方的第二块证据，是那些看得见的伤害：喂胖的狗、穿裙子的狗、喘不上气的法斗。我方从头到尾承认这些现象都在。我方只指出一步：从“效果不好”推到“动机不对”，中间少了一整段。这一段反方全场没有补上。

我方的两条通道还立在这里。第一条，这份感情的内容由谁塑造。答案是它。你改了作息，学会了不抱它，换了三种猫砂才找到它肯用的那一种。第二条，冲突时跟着谁走。二零二零年武汉，主人在千里之外，从监控里看着猫粮见底，然后把自己家的钥匙交给了陌生人。

我方一辩抛出的那个问题，反方到现在也没有正面回答：按他们的标准，有没有任何一种爱是更指向对方的。

我想说一件小事。

我认识的一个人，养了一只十六岁的猫。那猫后来聋了，也不太认人了。它不再在门口等他，不再在他打游戏的时候踩键盘。它大部分时间睡在阳台的一个纸箱里，醒了就叫，叫的不是他的名字，它什么都不认得了。

他每天照样按点喂药，一天两次，扶着它的下巴，等它咽下去。

在那段日子里，这段关系已经不给他任何东西了。没有陪伴，没有回应，连一个眼神都没有。

他还在做。

各位，今天我们争的不是谁在这份感情里得到得更多。我们争的是，一个人有没有能力去爱一个永远不会说“我也爱你”的生命。

我方认为有。而且我方认为，恰恰是在它什么都给不了你的那一段日子里，这份爱才露出了它本来的方向。

它一直朝着它。

谢谢。
