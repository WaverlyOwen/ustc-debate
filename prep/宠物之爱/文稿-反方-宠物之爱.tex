\begin{thesisbox}[全队第一纪律]每个环节至少说一次“我方不否认你爱它”。这不是客套，这是让评委愿意继续听下去的门票\end{thesisbox}
\begin{speech}{1. 反一开篇立论稿}{正文 776 字 / 180 秒}
谢谢主席。

刚才的质询里，正方一辩已经承认了两件事：人会按自己的审美挑宠物，人也从养宠里得到陪伴。请评委先把这两句话记下来。

我先说清楚一件事，免得后面被误会。我方不认为养宠的人自私，更不认为你不爱它。我方今天要说的从来不是“你不爱”，而是这份爱的重心落在哪一边。

定义上我方和正方没有大分歧。爱是对某个对象的深挚感情，以及由这份感情带来的关切和行动。

真正要争的是「更」。这是一道比较题。两边都在，比的是分量。怎么比？我方也给两条通道。第一，这份爱的内容是被谁塑造的。第二，两边的需要真正撞上的时候，它跟着谁走。这两条不是我方偏心设计的，正方待会儿也可以用，我方只求评委在同一把尺子下面听完两边。

我方第一点，这份爱从我的缺口开始。

心理学里有一个被引用了近二十年的理论，叫拟人化三因素理论，二零零七年发表在《心理学评论》上。它说，人把心理活动安到非人的东西身上，有三个开关，其中一个叫社交动机：越是缺少和人的连接，越容易这么做。这不是道德判断，这是一个人人都有的机制。请评委顺着这个机制往下看一步。我们不只是把心思安上去，我们连它长什么样都按自己的喜好挑。学者塞尔佩尔把这个叫拟人化选择：人喜欢圆脸、大眼睛和短鼻子，因为那像婴儿，于是一代一代把狗选成了今天这个样子。结果是什么？二零一二年一项针对二百八十五只犬、六十八个品种的研究发现，在患短头阻塞性气道综合征的狗里，将近六成的主人说，自家狗没有呼吸问题。它就在你面前喘，你说它没事。

我方第二点：真到冲突的时候，让路的是它。

日常的小让步区分不了双方，正方让的我方也承认。可我们得看撞上的那一刻。美国宠物肥胖防治协会的调查里，将近六成的狗和六成的猫超重或者肥胖，而八成多的狗主人说自家狗体型很健康。二零二一年一篇综述写得更直接：夏天给狗穿上衣服，热量散不出去，不到一个钟头就可能中暑，甚至死亡。你有没有想过，那件小裙子是给谁穿的？照片是发给谁看的？

我方全场要请对方回答一个问题：给狗穿裙子拍照这件事，受益人是谁。

我方承认这份感情真实。我方只是想说，它最深的那一层，服务的还是我们自己。

谢谢。

\begin{contingency}
\ifthen{正方把「爱」定义成“为对方自身之故的关切”}{30 秒定义之争口径：这个定义把结论藏进了定义，我方在它之下不可能成立；请对方回答“把狗喂到走不动路，算不算爱它”。}
\ifthen{正方问“有没有任何一种爱更指向对方”}{正面答“有”，然后立刻要条件，把条件搬到养宠里逐条比。绝不能答“一种都没有”。}
\ifthen{正四质询逼我方承认挑品种在关系之前}{承认，并反问：为什么明知道法斗会喘，它还是卖得最好。}
\end{contingency}
\end{speech}
\begin{stage}{2. 反一被质询防守预案}{正四质询，120 秒双边计时}
\begin{qa}[对方会问][我方回答（简短，守住前提）]
\qarow{母亲对孩子的爱，更是谁？}{更是孩子。我方承认存在更指向对方的爱。}
\qarow{那什么条件下算“更指向对方”？}{两条：内容由对方塑造，冲突时为对方让路。我方全场用的就是这两条。}
\qarow{养宠满不满足这两条？}{不满足。挑品种是按我的审美，喂养是按我的习惯。}
\qarow{挑品种发生在认识它之前，对吗？}{对。但选择每天都在重复，法斗现在还是最好卖的犬种之一。}
\qarow{那进家门之后的爱呢？}{进家门之后我方也承认有爱，我方比的是分量。}
\qarow{你方是不是在说所有人都在害宠物？}{不是。我方从没这么说，我方说的是重心。}
\qarow{你承不承认动物对主人有真实依恋？}{承认。它越真实，我方越成立：我们得到了一个会回应我们的对象。}
\qarow{那你方承不承认宠物是真实的他者？}{承认。我方从没说它是假的。}
\qarow{按你方标准，有没有爱是更指向对方的？}{有。比如一个母亲为孩子放弃自己的职业规划。养宠里这种放弃很少。}
\qarow{你们是不是在说人不该养宠？}{不是。我方的立场里没有任何一句应然判断。}
\end{qa}
防守原则：凡是与常识冲突的都不否认，凡是道德指控都当场撇清。全场只有一句话绝对不能说：\textbf{养宠的人在骗自己}。

\end{stage}
\begin{stage}{3. 反四质询正一问题链}{120 秒，双边计时}
\begin{chain}{链一：承认链}{拿到“按自己审美挑”“从中得到陪伴”两个承认，反一开头要用}
\q{请问，你是先认识它，还是先决定养一只什么样的？}{答“先决定”:下一问。}
\q{决定的时候，依据的是你的喜好，还是它的需要？}{答“我的喜好”：记住这句。}
\q{养了之后，它有没有让你觉得被需要？}{答“有”：收。}
\end{chain}
\begin{chain}{链二：矛盾链}{让正方在“付出”与“效果”之间二选一}
\q{你方说为它花钱就是爱它，对吗？}{答“对”：下一问；答“不对”：那你方用什么证明爱它？}
\q{给狗买裙子花的钱，算不算爱它？}{答“算”：那爱它的标准就是花钱；答“不算”：那花钱不能证明爱它。}
\q{那么医疗支出凭什么能证明？}{收。}
\end{chain}
\begin{chain}{链三：边界链}{逼正方给出“它的真实需要”由谁判定}
\q{你方判准说“它的真实需要”，请问由谁判定？}{答“兽医”：下一问；答“主人”：那就是我的想法。}
\q{按兽医的标准，八成多的主人以为狗不胖，对吗？}{答“对”：下一问；答“不对”：请给你方的数字。}
\q{那这算不算没按它的需要来？}{收。}
\cut{“好的，这个我理解为您没有否认。下一个问题。” 收束语：“感谢。对方已经承认，挑的时候按的是自己的喜好，养了之后也确实被满足了。”}
\end{chain}
\end{stage}
\begin{speech}{4. 反二驳论稿}{正文 513 字 / 120 秒}
谢谢主席。

正方立论最大的问题，是把“它爱我”当成了“我爱它”。

正方拿出的核心证据是那个陌生情境实验：二十九对狗和主人，狗在重聚时找的是主人，狗和主人的皮质醇还同步。我方一点都不反对这个结论。可是请评委看清楚，这个实验测的东西长在谁身上。测的是狗的行为、狗的激素，还有狗对人的偏好。它证明得越漂亮，越说明我们在这段关系里拿到了一个真正会回应我们的对象。这恰恰是我方的论点。正方等于把自己的论据递给了我方。

正方第二个说法是不可替代：换一只同款就不成立。正方自己引的那本《斯坦福哲学百科》里，巴德瓦尔的结论写得很清楚：被爱者在客观上是可替换的，只是在现象上不可替换。现象上是什么意思？就是在你的感受里不可替换。那么请问，这份不可替代性存在于哪里？存在于你的感受里。这不正是我方要说的吗。再看真实的生活：一只猫走了，很多人一两年后会再养一只，然后很快又不可替换了。不可替换的不是它，是它占的那个位置，而位置是我的。

我方承认正方说的武汉那件事让人动容，我方也相信那些主人是真的着急。我方只问一句：那五千户，放在全国一亿两千六百万只城镇犬猫的基数里，是多少。正方全场都在举“有人这样做过”，而这道题问的是“多数人往哪边”。这两件事之间隔着一个数字，正方从开场到现在没有给过。

请评委回到判准。正方到现在为止，一条都没有正面回答我方的问题：那件小裙子，是给谁穿的。

\begin{contingency}
\ifthen{正一立论没用依恋研究}{把驳点一换成“花钱不能证明为谁”，用买裙子那一问代替。}
\ifthen{正方先自己承认“得到是副产品”}{直接追问：副产品为什么每一次都恰好出现，请给一个例外。}
\ifthen{正方指控我方犬儒}{立刻撇清：“我方承认你爱它，我方全场没有一句说养宠的人虚伪。”}
\end{contingency}
\end{speech}
\begin{stage}{5. 反二对辩要点}{90 秒，单边计时}
\begin{bullets}
\item 进攻点（每个 15–20 秒，说完就停）：
\begin{enumerate}[leftmargin=1.8em,itemsep=2pt,topsep=2pt]
\item 你方所有的依恋研究，测的都是动物身上的指标。这道题问的是我爱谁。
\item 巴德瓦尔说的是现象上不可替换。现象在哪里？在你的感受里。
\item 那件小裙子是给谁穿的，照片发给谁看的？这个问题你方还没答。
\item 明知道法斗会喘，为什么它还是最好卖的犬种之一？
\item 武汉那五千户，占一亿两千六百万只的多少？
\end{enumerate}
\item 备用点（回应对方进攻用）：
\begin{enumerate}[leftmargin=1.8em,itemsep=2pt,topsep=2pt]
\item 我方承认你爱它，我方比的是分量，不是有无。
\item 无知和不看是两件事。八成多的主人说狗不胖，那不是没学过营养学。
\item 拟人化研究不是说它是假的，是说填进去的内容是我们的。
\item 照料系统长在人身上，宠物只是那把钥匙。
\item 葬礼上它已经不在了，仪式安慰的是活着的人。
\item 救助带来的道德满足感是真实的回报，而且比陪伴更强烈。
\item 你方举的是极端情境，我方问的是日常。
\item 绝育的时间点，多数人是它开始嚎叫的那一周。
\end{enumerate}
\item 对方最可能问的三个问题 → 回应：
\begin{enumerate}[leftmargin=1.8em,itemsep=2pt,topsep=2pt]
\item “母亲对孩子的爱更是谁？” → 更是孩子，我方承认存在更指向对方的爱，请你方给条件，我们逐条比。
\item “临终的皮下补液怎么解释？” → 止痛的是它，交代是给自己的；而且请问在那之前拖了多久。
\item “你方是不是在说人都自私？” → 不是，我方全场没有一句道德判断。
\end{enumerate}
\end{bullets}
\end{stage}
\begin{stage}{6. 反三盘问问题链}{90 秒，单边计时}
\begin{chain}{链一：口径一致性检验}{让正二与正四在“花钱能不能证明爱它”上出现分歧}
\q{问正二：给狗买裙子的钱，算不算爱它？}{答“算”：那标准就是花钱；答“不算”：记住这句。}
\q{同一个问题问正四：您同意二辩的回答吗？}{答“同意”：口径锁死；答“不同意”：两人不一致。}
\q{那你方用医疗支出证明爱它，凭的是花钱吗？}{答“是”：那买裙子也该算；答“不是”：那凭的是什么。}
\close{花钱证明的是它重要，不证明这份爱为谁。}
\end{chain}
\begin{chain}{链二：把边界逼出来}{证明爱的边界在饲主这边}
\q{问正四：工作调去外地带不走它，你方建议送人吗？}{答“不送”：那带不走的人怎么办；答“送”：下一问。}
\q{托付出去之后，这份爱还算你的吗？}{答“算”：那爱不必在场；答“不算”：那边界就在你这边。}
\q{问正二：为宠物改变，是不是都停在你能接受的地方？}{答“是”：收；答“不是”：请举一个越线的例子。}
\close{这条线是谁画的，一清二楚。}
\end{chain}
盘问目标（小结里要证明什么）：第一，正方在“花钱能否证明指向”上口径不一；第二，正方承认了改变的边界由饲主自己划定。

\end{stage}
\begin{stage}{7. 反二、反四被盘问防守预案}{两人口径必须一致}
\begin{qaa}[对方会问][二辩答][四辩答（必须一致）]
\qaarow{母亲对孩子的爱更是谁？}{更是孩子。}{更是孩子，我方承认有这种爱。}
\qaarow{那什么条件算更指向对方？}{内容由对方塑造，冲突时为对方让步。}{同上，两条。}
\qaarow{你方是不是说人都自私？}{不是，我方没有道德判断。}{不是，我方承认你爱它。}
\qaarow{你方承认动物有真实依恋吗？}{承认，它越真实我方越成立。}{承认，我们得到了真实的回应。}
\qaarow{肥胖数据是美国的吧？}{是，这是我方的局限，中国没有可比调查。}{是，美国样本，但机制一样。}
\qaarow{你方怎么解释临终补液？}{止痛的是它，交代是给自己的。}{同上，而且要问在那之前拖了多久。}
\qaarow{弃养占多少？}{我方不用它证明比例，只用它标出边界。}{同上，弃养标的是那条线。}
\end{qaa}

\end{stage}
\begin{speech}{8. 反三盘问小结稿}{正文 306 字 + 临场位 80 字 / 90 秒}
谢谢主席。

\reserve{此处留临场位，约 80 字：直接回应正三小结里最用力的一句。正三很可能会说我方拿不出“更”的比例，这里先接住：我方举的不是比例，是三个人人都会经过的时刻。}
刚才的盘问里我问了两件事。第一件，给狗买裙子的钱算不算爱它。请评委注意正方二辩和四辩的回答。说算，那爱的标准就只剩下花钱，医疗支出也就证明不了什么；说不算，那正方就得告诉我们，凭什么同样是花钱，给它治病的那一笔能证明爱它，给它买裙子的那一笔就不能。

第二件，如果工作调动带不走它，怎么办。正方给的所有答案，都停在同一个位置上：能带走就带走，带不走就托付。没有一个人说到辞职，也没有一个人说到不去。请评委想一想，这条线是谁画的。是我们自己画的，画在我们能接受的地方，一寸也不多。

这就是我方两条通道的意思。第一条：它长什么样，吃多少，照片拍成什么样子，都是按我们的喜好定的。第二条：撞上的时候，被调整的是它。

到这里，正方全场还是没有回答我方一辩问的那一句：那件小裙子，究竟是给谁穿的。

谢谢。

\begin{contingency}
\ifthen{正三小结主打“反方拿不出比例”}{临场位里正面接：我方不比人数，我方比时刻，而那三个时刻每个饲主都会经过。}
\ifthen{正二正四口径一致且都说“不算”}{直接推进：“那请正方给出判准：同样是花钱，哪一笔算，哪一笔不算。”}
\end{contingency}
\end{speech}
\begin{stage}{9. 自由辩战场设计}{240 秒}
\begin{battleground}{战场一：那件小裙子是给谁穿的（前 90 秒）}
\begin{bullets}
\item 目标：让评委在一个具体画面上看见“受益人是人”。
\item 开场问题：夏天给狗穿裙子拍照，受益人是谁？
\item 对方答“它也开心” → 追问：热量散不出去，不到一个钟头可能中暑，它开心在哪里？
\item 对方答“我方也反对这种做法” → 追问：那请问反对的人多，还是拍的人多？青年志的问卷里，买服装配饰的超过一半。
\item 对方可能反攻：那给孩子拍照也是自恋吗？ → 我方防守：给孩子拍照，孩子会长大、会说不要拍。它不会。
\item 收束语：一件它穿不了的衣服，一张它看不懂的照片，这两样东西的受益人写在脸上。
\end{bullets}
\end{battleground}
\begin{battleground}{战场二：依恋研究测的是谁（中间 90 秒）}
\begin{bullets}
\item 目标：把正方的核心数据转成我方的证据。
\item 开场问题：那个陌生情境实验，因变量是狗的行为还是人的行为？
\item 对方答“狗的” → 追问：那它证明的是狗认人，还是人爱狗？
\item 对方答“它是真实的他者” → 追问：我方完全同意。正因为它真实地回应我们，我们才留下来。请问这算谁被满足了？
\item 对方可能反攻：照你这么说，被爱就不能算爱人了？ → 我方防守：能。我方只说，这份数据支持不了正方，它谁都不偏。
\item 收束语：正方全场最硬的三组数据，测的全是动物身上的指标。
\end{bullets}
\end{battleground}
\begin{battleground}{战场三：边界是谁画的（最后 60 秒）}
\begin{bullets}
\item 目标：用弃养与生活变动收束，不新开战场。
\item 开场问题：工作调动带不走它，你方怎么办？
\item 对方答“想办法” → 追问：想办法的上限在哪里？会不会辞职？
\item 收束语：中秋节那天被送到北京房山救助站的那只八哥犬，它的主人也爱过它。它的主人只是要去外地。
\end{bullets}
\begin{points}{必问 （不问就亏）：}
\item 那件小裙子是给谁穿的？（一辩稿抛出的那个问题）
\item 依恋研究的因变量长在谁身上？
\item 同样是花钱，哪一笔算爱它，哪一笔不算？

\begin{speech}{10. 反四结辩稿}{正文 976 字 / 210 秒，封路式}
谢谢主席。

我先做一件事：把正方四辩待会儿要走的那条路，提前指出来。

正方四辩接下来大概率会给各位讲一个故事。一只很老的猫，或者一只聋了的狗，已经不认得主人了，主人还在每天喂药。然后他会说，你看，在它什么都给不了的时候，这个人还在做，所以爱的是它。

这个故事我方相信是真的，讲的人也是真诚的。可是请评委听清楚，这里面有没被说出来的那一半。

那个每天喂药的人，为什么喂？因为停下来他受不了。喂药让他能对自己说一句“我尽力了”。这句话说给谁听？说给他自己。我方不是说这不高尚，我方是说，请评委不要把“他很痛苦地坚持”直接读成“他为的是它”。痛苦地坚持，恰恰说明这段关系在他生命里有多重。重的是谁的生命？

正方全场还会收在一句话上：一个人有没有能力去爱一个不会说“我也爱你”的生命。这句话很好听。可它回避了我方从第一分钟就在问的东西：我们给它的这份爱，是按它的样子给的，还是按我们想给的样子给的。

现在回到判准。双方给的是同一套判准，两条通道。

第一条，这份爱的内容由谁塑造。我方给了三层证据。我们按“像婴儿”的标准挑它的脸，把狗选成了喘不上气的样子；二零一二年那项针对二百八十五只犬的研究里，将近六成患病狗的主人说自家狗没有呼吸问题。我们按自己的习惯喂它，将近六成的狗和六成的猫超重或肥胖，而八成多的主人说它很健康。我们按自己的需要给它定位，国内一份二零二五年的青年养宠问卷里，现实中把它当孩子的有四成多，理想中只有两成半。正方在这条通道上，全场只回了一句话：那是不懂。

可是请各位想一想，不懂是听不见吗？它天天在你面前喘。

第二条，撞上的时候跟着谁走。正方举了武汉，我方承认那件事让人动容，也承认那五千户主人是真的着急。我方只是提醒评委算一笔账：全国城镇犬猫一亿两千六百万只。而那条线真正在哪里，中秋节那天送到北京房山救助站的那只八哥犬知道。它的主人也爱过它。它的主人只是要去外地。

我方今天没有一句是在说养宠的人自私。

我想请各位想一件很小的事。

你的手机相册里，大概有几百张它的照片。

它那边，一张你的都没有。

它不知道你叫什么，不知道你在哪里上班，不知道你昨天为什么回来得那么晚。你难过的时候抱着它，它其实不知道你在难过。

这不是它的错。它就是这样一种生命。

所以这份关系从一开始就不是对等的。我们在里面投进去的想象、期待、委屈、盼望，它一样也接不住。它接不住，我们还是投。投给谁了？投给了那个被我们想象出来的它，而那个它，是用我们自己的东西搭起来的。

承认这一点，不是让我们爱得少一点。

恰恰相反。只有先承认那面镜子在，我们才有可能放下镜子，低下头，看一眼真正的它到底想要什么。

它可能只是想下楼多闻十分钟。

谢谢。
