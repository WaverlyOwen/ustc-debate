# 正赛文稿：对知识网红的崇拜让我们离真知更近 / 更远（正方：更近）

- **赛制**：中国科学技术大学新生辩论赛（正方先立论，正四最后结辩）
- **口径来源**：01-备赛文档 第十节 10.1 正方口径表。本文稿所有定义、判准、论点、数据均取自该表；允许换说法，不允许换意思、换数字。
- **全场一句话立论**：崇拜不是终点，是入口——它把抽象的知识变成一个你愿意反复靠近的人，让本来不会开始的人开始了，也让真正的专家愿意留在公共场域，所以我们离真知更近。
- **全场只守两句话**：①"更近"是位移，不是到达。②这笔账要记对人——知识网红的功劳不算崇拜的，短视频媒介的毛病也不算崇拜的。

## 1. 正一开篇立论稿（正文 775 字 / 180 秒）

谢谢主席。先说清三个词。**知识网红**，指在网上传播知识、并因此获得大量关注的创作者。**崇拜**，词典释义是尊敬钦佩；今天的语境里，指明显强于一般关注的推崇与信任——你会持续追着看，会优先采信他的说法。崇拜是情感的强度，不是认知的关闭；“盲目”两个字词典里没有，是对方要替我们加上的。**真知**是正确而有理据的认识，有三层：内容对，知道自己凭什么认为它对，错了能改。

判准呢？题目问“更近”还是“更远”，是比较级，比的是净位移。跟谁比？跟同样在看这些人、但没有崇拜的自己比。正方要证明接触增量大于理据损耗，反方反过来。还有两条对称的规矩请评委记住：**知识网红的功劳不能记在崇拜头上，短视频媒介的毛病也不能记在崇拜头上。**

我方第一点，**门票效应**：崇拜是把一次性接触变成持续关注的现实机制。人是先被一个具体的人吸引，才走到一个领域门口的——Katz 和 Lazarsfeld 1955 年管这叫意见领袖。中国科协第十三次公民科学素质抽样调查显示，2023 年我国公民具备科学素质的比例达 14.14%，互联网作为首选科技信息渠道的比例升到 58.3%。这条曲线不是崇拜画出来的，崇拜负责的是转化率：同一条视频推到上亿人面前，只有对讲的人有了感情的才会追更，两年后还记得他。汪品先院士入驻 B 站后说，在学校讲课只有几百个学生，现在有这么多人可以听讲，这是老师最大的享受。**是那份热情，把一位院士留在了公共场域。**

我方第二点，**崇拜给错误一个可以被撤回的地址**。Hardwig 1985 年说过：什么都要自己验证的人，持有的信念只会更粗糙、更不理性。问题不是依赖不依赖，是依赖谁。崇拜的对象是有名有姓的活人，可以被查资质、被质问。2024 年 12 月，有账号用 AI 合成张文宏的脸和声音卖蛋白棒，卖出 1266 件。可假的能被戳穿，是因为真人还在——他能出来说这不是我，媒体能追，平台能封。**如果大家信的只是一句无名的“蛋白棒对身体好”，没有任何一个人有资格出来否认它。**

所以我方全场反复请对方回答：**一个不崇拜任何人、只信自己亲手验证过的证据的普通人，在现实中是谁？** 我方从不认为崇拜的人掌握了真知。我方说的是，他动了。题目问的是更近，不是到达。谢谢。

**如果……就……**
- 如果对方把"崇拜"定义成"无条件盲从"→ 立刻回："这四个字是对方加的，词典里只有'尊敬钦佩'。请对方用我们两方都承认的定义来打这场比赛。"
- 如果对方要求我方证明崇拜者理解更深 → 不接。回："我方从不主张这一点，我方主张的是位移。请对方回答，起点前移算不算更近。"
- 如果对方拿出我方没预料到的数据 → 先问出处与自变量："请问这项研究测的自变量是崇拜，还是媒介？"
- 如果时间不够 → 删汪品先案例的引语，保留"是那份热情把院士留下来"这一句。

## 3. 正四质询反一问题链（120 秒，双边计时）

**总目标**：把反方逼到"归因"这一格上，拿到"对方的证据不是关于崇拜的"这个承认，为正二驳论铺路。

**链一：归因链**（目标：让反方承认其核心证据的自变量不是崇拜）
1. "您方承认，短视频这种形式本身会让人觉得容易，对吗？" → 答"是"：进 2；答"否"：问"那您方引 Salomon 1984 做什么？"
2. "那这个'觉得容易'，在崇拜发生之前就已经发生了，对吗？" → 答"是"：进 3；答"否"：问"是先刷到视频，还是先崇拜？"
3. "所以这笔账该记在媒介头上，还是记在崇拜头上？" → 任何回答都进 4。
4. "请问您方今天有哪一条数据，自变量是'崇拜'？"（此问不必等答完）

**链二：位移链**（目标：让反方承认"没有到达"不等于"没有更近"）
1. "一个人以前没听说过引力波，现在能说出个大概，他离真知近了还是远了？" → 答"近了"：收；答"远了"：进 2。
2. "那中学物理教材也简化了推导，它让我们离真知更远吗？" → 答"是"：指出该标准下一切科普皆为负分；答"否"：进 3。
3. "所以简化本身不扣分，扣分的是别的东西。是什么？"

**链三：对照组链**（目标：暴露反方的对照组不存在）
1. "您方比较的对象，是不崇拜但一样在看的人，对吗？" → 答"是"：进 2；答"否"：问"那是谁？"
2. "这个人看完视频之后，会去查原始文献吗？" → 答"会"：问"有数据吗？"；答"不会"：收束。

**打断用语**："好的，我理解为您没有否认。下一个问题。"
**收束语**："感谢。对方到现在没有拿出一条自变量是崇拜的数据，这一点我方二辩会继续。"

## 4. 正二驳论稿（正文 405 字 + 临场位 100 字 / 120 秒）

对方立论最大的问题只有一个：**他们花了三分钟骂媒介，却把账单寄给了崇拜。**

第一，对方全部的证据，没有一条是关于崇拜的。Fisher 和 Keil 2015 年那 9 项实验，自变量是有没有用互联网搜索；Salomon 1984 年那 124 名六年级学生，自变量是觉得这个媒介难不难；Rozenblit 和 Keil 2002 年的解释深度错觉，说的是全人类对所有事物的普遍状态。三份研究，三个自变量，没有一个叫崇拜。按我方一辩立下、对方也没有否认的那条对称规矩：短视频媒介的毛病，不能记在崇拜头上。

第二，对方的判准测的是到达，不是位移。他们说崇拜者不能独立复述推理链条——可这个标准把中学教材、科普书、大学通识课全都判成了负分，因为它们无一例外省略了推导。一个让所有知识普及都变成“更远”的标准，衡量的不是真知，是专业训练。我方承认崇拜者没到，我方说的是他动了。请对方正面回答：起点前移，算不算更近？

第三，对方说崇拜让人只信人不信理。那人不信人还能信什么？真正的问题是依赖谁——依赖一个能被查资质、被质问的具名的人，还是依赖一句无名的“网上说”。

## 8. 正三盘问小结稿（正文 403 字 / 90 秒）

刚才的盘问里，对方承认了两件事。

第一，他们承认崇拜确实带来了更多接触。第二，他们承认自己没有量化过这份“损耗”到底有多大。这两句话放在一起意味着什么？意味着这道题的账，对方只写了借方，没写贷方——他们不否认收入，却拿不出支出的数字，就宣布这家公司在亏损。

而当我方追问“崇拜和信任的分界线在哪里”，对方的回答一直在两个极端之间摇摆：线划得宽，一个信任自己导师的研究生也算崇拜，那对方就得承认崇拜者也可以离真知很近；线划得窄，只有最极端的粉丝才算，那对方全部论证只适用于一小撮人，和“我们”没有关系。这条线今天被问了三次，落点换了三次——标准自己都还没定下来，评委没法拿它判这道题。

所以分歧已经很清楚：**对方在测量一个人有没有到达，我方在测量他有没有往前走。** 对方举的每一个例子——错觉、免检、不查证——说的都是“他还没到”。可题目问的是“更近”。一个人从零走到三，他没有到十，但他动了三步。这三步，对方今天一步都没有还给我们。请对方正面回答我方一辩那个问题：一个不崇拜任何人、只信自己亲手验证过的证据的普通人，在现实中到底是谁？

## 9. 自由辩战场设计（240 秒）

### 战场一：归因（前 90 秒，主战场）
- **目标**：让评委记住"对方的证据不是关于崇拜的"。
- **开场问题**："请问对方，今天有哪一条数据的自变量是崇拜？"
- 对方答"我们靠机制论证" → 追问："那请把机制走完：从崇拜到少查证，中间那一步的证据在哪里？"
- 对方答"你方也没有" → 追问："我方承认双方都在机制层。那请评委注意，对方的机制里有一个洞：他们必须证明崇拜者比不崇拜的人更少检验，这句经验命题他们全场没给过任何东西。"
- 对方反攻："你方的科学素质数据也不是关于崇拜的。" → 防守："我方一辩就说过，它只用来证明渠道转移，转化率那一步由机制承担。我方主动交代边界，对方交代了吗？"
- **收束语**："对方骂的是媒介，寄来的账单写着崇拜。"

### 战场二：位移不是到达（中 90 秒）
- **目标**：把评委的判准从"到达"拉到"位移"。
- **开场问题**："起点前移，算不算更近？"
- 对方答"不算" → 追问："那请问中学物理教材算不算让我们更远？"
- 对方答"算，但同时更远了" → 追问："请给出净额。您方的损耗有多大？"
- 对方反攻："错觉会让人以为自己懂了，反而不去学。" → 防守："错觉是人性，Rozenblit 和 Keil 说的是全人类。请把崇拜这一层的独立贡献拿出来。"
- **收束语**："我方从不说他到了。我方说他动了，而对方一步都没还给我们。"

### 战场三（后 60 秒，收束，不开新战场）
- 重复一句话立论；重复必问；把"这笔账要记对人"再说一次。

2. 起点前移算不算更近？
3. 您方那个"不崇拜但会去查文献"的普通人，是谁？
4. 崇拜和信任的分界线在哪？
5. 如果大家信的是一句无名的话，谁有资格出来否认它？

## 10. 正四结辩稿（正文 787 字 / 210 秒，留 30–40 秒临场回应）

**〔开场留 30–40 秒真回应反四刚才的封路，不要念稿。模板：反四一定会说“正方接下来会说位移不是到达”——那就承认：“对方四辩预判对了，因为这确实是本题的分歧所在；可他用了三分钟告诉各位我方要说什么，却没告诉各位我方为什么说错了。”〕**

打到现在，分歧只剩一个：**衡量"更近"，我们该测量他有没有到，还是该测量他有没有动。**

对方最有力的一点我不回避，就是那句"错觉是人性，崇拜是按住除错开关的手"。这句话写得很漂亮。但请评委看它成立需要什么：需要证明崇拜者比不崇拜的人更少去检验。这是一句经验命题，需要数据。对方全场给了我们三份研究——一份关于上网搜索，一份关于看电视的小学生，一份关于全人类的普遍错觉。三份研究，没有一份的自变量叫崇拜。对方描述了一只手，却始终没有证明那只手是崇拜的手。要证明它是，对方需要的是一组对照：同样看着同一个人，一群人有那份感情，一群人没有，然后告诉我们哪一群更少去查证。这组对照，今天一次也没有出现过。而我方一辩立下的两条规矩，对方从头到尾没有反对过：**知识网红的功劳不能记在崇拜头上，短视频媒介的毛病也不能记在崇拜头上。** 今天违反第二条的，是对方。

我方两个点还站着。第一，崇拜是把一次性接触变成持续关注的现实机制——算法能制造一次点击，制造不了三年的追更；汪品先院士说，有这么多人可以听讲，这是老师最大的享受，那份热情就是让真专家留下来的报酬。第二，崇拜给错误一个可以被撤回的地址——正因为大家信的是一个有名有姓的人，假的张文宏才能被真的张文宏戳穿，四部门才能发文要求核验资质。而我方全场问了对方四次的那个问题，对方一次也没有正面回答：**一个不崇拜任何人、只信自己亲手验证过的证据的普通人，在现实中到底是谁？**

最后我想说一件很小的事。

高三那年有个晚上，我在宿舍刷到一个人讲相对论。我没有听懂。我只记住了他说话的样子——他讲到一个地方的时候眼睛是亮的。我不知道那是什么，但我想知道。

四年后，我在图书馆翻开一本正经的教材，读到那一章，发现他当年讲错了一个地方。

我没有难过。我合上手机，继续读下去。

那一刻我不再需要他了。可是，把我带到这本书面前的，就是当年那份说不出口的崇拜。

评委，我们今天争的其实不是崇拜好不好。我们争的是，一个普通人走向真知的那条路，到底是从一本书开始的，还是从一个人开始的。我方的答案是：从一个人开始，然后，在某一天，学会不再需要他。

**祛魅，从来都是崇拜的产物。** 谢谢。
