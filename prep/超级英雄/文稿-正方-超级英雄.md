# 正赛文稿：超级英雄的出现，对世界而言更是幸福（正方）

- **赛制**：中国科学技术大学新生辩论赛（四对四）
- **口径来源**：备赛文档 第十节 10.1 正方口径表。本文稿所有定义、判准、论点、数据均取自该表
- **证据纪律**：漫威、DC 的情节是设定，不是论据。全场只用现实世界的对应物。举例说明"我方说的是哪一类人"时可以提一句漫画，说完立刻加一句"这是设定，不是我方论据"

## 1. 正一开篇立论稿（正文 835 字 / 180 秒）

谢谢主席，各位评委。

开宗明义，我先说清三个词。超级英雄，指拥有远超常人的能力、主动用这种能力介入公共安全事务的人。他行动的依据是自己的判断。我方承认，他不由现有法律和权力机构授权，也不由它们问责。这三条缺一不可。第三条我方自己说出来，不藏。出现，不是某一次出手，是这种人存在于世界上成为事实，并且被世界知道。灾难，指的不是存在风险，是世界整体的处境重大地变糟，并且改不回来。

今天的判准，我方主张这样定：把有超级英雄的世界和没有他的世界放在一起，长期看，普通人的处境是变好还是变坏。处境有两项。一是安全，也就是能不能不被伤害。二是自主，也就是能不能靠自己和自己的制度决定怎么活。在这个标准下，我方要证明他挡下的伤害真实而且重大，秩序代价没有大到抵消它。对方要证明的是反过来的事。只讲"有风险"不够。

我方第一点，救得下来。

世界上有一类伤害，停不停得下来只取决于那一刻有没有人具备相应的能力。一九八六年四月二十六日凌晨，切尔诺贝利。世界卫生组织的记载是，当时现场的六百人里，一百三十四人受到极高剂量照射并出现急性放射病，二十八人在三个月内死亡。不是没人愿意去。是只能用人的身体去顶。请评委记住这个画面，我方说的能力缺口就是它。技术会进步，可人是在具体的那几分钟里死的。

我方第二点，恶做不成。

美国国家司法研究所二〇一六年那份报告的第一条结论是，让人不敢犯罪的是被抓住的确定性，不是惩罚有多重。一份汇总了六十五项研究的系统综述也发现，把力量放到最危险的地方，那里的犯罪下降了。一九九四年的卢旺达，一百天，联合国估计超过一百万人遇害，而维和部队的兵力在四月二十一日从两千一百多人减到两百七十人。那一百天里缺的不是道理。是当场有人挡在中间。

我方第三点，人会跟着做。这一点我讲得短一些，也讲得老实一些。

二〇〇五年有一项实验，四十九个学生，被要求列举"超级英雄"这个类别的那一组，承诺的志愿服务时间是对照组的两倍多。同一篇论文里还有一个方向相反的结果，我方后面自己会说。我方的判断是，一个真的存在的人，会把"这类事有人在做"变成常识，而常识会把门槛往下压。

最后，我方全场都会请对方回答一个问题。你说的灾难，是和哪个世界比？如果是和一个能及时救人的完美制度比，那个世界并不存在。谢谢。

- 如果反方抢先把定义拉到"不受约束的暴力持有者"，就用一句话拉回：删掉"英雄"两个字，那是另一道题。
- 如果反方不接判准，就在质询里直接问："对方是否接受长期净变化这个标准？"

## 3. 正四质询反一问题链（120 秒，双边计时）

**链一：比较对象**（目标：逼反方说出"灾难"是和哪个世界比，暴露他们在和一个不存在的理想制度比）

1. 对方说的灾难，是和哪个世界比？ → 答"和现在的世界比"：那请问，现在的世界里卢旺达那一百天有人挡住了吗？ → 答"和一个有制度约束的世界比"：那个世界现在存在吗？
2. 一九九四年四月二十一日，联合国维和部队减到两百七十人，这个事实对方承认吗？ → 承认：那当时缺的是能力还是决心？ → 不承认：这是联合国自己的记载。
3. 如果当时现场有一个不用等安理会表决的人，那一百天会不会不一样？ → 答"不一定"：不一定，就是有可能，对吗？

打断用语：好的，我理解为您没有否认。下一个问题。

收束语：感谢。对方到现在没有回答，他们说的灾难是和哪个世界比。

**链二：不受问责等于灾难吗**（目标：把"不受问责"从结论打回成前提）

1. 对方是否认为，只要一种力量不受问责，它就是灾难？ → 答"是"：那消防员在火场里的每一个判断，当场受谁问责？
2. 对方是否承认，我方一辩自己说出了他不受问责？ → 承认：那这一点不是对方发现的，是我方给的前提。
3. 前提不等于结论。请问对方，从"不受问责"到"灾难"，中间那一步是什么？

收束语：对方把我方的前提当成了对方的结论。

**链三：证据来源**（目标：把对方逼回现实证据，堵死漫画情节）

1. 对方今天会不会用电影或漫画的情节作为论据？ → 答"不会"：很好，那请对方全场遵守。 → 答"会"：那是编剧写的，不是世界发生的。
2. 对方引用的义警案例里，那些人有超常能力吗？ → 答"没有"：那对方比的是能力，还是问责？

收束语：对方自己承认了，他们比的不是能力。

## 4. 正二驳论稿（正文 423 字 + 临场位 100 字 / 120 秒）

【此处留临场位约 100 字：先用一句话回应反二驳论里最新出现的说法，再进入下面的正文】

反方立论有一个问题贯穿始终：他们在和一个不存在的世界比。

先说他们的第一点，没人能拦。反方举了印度护牛义警，四十四条人命；举了西雅图那个穿着制服喷错人的年轻人。这两个例子里的人，有谁拥有超常能力吗？一个都没有。他们伤人是因为判断差、因为无人过问，不是因为力量大。对方真正在意的是问责的落差，可对方今天要论证的是能力带来的灾难。这两件事被对方捆在了一起。

再说他们的第三点，等靠退化。反方引用了那项志愿者实验，说三个月后的到场率是百分之四对百分之十七。我方承认这个结果。但请评委记住一件事：那项研究比较的是"想一个具体的超人"和"想超级英雄这个类别"，作者自己写明了没有设中性对照组。所以它比的不是有和没有。同一篇论文的另一项研究里，被"超级英雄"这个类别启动的人，承诺的志愿时间是对照组的两倍多。

说到底，反方全场没有正面回答我方一辩的问题：你说的灾难，是和哪个世界比？和一个能及时救人的完美制度比，那个世界不存在。和现在这个世界比，一九九四年的一百天就摆在那里。对方今天想要的是一个能当场纠错的世界，可请对方告诉评委，那个世界现在由谁提供？

- 如果反二打的是判准而不是论点：先承认判准之争是全场焦点，再用"净变化"三个字把标准钉死。
- 如果反二拿出我方没预料到的数据：先问出处与年份，再指出它与判准的关系。

备用点（用于回应对方进攻）：

6. 不受问责是我方一辩自己说的，不是你们发现的。前提不等于结论。
7. 核弹是国家用工业体系造的技术，一个人不是技术。
8. 八十年一万两千多枚核弹头，核战争发生了吗？

- "他杀错人怎么办？" → 那是一条人命，我方不回避，请把它和那一百天放在同一个天平上。
- "谁来监督他？" → 没有人。这是我方一辩说的。判准问的是净变化，不是他完美。
- "你凭什么说他会一直做好事？" → 我方从不承诺他永远正确，我方承诺的是那些人多了一次活下来的可能。

## 6. 正三盘问问题链（90 秒，单边计时）

## 8. 正三盘问小结稿（正文 401 字 / 90 秒）

谢谢主席，各位评委。刚才的盘问，我想请评委记住两件事。

第一件，对方二辩和四辩在同一个问题上给了不一样的答案。我问他们，你方是否主张超级英雄迟早会作恶。一个人说无法验证，另一个人说很可能。这不是措辞的差别。如果是"无法验证"，那对方今天证明的只是风险；如果是"很可能"，那请对方拿出依据来。两条路对方都还没走完。

第二件，我请对方举一个例子，是超常能力本身造成的灾难。对方给出的是印度的护牛义警，是纽约的守护天使队，是西雅图那个喷错人的年轻人。这些人里没有一个拥有超常能力。他们造成伤害，是因为没有能力还硬上，是因为事后没人过问。对方比的从头到尾是问责的落差，不是能力。

那我方的两点就还立着。切尔诺贝利现场六百人里一百三十四人急性放射病，那里缺的是能力。卢旺达一百天，维和部队减到两百七十人，那里缺的是当场挡在中间的人。

说到底，现在双方的分歧已经很清楚了。对方说，一种没人能管的力量出现本身就是灾难。我方说，请你和那个没有他的世界比一比。到目前为止，对方一直没有回答，他们说的灾难是和哪个世界比。谢谢。

- 如果反三小结抢先点出我方"只引一半论文"，就在自由辩第一轮用"我方一辩就预告了"回应。

## 9. 自由辩战场设计（240 秒）

### 战场一：灾难是和哪个世界比

- 目标：让评委听到对方第四次回避同一个问题。
- 开场问题：对方说的灾难，是和哪个世界比？
- 对方答"和现在的世界比" → 追问：现在的世界里，那一百天有人挡住了吗？
- 对方答"和一个有约束的世界比" → 追问：那个世界现在存在吗？谁在提供它？
- 对方可能反攻：你们是在用极端案例绑架判准 → 我方防守：那不是极端案例，那是一百天里的一百万人，是人类近三十年最大的一次失败。
- 收束语：这个问题我方问了四次，对方没有答。

### 战场二：能力还是问责

- 目标：让评委看清对方全部证据讲的都是问责落差。
- 开场问题：对方举的义警案例里，有谁拥有超常能力？
- 对方答"没有" → 追问：那你们比的是能力，还是问责？
- 对方答"类比的是落差" → 追问：落差是我方定义里就写明的前提，请给出从前提到灾难的那一步。
- 对方可能反攻：能力越大落差越大 → 我方防守：落差大不等于后果坏，还要看这个人做了什么，这正是判准问的净变化。
- 收束语：对方全场没有一个例子，是超常能力本身造成的灾难。

### 战场三：那一半论文

- 目标：把对方最强的数据打成"机制说明"而不是"证据"。
- 开场问题：那项研究有没有设中性对照组？
- 对方答"没有" → 追问：那百分之四和百分之十七比的是有和没有，还是两种想法？
- 对方答"作者省略了" → 追问：省略的理由是对照组落在两者中间，对吗？
- 收束语：这项研究说明的是人怎么看待符号，不是世界有没有他更好。

必问（前两分钟问完）：

- 你说的灾难是和哪个世界比？
- 你举的例子里有谁拥有超常能力？
- 那项研究有没有中性对照组？
- 你主张他"会作恶"还是"无法验证"？

必答与口径：

- "谁来监督他？" → 没有人，这是我方一辩自己说的，前提不等于结论。
- "他杀错人怎么办？" → 那是一条人命，请和那一百天放在同一个天平上。
- "你只引了对你有利的一半论文？" → 我方一辩就预告了，二辩完整说过两半。

时间分配与站位：前 90 秒打战场一并把必问抛完；中间 90 秒打战场二；最后 60 秒打战场三并收束，不开新战场，留 20 秒备用。一辩守定义与判准，二辩接驳论过的点，三辩接盘问成果，四辩负责收束与价值。

## 10. 正四结辩稿（正文 773 字 / 210 秒，留 30–40 秒临场回应）

【此处留 30 到 40 秒临场位：真回应反四结辩，不要念稿】

谢谢主席。全场下来，双方真正的分歧只有一个：比较对象是什么。请评委注意，这不是一个细节上的分歧，它决定了这场比赛整本账怎么算。

对方说，一种没有人能管的力量出现，世界就失去了纠错能力。我方承认这句话的前半句。他确实不受问责，这是我方一辩主动说出来的。可纠错能力这四个字，请评委想一想，它在哪里存在过？一九九四年四月二十一日，联合国维和部队从两千一百多人减到两百七十人。之后的日子里，一百多万人死去。那一百天，没有任何机制纠正了任何东西。对方所说的我们正在失去的东西，在最需要它的时候，本来就是空的。

对方全场最有力的一击，是那项志愿者研究。想到超人的那一组，三个月后真正到场的只有百分之四，想到"超级英雄"这个类别的有百分之十七。我方不躲这个数字。我方只请评委记住两件事。第一，作者自己写明没有设中性对照组，所以它比的是两种想法，不是有和没有。第二，同一篇论文里，被"超级英雄"这个类别启动的人，承诺的志愿时间是对照组的两倍多。人在一个不可企及的符号面前会退后，在一件"有人正在做的事"面前会往前。辩题假设的，是后一种。

我方的两点，到现在还立着。切尔诺贝利现场六百人里一百三十四人急性放射病，二十八人三个月内死亡，那里缺的不是决心，是能力。威慑研究告诉我们，让人不敢做的是被抓住的确定性，而不是事后判得多重。一份汇总了六十五项研究的系统综述也发现，把力量放到最危险的地方，那里的犯罪降了，旁边的街区跟着一起降。这两件事合起来只说明一句话：有些伤害，只差那几分钟里有没有人来得及。

我请各位想一个画面。一个人在你面前倒下去。你围过去，蹲下来，手放在他胸口上，然后发现自己不会。旁边的人也不会。救护车还有七分钟。你抬头看表，第二次看表的时候才过了四十秒。那七分钟里，你不是不想救，你是救不了。

我们今天争的其实不是有没有超人。我们争的是，在那七分钟里，世界允不允许有人来得及。

对方描述的风险是真的。可风险是关于将来的，那七分钟是正在发生的。一个可能出错的人站在那里，和一个确定没有人站在那里，评委手上的天平要往哪边偏，我把它交给各位。
