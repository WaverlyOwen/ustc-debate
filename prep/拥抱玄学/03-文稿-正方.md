# 正赛文稿：拥抱玄学是当代年轻人的精神解脱之道（正方）

- **赛制**：中国科学技术大学新生辩论赛（四对四；正方先立论，正方后结辩）
- **口径来源**：01-备赛文档 第十节 10.1 正方口径表。本文稿所有定义、判准、论点、数据均取自该表。允许换说法，不允许换意思、换数字。

## 1. 正一开篇立论稿（正文 813 字 / 180 秒）

谢谢主席，各位好。

先说清楚讨论的是什么。玄学，指今天流行于年轻人的星座、塔罗、算命、求签、转运物这一类非科学的命运解释和仪式；拥抱玄学，是主动接纳它并在情绪和行为上有所依托——不是全盘皈依，也不只是玩玩。精神解脱，是从精神困境中真实地脱出，重新拿回对生活的安定和自主，不是烦恼断尽。之道，是一条多数人走得通、能通向这个结果的路，不必是唯一的，也不必是最好的。

判断的标准是：在多数年轻人身上，它是不是让人真实地从精神困境中脱出。看三件事——有没有用，能不能让人重新掌握生活，代价是不是小于收益。在这个标准下，我方要证明它的作用不止于一时镇痛、多数人适用、代价可控；对方要证明它只能暂时缓解，或削弱了行动，或代价盖过收益。

我方第一点：**它把控制感还回来了**。年轻人最难受的不是事情难，是使不上劲——简历投出去没回音，你连该改哪里都不知道。二〇〇八年《科学》杂志上的六个实验发现，控制感被削弱的人会更多地去找规律和秩序——这不是愚昧，是人在失控时重建秩序的正常反应。然后呢？二〇一四年《实验心理学杂志》上的三个实验给了答案：经历丧失后完成一套仪式的人，悲伤明显更低，起作用的正是控制感的提升；而且这个效果对明确说"我不信"的人同样成立。

我方第二点：**它换了一个能活下去的解释**。落榜、失业、关系结束，年轻人默认的反应是"是我不够好"，然后没完没了跟自己过不去。玄学给的是另一个解释：时机未到。二〇〇五年一项对 49 项研究的元分析发现，把困境重新解释成可以承受的、并继续和现实协作的那种应对，与更好的心理适应显著相关，相关系数 0.33。一个人花两百块买个手串，然后接着改简历、接着投出去——他停下的是自我攻击，不是行动。

最后，我方全场会反复问对方一个问题：**在对方的标准下，什么才算精神解脱之道？请举一个多数年轻人今天用得上的。**

我方从不说玄学改变了世界。我方说的是，它让一个人在世界没有改变的时候，还站得住。谢谢。

- **如果……就……**：
  - 如果被质询逼问"困境有没有变"→ 直接承认："外部困境一样都没变，我方从来没说它会变。变的是这个人。"不要含糊。
  - 如果对方在质询里抬高"解脱"的标准 → 反问："在您的标准下，心理咨询算不算解脱之道？"
  - 如果时间紧张 → 删第二点的元分析数字，保留机制与手串的例子；不要删定义和判准。

## 3. 正四质询反一问题链（120 秒，双边计时）

**链一：标准链**（目标：逼反方给出"什么才算解脱之道"，拿到"标准过高"的把柄）
1. 请问对方，精神解脱是不是要求困境的根源被拔掉？ → 答"是"：**下一问 2**；答"否"：**跳链一第 4 问**
2. 那心理咨询能拔掉就业压力吗？ → 答"不能"：**下一问 3**

4. 那请对方给一个标准：什么程度算"脱出来了"？ → 对方给出标准后，问："这个标准下，有哪一条路是多数年轻人今天用得上的？"

**链二：因果方向链**（目标：拿到"焦虑在前、玄学在后"的承认）
1. 是年轻人先焦虑，还是先接触玄学？ → 答"先焦虑"：**下一问 2**；答"说不清"：追问"那对方凭什么说玄学制造焦虑"
2. 所以焦虑的来源不是玄学，是就业、学业和关系，对吗？ → 答"是"：**下一问 3**
3. 那对方全场要论证的，就只剩下"它有没有帮上忙"，对吗？

**链三：举证链**（目标：暴露反方只有横断相关）
1. 对方有没有一份关于中国年轻人的追踪研究？ → 答"没有"：直接收束
2. 那对方引的研究，测的是同一时点的相关，还是前后变化？
3. 相关能推出"因此到不了"吗？

**打断用语**："好的，我理解为您没有否认，下一个问题。"
**收束语**："感谢对方。对方到现在没有给出一个多数年轻人用得上的标准，也承认了焦虑在玄学之前。"

## 4. 正二驳论稿（正文 433 字 + 临场位 100 字 / 120 秒）

对方的立论有一个从头到尾的问题：**他们把"人没有出来"和"人没有变"当成了同一件事。**

【临场位，约 100 字：此处回应反二驳论中最尖锐的一点。常见两种——若反二主攻"控制感是错觉"，说："对方说我们给的是错觉。可是二〇一四年那三个实验里，效果对明确说自己不信的人同样成立，这说明起作用的不是信不信，是做没做。"若反二主攻"商业收割"，说："对方在打卖东西的人，我方在讲买东西的人得到了什么。骗子卖假药，不能证明求医不是治病之道。"】

第一，对方的判准是偏的。对方要求我方证明困境的根源被拔掉，可就业压力、学业竞争，心理咨询拔不掉，运动拔不掉，朋友也拔不掉。一个把所有现实路径都判死的标准，不是标准。中立的标准是常识标准：人还在原来的处境里，但他不再被压垮，能重新做事——这就是脱出来了。这条标准之所以中立，是因为它对每一条路都一样：心理咨询、运动、朋友，没有一条改变了外面的世界，改变的都是人在里面还站不站得住。

第二，对方的证据打不到自己的结论。对方用癌症宿命论的元分析说人会因此不行动，可那说的是不去做筛查，不是不去投简历；对方引二〇二四年那份三千多人的研究，却漏掉了同一篇里的另外半句：最接近年轻人星座塔罗的那一类信念，与痛苦、与应对能力**都没有统计关联**。对方主张的是一个纵向结论——用了之后更差——手上却全是同一时点的相关数据。作者自己都写明了不支持因果。

回到我方判准：有没有用，能不能让人重新掌握生活，代价是不是小于收益。六成人一年花不到五百块，买回来的是今晚能睡着、明天能去面试。这三条我方都答了，对方到现在一条都没答。

- **如果……就……**：如果反二完全没打我方论点只在讲代价 → 把临场位换成"对方全场只在算钱，没有回应我方的两条机制"，然后加一句必问 1。

## 5. 正二对辩要点（90 秒，单边计时）

**进攻点（每个 15–20 秒，说完就停）**
1. 请对方回答：在你们的标准下，什么才算精神解脱之道？举一个多数人用得上的。
2. 对方承不承认，是焦虑在前、玄学在后？

**备用点（回应对方进攻用）**
- 错觉 → 我们判的是精神状态，人能睡着是真的。
- 宿命 → 停止自我攻击不等于停止改变自己，元分析里区分得很清楚。
- 商业化 → 打的是卖的人，不是买的人得到了什么。
- 挤出心理咨询 → 请拿出"玄学参与者求助率更低"的数据。
- 诈骗案 → 对方自己也说这是个案。
- 科学素质 → 那个数字还在提高，比上年提高了 1.21 个百分点。
- 文化 → 那是另一个论题，与解脱无关。
- 社交货币 → 那说明它很轻，对方不能一边说它轻一边说它害人重。

**对方最可能问的三个问题 → 回应**
1. "困境变了哪一样？"→ 一样都没变，变的是人。
2. "恢复行动的证据呢？"→ 二〇一四年的实验测的是悲伤下降与控制感中介；行动这一步我方用寺庙订单和继续投简历的日常事实来说明，我方不夸大它是实验结论。
3. "你承不承认有代价？"→ 承认，我方判准第三条就在算代价，而且算下来是六成人五百块以内。

## 8. 正三盘问小结稿（正文 402 字 / 90 秒）

刚才的盘问里，对方承认了三件事。

第一，对方承认玄学确实有安慰作用。那么今天真正的分歧就只剩一个：安慰到什么程度，才算脱出来。第二，我方连着问了三次"在你们的标准下什么才算解脱之道"，对方给出的答案是困境的根源被解除——可对方的二辩和四辩，在"心理咨询算不算"这个问题上给了不一样的说法。第三，对方承认自己没有一份关于中国年轻人的追踪研究。

这三件事连起来看：对方手里有一个高到没有路径能达到的标准，却没有任何纵向证据支持"这条路到不了"。换句话说，对方是拿一个谁都走不到的终点，来否认一条已经有人在走的路。

而我方的两点始终立在这里。第一，它把控制感还回来了——二〇一四年的三个实验证明，仪式带来的悲伤下降对不相信仪式的人同样成立。第二，它换了一个能活下去的解释——二〇〇五年对 49 项研究的元分析显示，这类重新解释与更好的心理适应相关，相关系数 0.33。

到现在为止，双方的分歧集中在"解脱"这两个字的门槛上。对方把门槛设在人力不可及的地方，我方设在常识可及的地方。谁的标准更像一个评委会点头的标准，请各位判断。

## 9. 自由辩战场设计（240 秒）

### 战场一：缓解还是解脱（前 90 秒）
- **目标**：把"解脱"锁死在常识标准，逼对方要么降标准、要么承认自己在做定义杀。
- **开场问题**：对方认为，一个人从整晚睡不着到能睡着，算不算脱出来了？
- **对方答"不算"** → 追问："那心理咨询算吗？运动算吗？请给一条算的。"
- **对方答"算，但不够"** → 追问："不够到什么程度才够？请给一个我们今天能验证的门槛。"
- **对方反攻**（"那喝酒也算了"）→ 防守口径："区别在第二天。喝完更空，求完签去投简历。我方判准第二条问的就是这个。"
- **收束语**："对方的标准里，没有一条路配叫解脱之道。"

### 战场二：因果方向（中 90 秒）
- **目标**：拿下"焦虑在前、玄学在后"，把对方的"制造焦虑"打成倒果为因。
- **开场问题**：是焦虑让人去找玄学，还是玄学让人焦虑？
- **对方答"互相强化"** → 追问："二〇〇八年《科学》上的六个实验证明的是前一个方向，对方证明后一个方向的实验在哪里？"
- **对方反攻**（"先卖你不安再卖你安心"）→ 防守口径："对方在打卖的人，我方在讲买的人得到了什么。而且六成人一年花不到五百块。"
- **收束语**："对方全场都在把先后顺序说反。"

### 战场三：举证责任（后 60 秒，只收束不开新战场）
- **开场问题**：对方有没有一份中国年轻人的追踪数据？
- **收束语**："主张'到不了'的是对方。到现在为止，对方给的全是同一时点的相关，连作者自己都写明不支持因果。"

**必问**（前两分钟内问完）：①什么才算解脱之道，举一个用得上的；②焦虑在前还是玄学在前；③追踪研究在哪里；④五百块的代价大在哪里。
**必答与口径**：见 02-速查-正方"必答"三条，全队一字不改。
**站位**：一辩守定义与判准，二辩接驳论过的点，三辩接盘问成果，四辩收束与价值。

## 10. 正四结辩稿（正文 804 字 / 210 秒，留 30–40 秒临场回应）

谢谢主席。

全场下来，分歧只有一个：**"解脱"这两个字，门槛定在哪里。** 对方定在困境的根源被拔掉，我方定在人从里面出来了。

先正面回应对方最强的一点：控制感是错觉。我方承认一半：星座不准，我方从没说过它准。但我们判的是**精神**解脱，衡量的是一个人的精神状态。二〇一四年那三个实验里，仪式带来的悲伤下降是测量出来的，而且对明确说"我不信"的人同样有效。这说明起作用的不是他信了假东西，是他做了一件事。

而对方最需要的结论——拥抱玄学的年轻人后来更差——需要一份追踪研究，对方一份都没拿出来。

我方全场问了三次的问题，对方到现在没有正面回答：在你们的标准下，什么才算精神解脱之道？

我想讲一件很小的事。

晚上十一点半，宿舍熄了灯。有人还在被子里刷手机，第五次刷新那个没有回音的邮箱。他没跟任何人说，因为说了也没用；他也没去心理中心，因为他觉得自己"还没到那个程度"。然后他点开一个星座 App，看见一句话：这段时间水逆，不是你的问题，过了这个月会好起来。

这句话是假的。我知道，你也知道，他自己其实也知道。

但那天晚上他睡着了。第二天他把简历又改了一遍。

我方想说的不是玄学有多好。我们想说的是：当一个人已经没有力气再责怪自己，让他借一句话喘口气，这不是软弱。对方全场都在问"他的困境变了哪一样"。我的回答是：困境一样都没变，**变的是他**。而所有改变，从来都是从人先站起来开始的。

对方说，该把这份力气用在能真正改变处境的地方。我同意。可是力气从哪来？一个整晚睡不着、第二天面试就崩掉的人，才真的什么都做不了。

所以我方只主张一件事：这是一条路。不是唯一的，不是最好的，但对很多年轻人来说，是他们够得着、走得动、并且真的走出来了一段的那条路。

它配得上"之道"这两个字。谢谢。
